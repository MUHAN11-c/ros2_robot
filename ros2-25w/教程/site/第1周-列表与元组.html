第1章 列表与元组（Python 基础入门）

第一篇（基础篇）从这里开始。本章对应课程第 1 周：Python 环境与变量、格式化输出、运算符、分支与循环，以及字符串/列表/元组/字典四种容器。它是整个 25 周体系的起点——后面写 rclpy 节点、解析传感器消息，本质上都是「拿到数据 → 用数据结构组织 → 用流程控制加工」。

1.1 案例以及案例分析

需求：管理机器人航点序列——用元组表示坐标 (x, y)，计算相邻航点总路程、筛选近处航点、按坐标排序。

流程：变量与类型 → 分支循环 → 字符串/列表/元组/字典 → 综合案例。

1.2 知识点与实现

1.2.1 变量、类型与格式化输出

  • 常用类型：int / float / bool / str；type() 查看、int()/float()/str() 转换；
  • input() 一律返回字符串，数值运算前必须转换；
  • 推荐 f-string：print(f"x={x:.2f}")；
  • 运算符：/ 得浮点、// 整除、** 幂；逻辑运算符有短路求值。

1.2.2 分支与循环

scores = [92, 78, 65, 88, 54, 100, 73, 81]
grade = {"A": 0, "B": 0, "C": 0, "D": 0}
for s in scores:
    if s >= 90:   grade["A"] += 1
    elif s >= 80: grade["B"] += 1
    elif s >= 60: grade["C"] += 1
    else:         grade["D"] += 1
  • break 跳出整个循环、continue 跳过当次；for ... else 的 else 在未被 break 时执行；
  • range(start, stop, step) 左闭右开，是惰性对象。

1.2.3 四种容器

容器 特点 典型用途
str 不可变序列 find/split/replace/strip、切片 [start:end:step]
list 可变有序 append/extend/insert/remove/pop/sort、推导式
tuple 不可变有序 坐标 (x, y)、函数多返回值、字典的键
dict 键值映射 d[k]=v、d.get(k, 默认)、d.items()
  • 拆包：x, y = (3.0, 4.0)、a, b = b, a、first, *rest = lst；
  • 浅拷贝 lst[:]/copy() 只复制第一层，嵌套结构要 copy.deepcopy()。

1.4 端到端实战（实测）：航点管理器

把本章知识串成一个完整程序：字典存航点、while 逐行读命令、分支分发、sorted 按 x 排序输出。

# waypoints.py —— 标准输入逐行接收命令：add 名称 x y / list / quit
waypoints = {"w0": (0.0, 0.0), "w1": (1.5, 0.0)}
import sys
for line in sys.stdin:
    parts = line.split()
    if not parts:
        continue
    cmd = parts[0]
    if cmd == "add":
        name, x, y = parts[1], float(parts[2]), float(parts[3])
        waypoints[name] = (x, y)
        print(f"已添加 {name} -> ({x}, {y})")
    elif cmd == "list":
        for name, (x, y) in sorted(waypoints.items(), key=lambda kv: kv[1][0]):
            print(f"  {name}: ({x:.2f}, {y:.2f})")
    elif cmd == "quit":
        print(f"共 {len(waypoints)} 个航点，退出")
        break
    else:
        print(f"未知命令: {cmd}")

实测（管道喂入三条命令）：

$ printf "add w2 3.0 1.0\nlist\nquit\n" | python3 waypoints.py
已添加 w2 -> (3.0, 1.0)
  w0: (0.00, 0.00)
  w1: (1.50, 0.00)
  w2: (3.00, 1.00)
共 3 个航点，退出

1.5 本章小结

  • 分支/循环是「控制流」，四种容器是「数据组织」——二者组合即可写出完整小脚本；
  • 列表可变、字符串与元组不可变；str.replace() 返回新串而非改原串；
  • 推导式适合一行能写清的筛选/转换，复杂逻辑仍用普通循环；
  • 与 ROS2 的关联：消息字段就是数据结构（Point ↔ 三元组、Path.poses ↔ 列表），参数读写形如字典操作。
