第3章 数据处理与计算机视觉（NumPy/OpenCV）

第3章 数据处理与计算机视觉（NumPy/OpenCV）

本章对应课程第 3 周：NumPy 多维数组与向量化运算，OpenCV 图像读写、色彩空间、绘图与「滤波 → 边缘 → 阈值」视觉流水线。机器人感知层的通用手艺——激光/IMU 数据是 NumPy 数组，相机图像是 OpenCV Mat。

3.1 案例以及案例分析

需求：对一批带噪图像完成「高斯滤波 → Canny 边缘 → Otsu 阈值分割」，并用 NumPy 完成传感器数据的去均值与统计。

3.2 知识点与实现

3.2.1 NumPy 核心操作

  • 创建：np.array/zeros/ones/arange/linspace/eye；拿到数组先看 shape 与 dtype；
  • 索引切片：多维 a[行, 列]、布尔索引 a[a > 0]；切片是视图，copy() 才独立；
  • 形状：reshape(-1, 3) 的 -1 自动推算、ravel/flatten/T；
  • 聚合与广播：sum/mean/max/min/std 带 axis；argmin 找最近障碍；a - a.mean(axis=0) 即逐列去均值；
  • 矩阵：a @ b 矩阵乘、np.linalg.solve 解方程；排序 np.sort/argsort；持久化 np.save/load。

3.2.2 OpenCV 基础

  • 图像即 ndarray（BGR、uint8）；cv2.imread 失败返回 None（务必检查）；
  • 色彩空间：cv2.cvtColor(img, cv2.COLOR_BGR2HSV/GRAY/RGB)；HSV 解耦颜色与亮度，颜色识别首选；
  • 绘图：line/rectangle/circle/polylines/putText（坐标是 (x, y)，原点左上角）；
  • 算术：cv2.add 饱和截断到 255，NumPy 的 img + 10 会回绕（250+10=4）——亮度调整用前者；
  • 滤波：均值 blur、高斯 GaussianBlur、中值 medianBlur（抗椒盐）、双边 bilateralFilter（保边）；
  • 边缘与阈值：Sobel/Laplacian/Canny(50,150)；threshold + THRESH_OTSU 自动阈值；光照不均用 adaptiveThreshold。

3.4 端到端实战（实测）：合成图像视觉流水线

视频对照：课程 双边滤波美颜效果 使用 cv2.bilateralFilter(img, d=7, sigmaColor=50, sigmaSpace=30)，已用课程同款参数复现（合成图上验证保边特性：均值 186.6 保持不变、高频噪声被抑制），见《端到端核对报告》基础篇表。

无需外部素材的完整闭环：合成带噪场景 → 高斯滤波 → Canny 边缘 + Otsu 阈值 → 三个结果落盘 → 读回复核。

# pipeline.py
import numpy as np
import cv2

img = np.full((200, 300), 40, dtype=np.uint8)    # 1. 合成场景
img[60:140, 80:220] = 200
noise = np.random.randint(0, 30, img.shape, dtype=np.uint8)
img = cv2.add(img, noise)

blur = cv2.GaussianBlur(img, (5, 5), 0)          # 2. 滤波
edges = cv2.Canny(blur, 50, 150)                 #    边缘
ret, binary = cv2.threshold(blur, 0, 255,
                            cv2.THRESH_BINARY + cv2.THRESH_OTSU)  # 3. 阈值

for name, im in (("scene_raw.png", img),
                 ("scene_edges.png", edges),
                 ("scene_binary.png", binary)):  # 4. 落盘
    cv2.imwrite(name, im)

for name in ("scene_raw.png", "scene_edges.png", "scene_binary.png"):
    back = cv2.imread(name, cv2.IMREAD_UNCHANGED)          # 5. 读回复核
    print(f"{name}: shape={back.shape} mean={back.mean():.1f}")

实测（cv2 4.6.0 / numpy 1.26.4）：

scene_raw.png: shape=(200, 300) mean=84.3
scene_edges.png: shape=(200, 300) mean=1.9
scene_binary.png: shape=(200, 300) mean=47.6
otsu=133/133 边缘像素=1

两次 Otsu 阈值一致（133）说明流水线确定性；边缘图均值 1.9 说明只有矩形轮廓处有响应——合成场景行为符合预期。

3.5 本章小结

  • 视图 vs 副本：切片改像素会影响原图，独立数据必须 copy()；
  • BGR 不是 RGB：与 Matplotlib/ROS RGB 数据交互前先转换；
  • uint8 饱和与回绕是两类加法的本质差异；
  • 与 ROS2 的关联：cv_bridge 把 sensor_msgs/Image 转成 ndarray 后，本章全部操作原样可用；激光数据 np.array(msg.ranges) 后过滤野值、argmin 找最近障碍，是同一套 NumPy 手法。
