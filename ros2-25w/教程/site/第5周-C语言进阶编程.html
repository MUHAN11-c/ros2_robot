5.2 知识点梳理

5.2.1 第1课 运算符与类型转换深度解析

  • 核心概念：运算符（operator）+ 操作数 = 表达式，表达式有值和类型；类型转换决定不同类型的数如何一起运算。
  • 数学运算符：+ - * / %。整数除法截断（5/2 == 2），% 取模仅用于整数（-7 % 2 结果随实现，实际为 -1）。想要小数结果必须让操作数是浮点：5.0 / 2。
  • 除数不能为 0：整数除以 0 会崩溃（浮点除 0 得 inf/nan）。运行时变量作除数前先判 if (b != 0)——机器人中里程计轮径、时间差都可能为 0。
  • 自增和自减：i++ 先用后加、++i 先加后用；a = i++ - ++i 这类「一个表达式多次修改同一变量」是未定义行为，禁止出现在工程代码里。
  • 赋值运算：= += -= *= /= %=。a = b = c 右结合；赋值表达式本身也有值（while ((c = getchar()) != EOF) 是常见用法）。
  • 比较运算符：== != > < >= <=，结果为 1（真）或 0（假）。== 写成 = 是最高频 bug，建议把常量写左边（if (0 == ret)）或开 -Wall。
  • 逻辑运算符：&& 与、|| 或、! 非。关键性质：短路求值——a && b 中 a 为假则 b 不执行，a || b 中 a 为真则 b 不执行；if (p && p->x) 能防野指针解引用。
  • 运算符优先级：记「单目 > 算术 > 移位 > 关系 > 位 > 逻辑 > 三目 > 赋值 > 逗号」，拿不准就加括号。工程上靠括号表达意图，不靠背优先级表。
  • 三元、三目运算符：条件 ? 值1 : 值2。例如 int max = a > b ? a : b;，适合简单二选一；复杂逻辑用 if/else 保证可读性。
  • 了解逗号运算符：表达式1, 表达式2 从左到右求值，整体取最后表达式的值，如 for (i = 0, j = n - 1; i < j; i++, j--)（快排/翻转常用）。
  • 隐式类型转换：运算时小类型自动提升（char/short → int → unsigned → long → double）；赋值时向左值类型收窄（double d = 5 / 2; 得 2.0，因为先整数除）。混合有符号/无符号比较会被转成无符号，-1 < 1u 为假——经典坑。
  • 强制类型转换：(类型)表达式，如 double avg = (double)sum / n;（避免整数除法）。指针转换（第6周）也用这个语法。原则：转换要显式写出意图，避免编译器默默收窄。

5.2.2 第2课 分支语句与循环结构精讲

  • 核心概念：分支（selection）解决「做什么」，循环（iteration）解决「做几次」。控制流是机器人状态机与控制周期循环的基础形态。
  • 单分支和双分支语句：if (cond) {...} 与 if (cond) {...} else {...}。注意 if (cond); 的空语句陷阱与悬垂 else（就近配对），养成加大括号的习惯。
  • 多分支语句：else if (cond) {...} else {...} 链，条件从上到下判断，命中即停；else 可省略。适合范围判断（如速度分档）。
  • switch 语句：switch (整型/字符表达式) + case 常量: + break + default。case 后必须是整型常量；漏写 break 会「贯穿」（fall-through）到下一个 case。适合枚举状态机（如机器人模式切换）。
  • while 循环基础语法 / while 练习：while (cond) {...}，先判断后执行，可能一次都不执行。练习常做累加、阶乘、数字逐位拆解。警惕死循环与「差一错误」（off-by-one）。
  • do-while 循环基础语法：do {...} while (cond); 先执行后判断，至少执行一次；适合「菜单先显示再判断」类交互。注意结尾分号。
  • 水仙花数：三位数中各位立方和等于自身的数（153、370、371、404）。算法：取个位 n % 10、取百位 n / 100、取十位 n / 10 % 10——数字拆解在编码器数值解析中常用。
  • for 循环基础：for (初始化; 条件; 步进) {...}，三段都可省略但分号不能省；for 适合已知次数的遍历。
  • 猜数字实现：rand() % 范围 生成随机数、srand((unsigned)time(NULL)) 播种、循环读取输入比较大小并提示「大了/小了」——综合 scanf、分支、while 的第一个完整小程序。
  • for 循环嵌套 / 九九乘法表实现：外层控制行、内层控制列，printf("%d*%d=%-4d", ...) 对齐输出。嵌套循环复杂度是 O(n²)，是后面理解算法效率的起点。
  • break 跳出循环 / continue 跳出当次循环：break 终止本层循环，continue 跳过本次进入下一轮；只影响最内层循环。嵌套时可用标志位或 goto 语义跳出多层。
  • 了解 goto：goto 标签; 可无条件跳转，破坏结构化，仅在「深层嵌套统一错误清理」（C 语言内核风格）中使用，业务逻辑禁止。

5.2.3 第3课 数组及多维数组全面详解

  • 核心概念：数组（array）是连续内存中同类型元素的集合，下标从 0 开始；数组名 即首元素地址（常量指针语义）。
  • 数组数据是连续的 / 一维数组：int a[5] 占 5 * sizeof(int) = 20 字节，a[i] 等价 *(a + i)。越界访问不报错、直接踩内存，是最危险的 bug 之一。
  • 数组地址等于数组第零个地址：a == &a[0]，数值相同但类型不同（int* vs int(*)[]，第6周展开）。&a + 1 跳过整个数组。
  • 数组元素的个数：sizeof(a) / sizeof(a[0]) 求元素数（仅在定义所在作用域有效）；数组传参后退化为指针，sizeof 就失效了——常封装成 #define N (sizeof(a)/sizeof(a[0])) 并显式传长度。
  • 数组初始化语法总结：int a[5] = {1,2,3};（余下补 0）、int a[] = {1,2,3};（编译器定长）、int a[5] = {0};（全清零）、char s[8] = "hi";。部分初始化后未显式初始化的元素为 0（局部数组同理，因为整体初始化了）。
  • 数组翻转：首尾双指针交换——for (i = 0, j = n-1; i < j; i++, j--) 交换 a[i], a[j];，时间 O(n/2)，是原地算法的入门范例。
  • 冒泡排序思路 / 代码实现：相邻元素两两比较，大的后移，每轮「冒」出一个最大值到末尾；外层 n-1 轮，内层 n-1-i 次；可加 swapped 标志提前结束。时间复杂度 O(n²)，稳定排序。
  • 找数组最大值：打擂台法——取首元素为 max，遍历更新；同时可记录下标。求最值、均值是传感器数据处理的第一步。
  • 二维数据基础 / 初始化方法 / 初始化补充：int m[3][4] 是 3 行 4 列，按行优先连续存储；初始化可整体 { {1,2,3,4}, {5,6,7,8} }、逐行省略内层括号、或部分初始化（剩余补 0）。
  • 二维数组大小的计算 / 二维数组地址：sizeof(m) = 行*列*元素大小；m、m+1 跳过一整行；m[i][j] == *(*(m+i)+j)。行指针概念是理解图像缓冲区布局的关键。
  • 二维数据练习 / 求每个学生总成绩 / 求每门课总成绩：典型遍历方向不同——按行累加得每个学生总分（内层循环扫列），按列累加得每门课总分（内层循环扫行）。
  • 快捷导入代码：IDE 代码片段（snippet）与多文件复用技巧；工程上真正该复用的是函数与头文件（第6周）。
  • 了解多维数组：三维及以上（如 img[h][w][3] 表示 RGB 图像），本质仍是一段连续内存 + 多重下标换算。
  • 字符数组和字符串 / 练习 01 / 练习 02：char s[] = {'h','i','\0'} 与 char s[] = "hi" 等价；%s 读写、字符串拷贝、长度统计等练习，注意预留 '\0' 位置。
  • 统计字母出现次数：用 26 元素的计数数组（桶思想）——cnt[c - 'a']++，遍历字符串一次完成统计。这是哈希/频次统计的最简形态，也是解析传感器字符协议的常用手法。

5.3 重点与难点

  1. 短路求值与优先级：&&/|| 的副作用控制（防止空指针解引用）、== 与 = 混淆、混合有符号/无符号比较——这三类 bug 在 C 里隐蔽且高频。
  2. 数组越界与「数组名即首地址」：C 不做边界检查；sizeof(数组)/sizeof(元素) 只在数组本体作用域有效。写任何数组代码前先想清楚长度从哪来。
  3. 冒泡排序必须能默写：它综合了循环嵌套、交换、下标控制，是本周能力的验收点；理解 O(n²) 与「为什么每轮少比一次」。
  4. 二维数组的内存视角：m[i][j] 背后是 *(m + i*列数 + j) 的线性换算；图像、点云、栅格地图都是这个模型。

注意： for (int i = 0; i <= n; i++) 遍历长度为 n 的数组会越界访问 a[n]；C 编译器和运行时都不会报错，只会悄悄踩坏相邻内存。统一写 i < n。

/* ops.c —— 整数除法、短路求值、类型转换 */
#include <stdio.h>

int main(void)
{
    int a = 5, b = 2;
    printf("整数除法: %d / %d = %d\n", a, b, a / b);
    printf("浮点除法: %.1f\n", (double)a / b);      /* 强制转换后才出小数 */

    unsigned int u = 1;
    printf("-1 < 1u ? %d  (混合比较被转为无符号)\n", -1 < u);

    int x = 0;
    if (x != 0 && 10 / x > 1)        /* 短路：x==0 时右侧不执行，不崩 */
        printf("never\n");
    else
        printf("短路保护生效\n");

    int max = a > b ? a : b;          /* 三目运算符 */
    printf("max = %d\n", max);
    return 0;
}

场景 2：分支 + 循环综合——猜数字（对应第2课）

/* guess.c —— while + if/else + 随机数 */
#include <stdio.h>
#include <stdlib.h>
#include <time.h>

int main(void)
{
    srand((unsigned)time(NULL));
    int target = rand() % 100 + 1;    /* 1 ~ 100 */
    int guess = 0, times = 0;

    while (1) {
        printf("请猜一个 1~100 的数: ");
        if (scanf("%d", &guess) != 1) return 1;   /* 输入非数字则退出 */
        times++;
        if (guess > target)      printf("大了!\n");
        else if (guess < target) printf("小了!\n");
        else { printf("猜对了! 共用 %d 次\n", times); break; }
    }
    return 0;
}

场景 3：数组翻转 + 冒泡排序 + 求最值（对应第3课）

/* sort.c —— 翻转与冒泡排序，体现下标与交换 */
#include <stdio.h>

#define N 6

void print_arr(const int a[], int n)
{
    for (int i = 0; i < n; i++)
        printf("%d ", a[i]);
    printf("\n");
}

int main(void)
{
    int a[N] = {42, 7, 19, 3, 88, 25};

    /* 数组翻转：首尾双指针 */
    for (int i = 0, j = N - 1; i < j; i++, j--) {
        int t = a[i]; a[i] = a[j]; a[j] = t;
    }
    printf("翻转后: "); print_arr(a, N);

    /* 冒泡排序：每轮把最大值顶到末尾 */
    for (int i = 0; i < N - 1; i++) {
        int swapped = 0;
        for (int j = 0; j < N - 1 - i; j++) {
            if (a[j] > a[j + 1]) {
                int t = a[j]; a[j] = a[j + 1]; a[j + 1] = t;
                swapped = 1;
            }
        }
        if (!swapped) break;          /* 已有序，提前结束 */
    }
    printf("排序后: "); print_arr(a, N);

    /* 找最大值 */
    int max = a[0], idx = 0;
    for (int i = 1; i < N; i++)
        if (a[i] > max) { max = a[i]; idx = i; }
    printf("最大值 %d，下标 %d\n", max, idx);
    return 0;
}

gcc -Wall sort.c -o sort && ./sort

场景 4：二维数组成绩统计（对应第3课「求每个学生总成绩 / 求每门课总成绩」）

/* score.c —— 按行求每人总分，按列求每科总分 */
#include <stdio.h>

#define STUDENTS 3
#define COURSES  4

int main(void)
{
    int score[STUDENTS][COURSES] = {
        {80, 92, 77, 65},
        {95, 88, 90, 84},
        {70, 66, 75, 80}
    };

    for (int i = 0; i < STUDENTS; i++) {          /* 每个学生：行求和 */
        int sum = 0;
        for (int j = 0; j < COURSES; j++) sum += score[i][j];
        printf("学生%d 总分=%d 平均=%.1f\n", i, sum, (double)sum / COURSES);
    }

    for (int j = 0; j < COURSES; j++) {           /* 每门课：列求和 */
        int sum = 0;
        for (int i = 0; i < STUDENTS; i++) sum += score[i][j];
        printf("课程%d 总分=%d\n", j, sum);
    }
    return 0;
}

gcc -Wall score.c -o score && ./score

场景 5：字符数组与字母频次统计（对应第3课「字符数组和字符串 / 统计字母出现次数」）

/* count.c —— 桶计数统计 a-z 出现次数 */
#include <stdio.h>
#include <string.h>

int main(void)
{
    char text[] = "ros2 robot uses c language";
    int cnt[26] = {0};

    for (int i = 0; text[i] != '\0'; i++) {       /* 遇 \0 结束 */
        char c = text[i];
        if (c >= 'a' && c <= 'z') cnt[c - 'a']++; /* 桶下标映射 */
    }
    for (int i = 0; i < 26; i++)
        if (cnt[i] > 0)
            printf("%c: %d\n", 'a' + i, cnt[i]);
    printf("字符串长度 = %zu\n", strlen(text));   /* strlen 统计到 \0 */
    return 0;
}

gcc -Wall count.c -o count && ./count

5.6 端到端实战（实测）：成绩统计 + 字母频次

二维数组按行/按列两个方向的遍历统计，加上桶计数频次统计——一个程序覆盖本章三个核心场景。

/* grade.c（节选）—— 按行求每人总分、按列求每科总分、桶计数统计字母 */
#include <stdio.h>
#include <string.h>

int main(void)
{
    int score[3][4] = {
        {80, 92, 77, 65},
        {95, 88, 90, 84},
        {70, 66, 75, 80}
    };

    for (int i = 0; i < 3; i++) {              /* 按行：每个学生 */
        int sum = 0;
        for (int j = 0; j < 4; j++) sum += score[i][j];
        printf("学生%d 总分=%d 平均=%.1f\n", i, sum, (double)sum / 4);
    }
    for (int j = 0; j < 4; j++) {              /* 按列：每门课 */
        int sum = 0;
        for (int i = 0; i < 3; i++) sum += score[i][j];
        printf("课程%d 总分=%d 平均=%.1f\n", j, sum, (double)sum / 3);
    }

    char text[] = "ros2 robot uses c language";
    int cnt[26] = {0};
    for (int i = 0; text[i] != '\0'; i++)
        if (text[i] >= 'a' && text[i] <= 'z') cnt[text[i] - 'a']++;
    for (int i = 0; i < 26; i++)
        if (cnt[i] > 0) printf("%c:%d ", 'a' + i, cnt[i]);
    printf("\n长度=%zu\n", strlen(text));
    return 0;
}

5.7 与 ROS2 / 机器人开发的关联

  1. 分支与循环 = 状态机与控制周期：机器人主循环 while (rclcpp::ok()) { 采集 → 决策 → 控制; rate.sleep(); } 就是本周 while 的形态；switch 对机器人模式（待机/巡航/避障/回充）的枚举分派，与 ROS2 里 switch(state) 完全一致。
  2. 数组是传感器数据的载体：激光雷达 LaserScan.ranges[]、IMU 的 orientation[4]、图像的像素缓冲、导航代价地图的栅格，都是「连续内存 + 下标」的数组模型；二维数组视角直接对应图像行优先布局。
  3. 排序与最值进入感知处理：对 ranges[] 取最小值做最近障碍判断、对帧窗口做中值滤波，就是冒泡/选择排序与打擂台思想的直接应用。
  4. 类型转换与数值安全：机器人中 (double)sum / n 求均值、角度弧度换算、有符号/无符号混用导致的 -1 < 1u 陷阱，在里程计与时间戳计算中会造成真实事故。
  5. 字符频次统计是解析的起点：解析串口 ASCII 协议、GPS NMEA 语句、日志关键词计数，用的都是 cnt[c - 'a']++ 这类桶数组思路。

5.8 自测与练习（含参考答案要点）

  1. 写出 5/2、5.0/2、5%2 的值与类型，并说明 (double)a / b 为什么比 a / b 更常用于均值计算。
  2. 编程题：打印 100~999 中所有「水仙花数」（验收输出：153 370 371 404）。
  3. 编程题：实现九九乘法表，要求用 %-4d 对齐（验收：9 行，第 i 行 i 个式子）。
  4. 动手任务：把场景 3 的冒泡排序改造成「选择排序」，并用 sizeof(a)/sizeof(a[0]) 计算元素个数传入函数（验收：乱序数组输出有序结果）。

参考答案要点：① 5/2 得 int 2（截断），5.0/2 得 double 2.5，5%2 得 int 1；均值计算要先转浮点否则精度丢失；② 用 n/100、n/10%10、n%10 拆位立方求和比较；③ 外层 for (i = 1; i <= 9; i++)，内层 for (j = 1; j <= i; j++) 打印 j*i=积；④ 选择排序每轮找最小值下标后一次性交换，元素个数 sizeof(a)/sizeof(a[0]) 只在定义处有效，函数内必须用传入的长度参数。

5.9 常见问题（FAQ）

  • Q：a[i] 和 *(a+i) 有什么区别？ A：完全等价，编译后生成相同代码；a[i] 更可读，*(a+i) 在指针运算（第6周）中更常用。
  • Q：数组初始化没写全，剩下的元素是什么？ A：只要用了初始化列表（哪怕只有 {0}），剩余元素全部补 0；完全不初始化的局部数组内容是随机脏数据。
  • Q：switch 的 case 能写变量吗？ A：不能，case 后必须是整型常量表达式；范围判断请用 if/else if。
  • Q：为什么 while (scanf("%d", &a) != 1) 要判断返回值？ A：scanf 返回成功赋值的项数；用户输入字母时返回 0，不判断就会死循环。健壮输入永远检查返回值。

5.10 本章小结

  • 分支/循环 = 状态机与控制周期（while (rclcpp::ok()) 就是 while 的形态）；
  • LaserScan.ranges[]、图像缓冲、代价地图都是「连续内存 + 下标」的数组模型；
  • 对 ranges 取最小值做最近障碍判断，就是打擂台思想的直接应用；
  • 均值计算先转浮点（(double)sum / n）、== 与 = 别混淆、混合有符号/无符号比较警惕 -1 < 1u 陷阱；
  • 统一写 i < n 防 off-by-one 越界——C 不替你做边界检查。
