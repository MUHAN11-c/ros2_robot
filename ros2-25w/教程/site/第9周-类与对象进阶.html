第9章 类与对象进阶（构造析构/深浅拷贝/运算符重载）

第9章 类与对象进阶（构造析构/深浅拷贝/运算符重载）

本章对应课程第 9 周：构造/析构、拷贝控制与深浅拷贝、初始化列表、静态成员与单例、this/常函数、友元、运算符重载与智能指针雏形——整个 C++ 阶段最「值钱」的一周。

9.1 案例以及案例分析

需求：实现深拷贝的 Buffer 类（杜绝 double free）与 Vec2 类（operator+、operator<<、仿函数 operator()），体会三/五法则与运算符重载。

9.2 知识点与实现

9.2.1 构造、析构与拷贝控制

  • 构造可重载、析构不可重载；对象销毁时自动析构——RAII 思想的基础；
  • 拷贝构造在值传参/值返回/用旧对象初始化新对象时调用（所以参数用 const T&）；
  • 默认拷贝是浅拷贝：指针成员被两个对象共享 → 析构 double free。必须手写深拷贝（或 = delete / 用智能指针）；
  • 初始化列表 : a_(1), b_(2) 更高效且对引用/const/无默认构造成员必须使用；顺序按成员声明顺序；
  • explicit 禁止单参构造的隐式转换；Person p(); 声明的是函数不是对象；
  • new/delete（调用构造/析构）与 new[]/delete[] 必须配对；现代 C++ 优先智能指针。

9.2.2 静态成员、this 与友元

  • 静态成员属于类本身；静态成员函数无 this，常作单例入口；
  • 单例（C++11 局部静态线程安全）+ = delete 禁拷贝赋值；ROS2 更推荐依赖注入而非全局单例；
  • this 返回 *this 引用实现链式编程（NodeOptions().arguments(...).use_intra_process_comms(true) 即此风格）；
  • 常函数 void f() const（只读接口）与 mutable；空指针调不访问成员的函数可能不崩——防御性设计要保证对象存在；
  • 友元单向、不可传递，仅用于 operator<< 这类必须访问私有的场景。

9.2.3 运算符重载与智能指针雏形

  • + 成员/全局两版；<< 只能全局 ostream& operator<<(ostream&, const T&) 返回 os 支持链式；
  • 前置 ++ 返回引用、后置 ++(int) 返回副本；operator= 要自赋值检查 + 释放旧资源 + 深拷贝 + 返回 *this；
  • 仿函数 operator() 携带状态，是 lambda 与 STL 谓词的底层形态；
  • 智能指针靠 operator->/operator* 代理原生指针：unique_ptr 独占、shared_ptr 引用计数。

9.4 端到端实战（实测）：深拷贝 + 单例 + 链式

三大主题合一：深拷贝 Buffer（三法则）、单例 Logger（禁拷贝 + 地址唯一）、ConfigBuilder 链式接口（返回 *this）。

// logger.cpp（节选）
class Buffer {                        // 深拷贝
public:
    explicit Buffer(const char* s) : size_(std::strlen(s) + 1), data_(new char[size_]) {
        std::memcpy(data_, s, size_);
    }
    Buffer(const Buffer& o) : size_(o.size_), data_(new char[size_]) {
        std::memcpy(data_, o.data_, size_);
    }
    Buffer& operator=(const Buffer& o) { /* 自赋值检查+深拷贝 */ ... }
    ~Buffer() { delete[] data_; }
};

class Logger {                        // 单例
public:
    static Logger& instance() { static Logger inst; return inst; }
    Logger(const Logger&) = delete;
    Logger& operator=(const Logger&) = delete;
    void log(const std::string& msg) { std::cout << "[log] " << msg << "\n"; }
private:
    Logger() = default;
};

class ConfigBuilder {                 // 链式
public:
    ConfigBuilder& set_speed(double v) { speed_ = v; return *this; }
    ConfigBuilder& set_mode(const std::string& m) { mode_ = m; return *this; }
};

实测（g++ -std=c++17 -Wall）：

lidar lidar lidar
单例同地址=1
[log] 系统启动
mode=nav speed=2

三份深拷贝互不影响、两处取到的单例地址相同、链式配置生效。

9.5 本章小结

  • 三/五法则：析构、拷贝构造、拷贝赋值（加移动）要么都写要么都 = delete——C++ 内存安全第一原则；
  • 初始化列表与成员声明顺序；引用/const 成员必须用列表初始化；
  • 传感器回调若存裸指针，回调结束对象析构即悬垂——存 SharedPtr 或深拷贝是本周问题的真实版本；
  • RCLCPP_INFO_STREAM 拼接自定义类型的前提是重载了 operator<<。
