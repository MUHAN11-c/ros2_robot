第8章 C++ 基础特性入门（命名空间/引用/封装）

第8章 C++ 基础特性入门（命名空间/引用/封装）

本章对应课程第 8 周：C++ 相对 C 的增强（类型检查、bool、const、引用）、命名空间与 ::、内联函数与函数重载、类与封装入门——后续 rclcpp 节点类设计的第一块基石。

8.1 案例以及案例分析

需求：设计带访问权限的 Cube 类——成员私有、构造校验尺寸为正、提供体积与「点是否在立方体内」判断，体验封装与接口设计。

8.2 知识点与实现

8.2.1 命名空间与作用域

  • :: 作用域解析：::value 强制取全局版本；
  • namespace 只能写在全局、可嵌套、同名空间可分散声明（rclcpp 就是这么组织的）、支持匿名空间与别名；
  • using 名字;（细粒度）优先于 using namespace 空间;（易冲突）；头文件中禁止 using namespace。

8.2.2 C++ 相对 C 的增强

  • 严格检查：全局变量重定义、实参类型/个数、void* 必须显式转换；
  • struct 可有成员函数与访问权限（默认 public 的 class）；
  • const 是编译期常量（可作数组长度）、内部链接；取地址后退化为只读变量；用 const/constexpr 代替 #define；
  • 引用：T& 别名 是必须初始化、不可改指向的别名（底层 T* const）；const T& 只读传参避免拷贝；T*& 可在函数内改变外部指针指向。

8.2.3 内联、重载与封装

  • inline 替代宏函数（有类型检查）；constexpr 编译期计算；
  • 函数重载：参数列表不同即可，仅返回类型不同不算；extern "C" 按 C 规则链接以调用硬件 SDK；
  • 封装：成员 private、public 接口受控（setter 里做校验）；class 默认 private、struct 默认 public。

8.4 端到端实战（实测）：Rectangle 类

封装 + 构造校验异常 + 全局协作函数的综合案例（与课程立方体案例同型）：

// rect.cpp
class Rectangle {
public:
    Rectangle(double w, double h) : w_(w), h_(h) {
        if (w <= 0 || h <= 0) throw std::invalid_argument("尺寸必须为正");
    }
    double area() const { return w_ * h_; }
    double perimeter() const { return 2 * (w_ + h_); }
    double width() const { return w_; }
    double height() const { return h_; }
private:
    double w_, h_;
};

bool can_form_square(const Rectangle& a, const Rectangle& b) {
    return std::fabs(a.width() - b.height()) < 1e-9 &&
           std::fabs(a.height() - b.width()) < 1e-9;   // 旋转后可拼成正方形
}

8.5 本章小结

  • 命名空间即库边界（rclcpp、sensor_msgs::msg）——自己的功能包从第一天起建命名空间；
  • 引用与 const T& 是回调函数标准签名的理论基础；
  • 封装 = 节点类设计：publisher/subscription 收进私有成员、只暴露必要接口；
  • extern "C" 打通 C 语言编写的传感器 SDK。
