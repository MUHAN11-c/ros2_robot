第17章 工具应用实操（launch 与 rosbag2）

第17章 工具应用实操（launch 与 rosbag2）

launch 一次启动/管理一组节点；rosbag2 把话题数据录制到磁盘并可回放。本章完成两者的命令行与编程（C++/Python）实现。

本章对应代码：code/ws01_plumbing/src/cpp01_launch、py01_launch、cpp02_rosbag2。

17.1 launch 之 Python 实现

17.1.1 案例以及案例分析

需求：用 Python 编写 launch 文件，一次启动两只乌龟（节点名分别为 t1/t2）；随后以 XML、YAML 两种格式重写同一需求，体会三种格式的等价性。

17.1.2 实现

cpp01_launch/launch/py/py01_helloworld_launch.py：

from launch import LaunchDescription
from launch_ros.actions import Node


def generate_launch_description():
    t1 = Node(package="turtlesim", executable="turtlesim_node", name="t1")
    t2 = Node(package="turtlesim", executable="turtlesim_node", name="t2")
    return LaunchDescription([t1, t2])

XML 版（launch/xml/xml01_helloworld_launch.xml）：

<launch>
    <node pkg="turtlesim" exec="turtlesim_node" name="t1"/>
    <node pkg="turtlesim" exec="turtlesim_node" name="t2"/>
</launch>

YAML 版（launch/yaml/yaml01_helloworld_launch.yaml）：

launch:
- node:
    pkg: turtlesim
    exec: turtlesim_node
    name: t1
- node:
    pkg: turtlesim
    exec: turtlesim_node
    name: t2

注意：ros2 launch <包> <文件> 的第二个参数是文件名（launch 会递归搜索包的 share 目录），不要带子目录相对路径。

17.1.3 运行效果（实测）

ros2 launch cpp01_launch py01_helloworld_launch.py

[INFO] [turtlesim_node-1]: process started with pid [467494]
[INFO] [turtlesim_node-2]: process started with pid [467495]
[turtlesim_node-2] [INFO] [...]: Starting turtlesim with node name /t2

窗口弹出两只乌龟；ros2 node list 可见 /t1、/t2。XML 与 YAML 版输出相同。

17.2 rosbag2 之命令行与 C++ 编程实现

17.2.1 案例以及案例分析

需求：

  1. 命令行录制 /turtle1/cmd_vel 并回放；
  2. 编程实现：C++ 节点订阅 /turtle1/cmd_vel 写入磁盘文件（录制），再从文件读出消息打印（回放）。

17.2.2 C++ 实现要点

录制（cpp02_rosbag2/src/demo01_writer.cpp）：

// 3-1.创建一个录制对象；
writer_ = std::make_unique<rosbag2_cpp::Writer>();
// 3-2.设置被录制的文件；
writer_->open("ros2bag/demo01_bag");
// 3-3.订阅话题并在回调中写入；
sub_ = this->create_subscription<geometry_msgs::msg::Twist>("/turtle1/cmd_vel",10,
    std::bind(&SimpleBagRecorder::sub_callback,this,_1));
// 3-4.写入文件(注意传入消息本体而非智能指针)；
writer_->write(*msg,"/turtle1/cmd_vel",this->now());

回放（demo02_reader.cpp）：

reader_ = std::make_unique<rosbag2_cpp::Reader>();
reader_->open("ros2bag/demo01_bag");
while (rclcpp::ok() && reader_->has_next()) {
    auto msg = reader_->read_next<geometry_msgs::msg::Twist>();
    RCLCPP_INFO(this->get_logger(),"读取消息:(%.2f,%.2f)",msg.linear.x,msg.angular.z);
    rclcpp::sleep_for(std::chrono::milliseconds(200));
}
reader_->close();

兼容提示：

  • Writer::write() 需传入消息本体（*msg）；传智能指针会因模板推导出 shared_ptr<Twist> 而链接失败。
  • Jazzy 中 Reader::read_next<T>() 按值返回消息（msg.linear.x）；Humble 返回 shared_ptr（msg->linear.x）。
  • 同名 bag 目录已存在时 open() 会抛异常，重跑前先删除 ros2bag/demo01_bag。

17.3 本章小结

  • launch 三种格式等价，推荐 Python（可编程、可传参）；
  • rosbag2 底层存储为 mcap，命令行 ros2 bag record/play/info 覆盖大多数场景；
  • 编程接口 rosbag2_cpp::Writer/Reader 与命令行行为一致，注意 write(*msg) 解引用与不同发行版 read_next 返回值差异。
