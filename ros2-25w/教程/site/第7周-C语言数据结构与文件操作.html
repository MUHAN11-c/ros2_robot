7.2 知识点梳理

7.2.1 第1课 结构体深度剖析与应用

  • 核心概念：结构体（structure）用 struct 名字 { 成员; }; 把一组相关字段聚合成自定义类型，每个成员各占自己的内存。
  • memset 函数：memset(p, c, n) 把 n 字节填充为字节值 c，常用于 memset(&s, 0, sizeof(s)) 清零结构体/数组。注意：memset(&d, 0, sizeof(d)) 对 double 清零恰好成立（全 0 位就是 0.0），但 memset(&d, 1, ...) 不等于把 double 设为 1。
  • memcpy 函数：memcpy(dest, src, n) 拷贝 n 字节，要求源与目标不重叠；用于结构体/数组整体复制，比逐成员赋值快。
  • memmove 函数：同 memcpy 但允许内存重叠（内部有方向处理），同一缓冲区内搬移数据（如环形缓冲、数组左移）必须用 memmove。
  • memcmp 函数：按字节比较 n 字节，返回 0 相等、<0/>0 表大小序；可比较结构体字节（前提是没有 padding 未初始化问题，建议先 memset 清零）。
  • 结构体定义和赋值 01 / 02：定义后可用 s.x = 1; 逐成员赋值，或用初始化列表 struct Point p = {1, 2};（C99 支持指定初始化 .x = 1）；同类型结构体可整体赋值 a = b;（逐字节拷贝）。
  • 结构体嵌套：成员可以是另一个结构体（如 struct Robot { struct Pose pose; struct Battery bat; };），访问链式 r.bat.voltage。嵌套是把简单类型组装成复杂数据模型的基本手段。
  • 了解结构体空间大小：成员大小之和 ≠ sizeof(struct)，因为内存对齐（alignment）：成员按自身大小对齐，尾部可能有填充字节。可 #pragma pack(1) 或 __attribute__((packed)) 取消对齐（通信协议用），但会牺牲访问性能。
  • 结构体数组：struct Student stu[3] 即同类型记录的集合，遍历 stu[i].score；配合排序就是小型数据库。
  • 结构体变量交换：用临时结构体整体交换（tmp = a; a = b; b = tmp;）或 memcpy，比逐成员交换简洁；冒泡排序中交换的就是结构体。
  • 结构体成员为指针：如 struct { char *name; int *buf; }，指针成员指向的内存需单独分配/释放——结构体整体 free 不会释放成员指针，这是内存泄漏高发点。
  • 结构体为指针：struct Student *p = &s; 访问成员用 p->score（等价 (*p).score）；传结构体指针而非整个结构体，可避免大对象拷贝。
  • 堆空间创建结构体 / 方式改写排序案例：struct Student *p = (struct Student *)malloc(n * sizeof(struct Student)); 动态数组；排序时交换的指针或用 p[i] 下标访问。适合数量运行时才确定的场景（如读文件得到记录数）。
  • 结构体赋值：同类型整体赋值是浅拷贝——若成员含指针，两个结构体共享同一块指针内存，free 一个会影响另一个。
  • 值传递，形参不影响实参的值：void f(struct Student s) 传的是副本，修改不影响外部，且大结构体拷贝开销大。
  • 地址传递，修改同一块内存空间：void f(struct Student *s) 传指针，s->score = 100 直接改原对象，效率高，是工程默认做法；只读参数加 const。

7.2.2 第2课 联合体特性及实际应用

  • 核心概念：联合体（union，共用体）所有成员共享同一块内存，sizeof 取最大成员大小；同一时刻只有一个成员有效。
  • 结构体数组做函数参数：void sort(struct Student a[], int n)（退化为指针）或 void f(struct Student *a, int n)，配合 const 表示只读遍历。
  • const 修饰结构体指针：void print(const struct Student *s)——保证函数不修改数据，同时传指针避免拷贝；这是只读接口的标准声明。
  • 联合体共用体：典型用途① 节省内存的互斥字段；② 类型双关（type punning）查看字节表示，如把 float 的 4 字节按 unsigned char[4] 读出；③ 变体记录（tagged union）：结构体里放 type 枚举 + union，用枚举标记当前有效成员——协议解析常用。
  • 枚举：enum Color { RED, GREEN, BLUE }; 默认从 0 递增（可显式赋值），本质是整型常量；用枚举替代魔法数字表达状态（enum State { IDLE, RUN, ERROR }），可读且便于 switch。
  • 标准输入、输出和关闭：stdin / stdout / stderr 是三个预定义 FILE *；fprintf(stderr, ...) 输出错误信息，fclose 关闭自己 fopen 的流；进程退出时标准流自动关闭，但自己打开的文件必须显式 fclose。

7.2.3 第3课 文件操作原理与实战

  • 核心概念：文件 = 字节序列；按内容分文本文件（人可读，行结束符 \n）与二进制文件（内存原样，如图像、点云、结构体转储）。所有文件 IO 通过 FILE * 流（stream）+ 缓冲区完成。
  • 文件分类 / 文件指针和普通指针区别：FILE *fp 是指向「文件结构体」的不透明指针，内部带缓冲区、文件位置指针、错误标志；不能像普通指针那样解引用取内容。
  • 文件打开和关闭 / 实现：fopen("data.txt", "r") 成功返回 FILE *、失败返回 NULL（必须检查）；常用模式 "r" 读、"w" 写（清空重建）、"a" 追加、"rb/wb/ab" 二进制、"r+" 读写。用完 fclose(fp)，返回 0 成功。
  • 相对路径：相对当前工作目录（./a.txt、../data/a.txt），绝对路径以 / 开头（Linux）。ROS2 节点的工作目录由启动方式决定，工程上优先用包路径拼接（ament_index）而非裸相对路径。
  • fputc 函数 / fputc 练习：fputc(ch, fp) 写一个字符，返回写入字符或 EOF；练习常做「写 a-z 到文件」「文件加密（每个字符 +1）」。
  • fgetc 函数：fgetc(fp) 读一个字符，返回 int（0-255 或 EOF）；循环读到 EOF 为止是逐字符处理的标准写法。
  • feof 函数：feof(fp) 判断是否已读到文件末尾标志；正确用法是「先读后判」——只有读操作返回 EOF 后 feof 才为真，不能用它作读取前的循环条件，否则多处理一次。
  • 按行写入 / 按行读取：fputs(str, fp) 写字符串（不含 \n 需自行补），fgets(buf, size, fp) 读一行（保留 \n，遇 EOF 返回 NULL）——按行处理文本配置/CSV 的标准组合。
  • fprintf 函数 / fscanf 函数：格式化写/读，语法与 printf/scanf 一致但多了 FILE *：fprintf(fp, "%d %s\n", id, name)、fscanf(fp, "%d,%f", &id, &v)。适合生成与解析 CSV/文本配置。
  • fwrite 函数 / fread 函数：块读写——fwrite(ptr, size, count, fp)、fread(ptr, size, count, fp)，返回成功读写的块数；可直接把结构体数组写成二进制文件（注意字节序与对齐，跨平台有风险）。存取点云、地图、模型权重都用这对函数。
  • 文件拷贝案例：源文件 fread 读块 → 目标文件 fwrite 写块，循环直到读到 0 块；二进制模式 "rb"/"wb" 可拷贝任意文件（图像、可执行文件）。
  • 随机读取：fseek(fp, 偏移, 起点)（起点 SEEK_SET/SEEK_CUR/SEEK_END）、ftell(fp) 返回当前位置、rewind(fp) 回到开头；可实现「按记录号随机访问」——第 N 条记录偏移 = N * sizeof(struct)。
  • 文件总大小：fseek(fp, 0, SEEK_END); long size = ftell(fp);，或 stat（见下）。
  • 同一个文件读取和写入：读写混合时，fread/fwrite 之间必须插入 fseek 或 fflush 切换方向（C 标准要求），否则缓冲区状态混乱导致数据错位。
  • 了解 Windows 和 Linux 文本区别：Windows 行结束 \r\n（CR+LF），Linux \n（LF）；用 "rb" 读 Windows 文本会多出 \r，处理时需剔除。git 的 autocrlf 设置与此相关。
  • stat 方式获取文件大小：#include <sys/stat.h>，struct stat st; stat("a.txt", &st); st.st_size; 不用打开文件即可得大小与修改时间。
  • 重命名和删除：rename("old.txt", "new.txt")、remove("a.txt")（<stdio.h>），返回 0 成功、非 0 失败（可用 perror 打原因）。
  • 文件缓冲区：C 的 stdio 是带缓冲的（全缓冲/行缓冲/无缓冲）；fprintf 先写进用户缓冲，fflush(fp) 或 fclose 时才真正落盘。stderr 无缓冲保证错误信息即时；断电丢数据问题通常源于「没 fclose/fflush」。子进程 fork 后 _exit 会丢缓冲（exit 会刷新）。

7.3 重点与难点

  1. 结构体内存对齐：sizeof(struct) 不等于成员之和；通信协议、二进制文件、与硬件共享内存时，对齐/packing 不一致会导致数据错位。用 offsetof（<stddef.h>）可查成员偏移。
  2. 浅拷贝与指针成员：结构体整体赋值/memcpy 只复制指针值不复制指向内容；两个结构体共享指针成员时 free 有 double-free 风险。
  3. feof 的正确姿势：先 fgets/fread 返回失败再查 feof(fp)；用 while (!feof(fp)) 作读循环是经典错误（最后一次记录被重复处理）。
  4. 缓冲区与数据落盘：写完不 fclose/fflush，崩溃/断电就丢数据；随机读写时读写方向切换要 fseek/fflush。
  5. 联合体的「当前有效成员」纪律：union 读出的是最后写入的成员，必须用枚举标记当前状态（tagged union），否则必然读脏数据。

注意： fread/fwrite 的返回值是块数而不是字节数；fopen 返回值一定要判 NULL；写二进制结构体文件要考虑字节序（x86 小端）与对齐，跨机器交换数据建议序列化为文本或显式字节序。

7.4 代码与命令实战

场景 1：结构体数组排序（冒泡 + 整体交换 + 内存对齐观察）（对应第1课）

/* student.c —— 结构体数组按成绩排序，观察 sizeof 与对齐 */
#include <stdio.h>
#include <string.h>

struct Student {
    int id;
    char name[16];
    double score;      /* double 按 8 字节对齐，前面会出现填充 */
};

int main(void)
{
    struct Student s[3] = {
        {1, "alice", 88.5},
        {2, "bob",   95.0},
        {3, "carol", 72.5}
    };
    printf("sizeof(struct Student) = %zu\n", sizeof(s[0]));  /* 含填充字节 */

    for (int i = 0; i < 2; i++)                    /* 冒泡排序 */
        for (int j = 0; j < 2 - i; j++)
            if (s[j].score < s[j + 1].score) {     /* 降序 */
                struct Student tmp = s[j];         /* 结构体整体交换 */
                s[j] = s[j + 1];
                s[j + 1] = tmp;
            }

    for (int i = 0; i < 3; i++)
        printf("%d %-8s %.1f\n", s[i].id, s[i].name, s[i].score);
    return 0;
}

gcc -Wall student.c -o student && ./student

场景 2：结构体指针 + const 只读接口 + 堆上结构体数组（对应第1课「堆空间创建结构体」）

/* robot.c —— 堆上结构体数组、地址传递、const 保护 */
#include <stdio.h>
#include <stdlib.h>

struct Pose { double x, y, yaw; };

void print_pose(const struct Pose *p)     /* const：承诺不修改 */
{
    printf("x=%.2f y=%.2f yaw=%.2f\n", p->x, p->y, p->yaw);
}

void move(struct Pose *p, double dx, double dy)   /* 地址传递：改原对象 */
{
    p->x += dx;
    p->y += dy;
}

int main(void)
{
    int n = 2;
    struct Pose *path = (struct Pose *)malloc(n * sizeof(struct Pose));
    if (path == NULL) return 1;
    path[0] = (struct Pose){0.0, 0.0, 0.0};   /* C99 指定初始化 */
    path[1] = (struct Pose){1.0, 0.0, 1.57};

    move(&path[0], 0.5, 0.25);
    for (int i = 0; i < n; i++) print_pose(&path[i]);
    free(path);
    path = NULL;
    return 0;
}

gcc -Wall robot.c -o robot && ./robot

场景 3：联合体 + 枚举的 tagged union（对应第2课）

/* sensor.c —— 枚举标记 + 联合体存互斥数据，模拟传感器读数 */
#include <stdio.h>

enum Kind { LIDAR, IMU };          /* 枚举表达状态/类型 */

struct Reading {
    enum Kind kind;                /* 标记当前有效成员 */
    union {
        double range;              /* 激光：距离 */
        double accel[3];           /* IMU：三轴加速度 */
    } data;                        /* 共享同一块内存 */
};

int main(void)
{
    struct Reading r;
    r.kind = LIDAR;
    r.data.range = 3.25;

    if (r.kind == LIDAR)
        printf("lidar range = %.2f m\n", r.data.range);
    else
        printf("imu accel = %.2f\n", r.data.accel[0]);

    r.kind = IMU;                  /* 切换有效成员后再写 */
    r.data.accel[0] = 0.0;
    r.data.accel[1] = 9.81;
    r.data.accel[2] = 0.0;
    printf("imu ay = %.2f, union 大小 = %zu\n", r.data.accel[1], sizeof(r.data));
    return 0;
}

gcc -Wall sensor.c -o sensor && ./sensor

场景 4：文本文件读写 + feof 正确用法（对应第3课「按行读取 / fprintf / fscanf」）

/* logio.c —— 写配置、逐行读回，演示先读后判 EOF */
#include <stdio.h>
#include <string.h>

int main(void)
{
    /* 写：fprintf 格式化输出 */
    FILE *fp = fopen("config.txt", "w");
    if (fp == NULL) { perror("fopen"); return 1; }   /* 打印失败原因 */
    fprintf(fp, "wheel_radius,%.3f\n", 0.050);
    fprintf(fp, "max_speed,%d\n", 30);
    fclose(fp);                       /* 关闭即落盘 */

    /* 读：fgets 逐行，读失败后再判 feof */
    fp = fopen("config.txt", "r");
    if (fp == NULL) { perror("fopen"); return 1; }
    char line[128];
    while (fgets(line, sizeof(line), fp) != NULL) {   /* 先读 */
        line[strcspn(line, "\n")] = '\0';             /* 去行尾换行 */
        printf("读到: [%s]\n", line);
    }
    if (feof(fp))  puts("-- 到达文件末尾 --");          /* 后判 */
    fclose(fp);
    return 0;
}

gcc -Wall logio.c -o logio && ./logio

场景 5：二进制读写 + 文件拷贝 + 随机读取（对应第3课「fwrite/fread/文件拷贝/随机读取」）

/* binfile.c —— 结构体数组写二进制文件，随机读第 k 条，并拷贝文件 */
#include <stdio.h>
#include <stdlib.h>

struct Rec { int id; double value; };

int main(void)
{
    struct Rec out[3] = { {1, 1.5}, {2, 2.5}, {3, 3.5} };
    struct Rec in;

    FILE *fp = fopen("data.bin", "wb");           /* 二进制写 */
    if (fp == NULL) { perror("fopen"); return 1; }
    fwrite(out, sizeof(struct Rec), 3, fp);       /* 块写：块数=3 */
    fclose(fp);

    fp = fopen("data.bin", "rb");
    if (fp == NULL) { perror("fopen"); return 1; }

    /* 随机读取：定位到第 2 条（下标 1） */
    fseek(fp, 1L * sizeof(struct Rec), SEEK_SET);
    if (fread(&in, sizeof(struct Rec), 1, fp) == 1)   /* 块读返回块数 */
        printf("随机读第2条: id=%d value=%.1f\n", in.id, in.value);

    /* 文件总大小 */
    fseek(fp, 0, SEEK_END);
    printf("data.bin 总大小 = %ld 字节\n", ftell(fp));
    fclose(fp);

    /* 通用文件拷贝（二进制块搬运） */
    FILE *src = fopen("data.bin", "rb");
    FILE *dst = fopen("copy.bin", "wb");
    if (src == NULL || dst == NULL) { perror("fopen"); return 1; }
    char buf[1024];
    size_t n;
    while ((n = fread(buf, 1, sizeof(buf), src)) > 0)  /* 读到 0 块结束 */
        fwrite(buf, 1, n, dst);
    fclose(src);
    fclose(dst);
    printf("拷贝完成\n");
    return 0;
}

7.6 端到端实战（实测）：成绩文件流水线

完整闭环：生成源文件 → fgets+sscanf 读入结构体数组 → 冒泡降序 → 写回 sorted.txt。

/* sort_scores.c（节选） */
struct Student { char name[32]; double score; };

/* 1.生成源数据 */
FILE *fp = fopen("scores.txt", "w");
fprintf(fp, "alice,88.5\nbob,95\ncarol,72.5\ndave,81\n");
fclose(fp);

/* 2.读入结构体数组（先读后判 EOF） */
while (fgets(line, sizeof(line), fp) != NULL && n < 8) {
    line[strcspn(line, "\n")] = '\0';
    if (sscanf(line, "%31[^,],%lf", stu[n].name, &stu[n].score) == 2) n++;
}

/* 3.冒泡降序（结构体整体交换） */
if (stu[j].score < stu[j + 1].score) {
    struct Student tmp = stu[j]; stu[j] = stu[j + 1]; stu[j + 1] = tmp;
}

/* 4.写回 */
for (int i = 0; i < n; i++) fprintf(fp, "%s,%.1f\n", stu[i].name, stu[i].score);

7.7 与 ROS2 / 机器人开发的关联

  1. 结构体 = 消息类型（msg）的 C 原型：geometry_msgs/Pose、sensor_msgs/LaserScan 等消息生成到 C/C++ 就是结构体（C 中 geometry_msgs__msg__Pose）。理解成员布局、内存对齐、指针成员，才能理解 DDS 序列化、消息数组为何要预分配，以及为什么传消息用 SharedPtr 而不是值拷贝。
  2. 联合体/枚举 ↔ 机器人状态与变体数据：传感器多模式（激光/超声互斥数据）、导航状态机（IDLE/NAVIGATING/CHARGING）、协议中「类型 + 载荷」的 tagged union 模式，都直接使用本周的 enum/union 手法。
  3. 文件 I/O ↔ rosbag 与配置读写：rosbag 本质是二进制记录文件；YAML 参数文件的加载、导航地图（PGM/二进制栅格）、标定结果、日志落盘，全是 fopen + fread/fwrite/fprintf 的应用形态；stat 获取文件大小对应地图加载前的完整性检查。
  4. 随机读取 ↔ 大数据文件索引：对点云包、轨迹文件按 sizeof(Record) 定位第 N 条，是 rosbag 索引（index）的朴素原理；fseek/ftell 用于「先读头部取数量、再定位数据段」。
  5. 缓冲区与可靠性：机器人长时间运行时，日志/数据记录若不 fflush，崩溃会丢最后一段数据；理解 stdio 缓冲机制才能设计可靠的记录器（logger），这也是 rcutils 日志要显式 flush 的原因。
  6. memset/memcpy ↔ 消息与传感器缓冲：清零 LaserScan.ranges 数组、拷贝图像帧缓冲、重置 IMU 数据结构，用的都是这四个内存函数；注意 memmove 处理重叠与 packed 结构体的字节序。

7.8 自测与练习（含参考答案要点）

  1. 解释 struct { int a; char b; double c; } 在 64 位 Linux 下为什么 sizeof 大于 13 字节，并说明 #pragma pack(1) 的利弊。
  2. 编程题：定义 struct Point { double x, y; }，实现 double dist(const struct Point *a, const struct Point *b)（只读参数用 const），计算两点距离（验收：(0,0) 与 (3,4) 得 5.0）。
  3. 编程题：把结构体数组写入二进制文件，再随机读取第 k 条打印（验收：写 3 条读第 2 条，内容一致）。
  4. 动手任务：写一个程序把成绩文本文件（每行 姓名,分数）读入结构体数组，按分数降序排序后写回 sorted.txt（验收：输出文件有序、fclose 前后对比内容不丢）。

参考答案要点：① 成员按对齐规则排布（int 4 + char 1 + 填充 3 + double 8 = 16 字节），pack(1) 消除填充省内存但访问变慢、跨平台协议才有必要；② sqrt((a->x-b->x)*(a->x-b->x) + (a->y-b->y)*(a->y-b->y))，记得 #include <math.h> 并 -lm 链接；③ fwrite(arr, sizeof(struct), n, fp) 写，fseek(fp, k*sizeof(struct), SEEK_SET) + fread 读，检查返回块数；④ fgets 读行 → sscanf(line, "%[^,],%lf", name, &score) 解析 → 冒泡排序 → fprintf 写回；注意先 fclose 或 fflush 再验证文件内容。

7.9 常见问题（FAQ）

  • Q：memcpy 和 memmove 该用哪个？ A：能确定不重叠用 memcpy（可能更快），同一缓冲区内部搬移（dst 在 src 范围内）必须 memmove，用错是未定义行为。
  • Q：struct 能直接比较 == 吗？ A：C 不支持结构体整体 ==/!=（C++ 可重载运算符），需逐成员比较或用 memcmp（注意 padding 未初始化内容会造成误判，先 memset 清零）。
  • Q：fopen 失败怎么排查？ A：返回 NULL 时用 perror("fopen") 或 strerror(errno) 打印原因，常见是路径不对（相对路径相对「当前工作目录」）或权限不足。
  • Q：二进制文件能跨机器读吗？ A：风险较高——字节序（大端/小端）、结构体对齐、sizeof(long) 平台差异都会导致不兼容；跨平台交换建议用文本格式（JSON/CSV/YAML）或显式序列化协议。
  • Q：union 里存完 A 再读 B 会怎样？ A：读到的是同一块内存按 B 的类型解释的脏数据；必须用枚举/标志记录「当前写入的是哪个成员」（tagged union）。

7.10 本章小结

  • 结构体 = .msg 消息的 C 原型；理解对齐与指针成员才能理解 DDS 序列化与消息 SharedPtr；
  • tagged union（枚举 + 联合体）是机器人状态与变体数据的通用手法；
  • feof 先读后判、fread/fwrite 返回块数、fopen 判 NULL——文件三纪律；
  • rosbag 二进制记录、YAML/地图/日志落盘全是 fopen + fread/fwrite/fprintf 的应用形态；
  • 长时间运行的节点若日志不 fflush，崩溃会丢最后一段数据——缓冲区机制决定记录器设计。
