6.2 知识点梳理

6.2.1 第1课 函数的综合应用与多文件编程

  • 核心概念：函数（function）= 命名的代码块，把「做什么」封装成可复用单元；C 程序 = 若干函数，main 是入口。
  • scanf 获取带空格的字符：scanf("%[^\n]", buf)（正则风格扫描集）可读入含空格的一行，记得配合 getchar() 清掉换行；或直接用 fgets。
  • gets 输入：gets(buf) 能读带空格的整行但不做长度检查，C11 已从标准库删除，禁止使用。
  • fgets 函数：fgets(buf, size, stdin) 读入至多 size-1 个字符并保留换行符 \n、自动补 \0，是安全读行的标准答案。注意返回的字符串末尾可能带 \n，常用 strcspn/手工去掉。
  • puts 函数 / fputs 函数：puts(s) 输出字符串并自动追加换行；fputs(s, stdout) 不加换行、可指定输出流。二者都比 printf("%s") 轻量。
  • strlen 函数：strlen(s) 返回到 \0 之前的字符数（不含 \0），类型 size_t；与 sizeof 语义完全不同（见第5周）。
  • 字符串拼接：手工实现 dest 末尾接 src——先用指针/下标找到 dest 的 \0，再逐字符拷贝 src（含 \0）。这是 strcat 的原理，注意目标缓冲区必须足够大。
  • 函数的作用和分类：库函数（printf/strlen 等标准库提供）与自定义函数；有返回值函数与 void 函数；无参函数 void f(void)。函数的价值：复用、模块化、隐藏细节、便于测试。
  • 系统函数调用的总结：system() 调 shell、exit() 退出进程、库函数最终可能陷入内核（如 write）。C 的「系统调用」语境下这些封装函数是上层入口。
  • 函数的定义 / 执行流程：返回类型 函数名(参数列表) { 函数体 }。调用时实参值拷贝给形参（值传递），遇 return 返回调用点；函数内变量在栈上，返回后销毁。递归（函数调用自己）也在此建立：要有终止条件。
  • 函数声明：函数先使用后定义时，需在前面写原型声明（如 int add(int a, int b);），通常放进 .h 头文件。声明不分配内存，定义才分配。
  • exit 函数：exit(0) 正常终止整个进程，exit(非0) 表示异常；atexit() 可注册退出回调。与 return 不同，exit 可在任意函数中终止程序。子进程中 _exit / exit 的缓冲区差异在第7周文件缓冲区展开。
  • 多文件编程：把声明放 xxx.h、实现放 xxx.c，主程序 main.c 通过 #include "xxx.h" 使用；编译：gcc main.c xxx.c -o app（多 .c 同时编译链接）。这是 ROS2 包 include/ + src/ 结构的原型。
  • 防止头文件重复包含：#ifndef _XXX_H_ / #define _XXX_H_ ... #endif（守卫宏）或 #pragma once。否则重复包含会报重定义错误。

6.2.2 第2课 指针原理与操作

  • 核心概念：指针（pointer）= 存放内存地址的变量。int *p = &a; 中 p 存 a 的地址，*p 读写 a 本身——「间接访问」是 C 的核心能力。
  • 指针和指针变量 / 解引用、间接引用：& 取地址、* 解引用。*p = 100; 直接改写 a 的值。指针变量自身也有地址（&p），为多级指针铺垫。
  • 间接修改变量：函数想修改调用方的变量，必须传地址（void set(int *p) { *p = 5; }），这叫地址传递——ROS2/C++ 的引用参数同一原理。
  • 指针类型占用空间：64 位系统指针一律 8 字节（与指向类型无关），32 位系统 4 字节；指针类型决定 p+1 跳多少字节、解引用读多少字节。
  • 野指针：未初始化或已释放后仍使用的指针，指向随机地址，解引用常导致段错误或静默踩内存。对策：声明即初始化为 NULL，释放后置 NULL。
  • 空指针：NULL（(void*)0）表示「不指向任何对象」，解引用 NULL 必然崩溃；使用前判 if (p != NULL)。ROS2 中 nullptr 检查同理。
  • 万能指针、泛型指针：void *p 可接收任意类型指针，但不能直接解引用/算术（不知步长），使用前需强转回具体类型。malloc 返回 void *、memcpy 参数都是 void *。
  • const 修饰变量：const int a = 1; 不可直接改值。
  • const 修改指针变量：三种形态——const int *p（不能通过 p 改值，p 可改指向）、int * const p（p 不可改指向，可改值）、const int * const p（都不可）。口诀：const 修饰其后最近的成分。
  • 数组名不允许修改：a 是常量地址（a = a + 1 非法），但 a[i] 可改；把数组传参时退化为普通指针后可移动。
  • 指针取数组元素 / 指针加法 / 指针循环遍历数组：p[i] == *(p+i)；p+1 跳过一个元素（sizeof(*p) 字节）；遍历常用 for (int *p = a; p < a + n; p++) sum += *p;。
  • 指针写入和读取数组练习：用指针向数组写入 0..n-1 再读出打印，熟悉 *p 与 p[i] 互换。
  • 指针减法 / 数组名的地址加一 / 指针与指针的运算 / 数组指针之间的运算：同类型指针相减得元素个数（p2 - p1，不是字节数），如 int *p = &a[2]; p - a == 2；&a + 1 跳过整个数组（类型是数组指针 int (*)[N]）。
  • 利用数组指针获取元素个数：(int)(end - begin) 求元素数，是 C++ 迭代器区间 [begin, end) 的雏形。
  • mystrlen 函数 / 指针实现 mystrlen 函数：while (*p != '\0') { p++; len++; } 或 while (*p++) len++;——字符串遍历的标准手势，也是理解 C 字符串以 \0 结尾的最佳练习。
  • 指针的比较运算：指向同一数组的指针可 <、>、== 比较（比较地址顺序）；指向不同对象的指针比较无意义。p != NULL 最常用。
  • 指针数组：int *arr[5] 是「数组，元素为指针」，如 char *names[] = {"ros2", "rcl"};（存字符串字面量地址）；与「数组指针」int (*p)[5] 类型完全不同，注意括号优先级。
  • 多级指针：int **pp = &p;，**pp 是 a。二级指针用于「函数内修改外部指针变量」（如 malloc 分配后返回）——char **argv 就是多级指针。
  • 指针值传递 01 / 02：void f(int *p) 把指针本身的值复制给形参，形参指向改了不影响实参指向（p = NULL 不影响外部）。
  • 指针地址传递：传 &p（int **）才能让函数修改外部指针的指向；这是「申请堆内存并在函数内返回」的标准范式。

6.2.3 第3课 字符串处理函数应用

  • 核心概念：C 字符串 = char * 指向的以 \0 结尾的字节序列；<string.h> 提供一整套字符串函数，配合指针使用。
  • 数组名当参数传递细节：数组传参退化为 char *，函数内 sizeof 得到的是指针大小；长度必须另传参数（void f(char *s, size_t len)）。
  • 指针作为函数返回值：可返回指向静态区/堆/调用方缓冲区的指针，不可返回局部变量地址（函数返回后栈帧销毁）——经典悬垂指针 bug。
  • 指针字符串：char *s = "hello"; 指向只读字面量（改它会段错误），char s[] = "hello"; 是可改的栈上副本；要修改字符串用数组或堆内存。
  • 自制复制字符串函数 01 / 02：mystrcpy(dest, src)：while ((*d++ = *s++) != '\0'); 或显式循环，注意 dest 容量与 '\0' 收尾。
  • 自制去除空格函数 01 / 02：trim 逻辑——跳过开头空格、拷贝中间内容、截掉尾部空格；可用双指针原地完成（读指针与写指针分离），用于解析配置行。
  • main 函数的参数：int main(int argc, char *argv[])，argc 是参数个数、argv[i] 是第 i 个参数字符串（argv[0] 为程序名）。./app --input a.txt 的解析就靠它——对应 ros2 run pkg node --ros-args。
  • strstr 函数：strstr(hay, needle) 返回子串首次出现的地址，找不到返回 NULL；strstr(p+1, ...) 可继续找下一个。
  • 统计字符串中子串出现的次数：循环 p = strstr(p, sub) 命中后 count++; p += strlen(sub);（或 p++ 计重叠）。
  • 字符串反转 / 判断回文字符串：反转用首尾双指针交换；回文判断反转后与原串 strcmp 相等或双指针向中间扫描比较。
  • strcpy / strncpy：strcpy(dest, src) 含 \0 全拷贝、不检查容量；strncpy(dest, src, n) 最多 n 字符，src 超长时不补 \0，需手工补。
  • strcat / strncat：末尾追加；strncat(dest, src, n) 追加后保证 \0。务必保证 dest 有足够空间。
  • strcmp / strncmp：逐字符比较 ASCII，返回 0 相等、<0 前小、>0 后小；strncmp 只比前 n 个。比较字符串不能用 ==（那是地址比较）。
  • sprintf / sscanf：sprintf(buf, "x=%.2f", x) 格式化写入字符串；sscanf(line, "%d,%f", &i, &f) 从字符串解析——解析 CSV/配置行的利器（比 scanf 更常用于解析传感器文本协议）。
  • strchr / strrchr：找字符首次/最后出现位置，返回 char * 或 NULL；常用于拆路径、找分隔符。
  • strtok / strtok 练习：strtok(buf, ",") 按分隔符切词，首次传 buf、后续传 NULL，内部静态状态不可重入（多线程用 strtok_r）。切 CSV、解析命令行参数常用。
  • atoi、atof、atol：字符串转 int/double/long，不检查合法性（失败返回 0），严肃场景用 strtol/strtod（可检测溢出与剩余字符）。
  • 求字符串中非空格的元素个数：遍历统计 c != ' ' 的个数，配合 isspace（<ctype.h>）处理 \t \n。

6.2.4 第4课 内存管理

  • 核心概念：变量的可见范围（作用域）、存活时间（生命周期）、所处内存区域（四分区），三者共同决定内存安全。
  • 作用域：局部变量只在 {} 内有效；块作用域、函数原型作用域、文件作用域（全局）三层。
  • 全局变量 / 静态全局变量：全局变量在整个文件（跨文件需 extern 声明）可用、程序启动到结束都活着；static 修饰全局变量把作用域限制在本文件（模块私有），避免命名冲突——多文件工程必备。
  • static 静态局部变量：函数内 static int cnt = 0; 只初始化一次、函数退出后值保留、生命周期与程序一致（存放在数据段而非栈）；适合计数器、缓存。注意它不是线程安全的。
  • 静态函数：static void helper(void) 限定函数只在本文件可见，是 C 实现「私有函数」的唯一手段；头文件里只放对外接口。
  • 内存四分区：① 代码段（text，只读指令与字面量）② 数据段（全局/static 变量、static 初始化）③ 栈（stack，局部变量、函数调用，自动管理、空间有限约 MB 级）④ 堆（heap，malloc 手动管理，空间大、速度稍慢）。理解四分区才能解释「返回局部变量地址」为什么错。
  • 生命周期：栈变量随函数返回销毁；全局/static 从程序开始到结束；堆块从 malloc 到 free（不 free 就泄漏）。
  • 申请堆空间：malloc(n) 分配 n 字节不初始化、calloc(n, size) 分配并清零、realloc 调整大小；返回 void *，失败返回 NULL——必须检查。典型用法 int *p = (int *)malloc(n * sizeof(int)); if (p == NULL) ...。
  • free 细节：free(p) 释放后 p 成野指针，应立即 p = NULL；重复 free 是灾难；free(NULL) 是安全空操作；谁申请谁释放。
  • 堆空间操作字符串：malloc(strlen(src)+1) 分配后 strcpy——比固定数组灵活，是 C 里动态字符串的标准做法。
  • 二级指针 malloc 空间：char **pp = (char **)malloc(n * sizeof(char *)); 再为每行 pp[i] = malloc(...) 分配，得到「可变长字符串数组」，释放时逐行 free 再 free(pp)。

6.3 重点与难点

  1. 指针的值传递 vs 地址传递：int *p 形参改不了实参的指向，int **pp 才能。这是 malloc 封装函数、双缓冲区管理的根基。
  2. 悬垂/野指针：返回局部变量地址、free 后继续使用、未初始化就解引用——三类错误的共同点是「指针指向的内存已不属于你」。
  3. 字符串函数的容量陷阱：strcpy/strcat 不检查长度、strncpy 不保证补 \0、strtok 不可重入。工程上应封装带长度的版本。
  4. 内存四分区与生命周期：背下来不如画出来：每道指针题画栈/堆/数据段草图再写代码。
  5. const 修饰指针的三种形态：const int * / int * const / const int * const，接口设计中大量使用（如 const char * 参数表「我只读不改」）。

注意： free(p) 后把 p = NULL 是纪律不是可选项；malloc 返回值不检查、释放后不置空、忘记释放，是 C 程序崩溃与内存泄漏的三大来源。工具 valgrind ./app 可以直接检测泄漏。

场景 1：多文件编程（头文件 + 实现 + 主程序）（对应第1课）

/* strutil.h —— 头文件守卫防止重复包含 */
#ifndef STRUTIL_H
#define STRUTIL_H

#include <stddef.h>

size_t mystrlen(const char *s);        /* 函数声明（原型） */
void   mystrcpy(char *dest, const char *src);

#endif

/* strutil.c —— 函数实现 */
#include "strutil.h"

size_t mystrlen(const char *s)
{
    const char *p = s;
    while (*p != '\0') p++;     /* 指针遍历到结尾 */
    return (size_t)(p - s);     /* 指针相减得字符数 */
}

void mystrcpy(char *dest, const char *src)
{
    while ((*dest++ = *src++) != '\0')   /* 拷含 '\0' */
        ;
}

/* main.c —— 调用多文件接口 */
#include <stdio.h>
#include "strutil.h"

int main(int argc, char *argv[])
{
    char buf[64];
    const char *msg = (argc > 1) ? argv[1] : "ros2 humble";
    mystrcpy(buf, msg);
    printf("buf = %s, len = %zu\n", buf, mystrlen(buf));
    return 0;
}

场景 2：指针遍历数组 + 指针相减求元素数（对应第2课）

/* ptr.c —— 指针算术与数组遍历 */
#include <stdio.h>

int main(void)
{
    int a[5] = {10, 20, 30, 40, 50};
    int *begin = a;            /* 数组名即首元素地址 */
    int *end   = a + 5;        /* 指向最后一个元素的下一位置 */

    for (int *p = begin; p < end; p++)
        printf("%d ", *p);     /* 解引用取值 */
    printf("\n元素个数 = %ld\n", (long)(end - begin));   /* 指针相减 */

    int **pp = &begin;         /* 二级指针：指向指针的指针 */
    printf("通过二级指针取 a[0] = %d\n", **pp);
    return 0;
}

场景 3：const 修饰指针 + 函数地址传递（对应第2课「指针地址传递」）

/* constptr.c —— const 三种形态与地址传递 */
#include <stdio.h>
#include <stdlib.h>

void fill(int **out, int n)        /* 二级指针：函数内改变外部指针 */
{
    *out = (int *)malloc(n * sizeof(int));   /* 分配堆空间 */
    for (int i = 0; i < n; i++) (*out)[i] = i * 10;
}

int main(void)
{
    const int *p1;           /* 不能通过 p1 改值，可改指向 */
    int * const p2 = NULL;   /* p2 指向不可改（const 靠近 p2） */
    (void)p1; (void)p2;

    int *arr = NULL;
    fill(&arr, 4);           /* 地址传递，arr 被填上堆指针 */
    for (int i = 0; i < 4; i++) printf("%d ", arr[i]);
    printf("\n");
    free(arr);               /* 用完释放 */
    arr = NULL;              /* 释放后置空，防野指针 */
    return 0;
}

场景 4：自制 trim + strtok + sscanf 解析 CSV 行（对应第3课）

/* parse.c —— 去空格、切词、解析一行配置 "wheel, 0.05, 30" */
#include <stdio.h>
#include <string.h>
#include <stdlib.h>

void trim(char *s)
{
    char *p = s, *q = s;
    while (*p == ' ') p++;                /* 跳过前导空格 */
    while (*p) *q++ = *p++;               /* 前移拷贝 */
    *q = '\0';
    size_t len = strlen(s);               /* 去尾部空格 */
    while (len > 0 && s[len - 1] == ' ') s[--len] = '\0';
}

int main(void)
{
    char line[128] = "  wheel, 0.05, 30   ";
    trim(line);
    printf("trim 后: [%s]\n", line);

    char name[32];
    double radius;
    int rpm;
    if (sscanf(line, "%31[^,], %lf, %d", name, &radius, &rpm) == 3)
        printf("解析结果: name=%s radius=%.2f rpm=%d\n", name, radius, rpm);

    char buf[128] = "10,20,30";
    int sum = 0;
    for (char *tok = strtok(buf, ","); tok != NULL; tok = strtok(NULL, ","))
        sum += atoi(tok);                 /* 字符串转整数 */
    printf("strtok 求和 = %d\n", sum);
    return 0;
}

gcc -Wall parse.c -o parse && ./parse

场景 5：堆上二维空间（二级指针 malloc）与释放（对应第4课）

/* heap2d.c —— 二级指针申请 n 行 m 列，逐行释放 */
#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    int n = 3, m = 4;
    int **grid = (int **)malloc(n * sizeof(int *));   /* 行指针数组 */
    for (int i = 0; i < n; i++)
        grid[i] = (int *)calloc(m, sizeof(int));      /* 每行 m 列，清零 */

    for (int i = 0; i < n; i++)                        /* 写入 */
        for (int j = 0; j < m; j++)
            grid[i][j] = i * 10 + j;

    for (int i = 0; i < n; i++) {                      /* 读出 */
        for (int j = 0; j < m; j++) printf("%2d ", grid[i][j]);
        printf("\n");
    }

    for (int i = 0; i < n; i++) free(grid[i]);  /* 先释放每行 */
    free(grid);                                 /* 再释放行指针数组 */
    grid = NULL;
    return 0;
}

gcc -Wall heap2d.c -o heap2d && ./heap2d
valgrind --leak-check=full ./heap2d   # 可选：检查内存泄漏

6.6 端到端实战（实测）：多文件编程 + trim + 堆字符串

三个源文件构成的小工程：strutil.h（接口声明 + 头文件守卫）、strutil.c（指针遍历实现 mystrlen/mystrcpy/trim/heap_strdup）、main6.c（命令行参数 + trim + 堆复制 + 释放）。

/* strutil.h（节选） */
#ifndef STRUTIL_H
#define STRUTIL_H
#include <stddef.h>
size_t mystrlen(const char *s);
void   mystrcpy(char *dest, const char *src, size_t cap);
void   trim(char *s);
char  *heap_strdup(const char *s);
#endif

/* strutil.c（节选）：指针遍历求长度、堆上复制 */
size_t mystrlen(const char *s) {
    const char *p = s;
    while (*p != '\0') p++;
    return (size_t)(p - s);          /* 指针相减 = 元素个数 */
}
char *heap_strdup(const char *s) {
    char *p = (char *)malloc(mystrlen(s) + 1);   /* 分配并判空 */
    if (p == NULL) return NULL;
    mystrcpy(p, s, mystrlen(s) + 1);
    return p;                        /* 调用方负责 free */
}

/* main6.c（节选）：argv 传参 + trim + 堆字符串 + free 后置空 */
char buf[64];
mystrcpy(buf, argv[1], sizeof(buf));
trim(buf);
char *heap = heap_strdup(buf);
printf("heap: [%s]\n", heap);
free(heap);
heap = NULL;

6.7 与 ROS2 / 机器人开发的关联

  1. 指针与内存模型直接对应 rclcpp：rclcpp 的 shared_ptr<Message>、unique_ptr、回调里的 const msg::SharedPtr &msg 都建立在「指针 + 堆 + 生命周期」之上；理解了 malloc/free 与悬垂指针，才能理解智能指针为什么存在、为什么 get() 要小心。
  2. 多文件编程 = ROS2 包的组织方式：ROS2 包的 include/<pkg>/xxx.hpp（声明）+ src/xxx.cpp（实现）+ CMake 目标链接，就是本周 .h/.c 模式 + gcc 多文件编译 的工程化版本；头文件守卫对应 #pragma once。
  3. 字符串函数贯穿 ROS2 CLI 与协议解析：解析串口 GPS 的 NMEA 语句（strtok/sscanf）、拼接 topic 名与 frame_id（snprintf 更安全）、从参数字符串取子串（strstr），全是本周函数族的直接应用。
  4. main 参数 = 节点启动参数：int main(int argc, char **argv) 正是 ROS2 节点入口签名，rclcpp::init(argc, argv) 就是对 argv 的解析；理解 argv 才能理解 --ros-args -p。
  5. 堆与生命周期决定机器人程序稳定性：点云、图像缓冲都在堆上分配；二级指针申请二维栅格（代价地图）是导航开发的常见操作；内存泄漏在长时间运行的 SLAM/导航节点中会累积成 OOM 崩溃，valgrind/ASan 是标准排障工具。
  6. static 与作用域：模块内共享状态（如标定参数缓存）用 static 文件内全局 + 接口函数封装，对应 C++ 类的静态成员与单例节点设计。

6.8 自测与练习（含参考答案要点）

  1. 用自己的话解释：为什么 int *p 形参无法改变外部指针的指向，而 int **pp 可以？画栈/堆草图说明。
  2. 编程题：实现 size_t mystrlen(const char *s) 与 char *mystrchr(char *s, char c)（返回字符首次出现地址或 NULL），并写测试（验收：mystrlen("ros2")==4）。
  3. 编程题：实现 trim(char *s) 并处理 " abc " → "abc"（验收：前导与尾随空格都去掉，中间空格保留）。
  4. 动手任务：用 malloc 生成 n 个整数的数组填入斐波那契数列，打印后 free，用 valgrind --leak-check=full ./app 验证 0 泄漏（验收：valgrind 输出 "All heap blocks were freed"）。

参考答案要点：① 值传递复制的是指针本身的值，形参 p 是新副本，改它不影响实参；传 &p 得 int **，*pp = ... 才写回实参所在内存；② while (*s) { s++; len++; } return len;，mystrchr 用 while (*s) { if (*s == c) return s; s++; } return NULL;；③ 用读写双指针或先 memmove 去前导、再从 \0 向前删尾空格；④ malloc(n*sizeof(int)) 后必须判 NULL，free(p); p = NULL;，valgrind 确认无 "definitely lost"。

6.9 常见问题（FAQ）

  • Q：char *s = "hello"; 和 char s[] = "hello"; 到底差在哪？ A：前者指针指向只读字面量区，s[0]='H' 会段错误；后者是栈上可写副本。要改字符串内容用数组或堆内存。
  • Q：malloc 后要不要强转 (int *)？ A：C 中 void * 隐式转任意指针，可不转（C++ 必须转）。显式转换有助于表达意图，两种风格在工程中都常见。
  • Q：strncpy 就一定安全吗？ A：不一定。src 长度 ≥ n 时 dest 不会被补 \0，之后用 %s 打印会越界读。复制后必须 dest[n-1] = '\0' 或用 snprintf。
  • Q：函数里 malloc 的内存，调用者怎么拿到？ A：返回该指针（return p;），或通过二级指针参数写回（void make(int **out)），并约定好由谁 free。

  • 指针 + 堆 + 生命周期是理解 rclcpp 智能指针（SharedPtr）的前提；

  • 字符串函数族贯穿 ROS2 命令行与协议解析（NMEA 语句、topic 名拼接）；
  • 多文件 .h/.c + 头文件守卫 = ROS2 包组织的原型；
  • 堆上二维数组（二级指针 malloc）就是导航代价地图的内存形态；free 后置空、valgrind 查泄漏是工程纪律。
