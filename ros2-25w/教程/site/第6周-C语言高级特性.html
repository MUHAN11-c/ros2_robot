第6章 C 语言高级特性（函数/指针/字符串/内存）

本章对应课程第 6 周：函数与多文件编程、指针原理与运算、字符串处理函数族、内存四分区与 malloc/free。本周建立阅读 rclcpp 源码所需的内存直觉。

6.1 案例以及案例分析

需求：解析一行机器人配置 wheel, 0.05, 30——去掉首尾空格、sscanf 拆字段、strtok 切词求和；并用指针遍历数组、二级指针理解地址传递。

6.2 知识点与实现

6.2.1 函数与多文件编程

  • 声明放 xxx.h（加 #ifndef 守卫或 #pragma once）、实现放 xxx.c、gcc main.c xxx.c -o app 多文件编译——ROS2 包 include/ + src/ 结构的原型；
  • 安全读行用 fgets(buf, size, stdin)（gets 已被标准删除）；
  • exit(非0) 任意函数处终止进程；递归要有终止条件。

6.2.2 指针

  • int *p = &a;，*p 解引用读写 a；64 位指针一律 8 字节，类型决定 p+1 步长；
  • 野指针三来源：未初始化、释放后使用、返回局部变量地址——声明即置 NULL、free 后置 NULL；
  • p[i] == *(p+i)；同类型指针相减得元素个数；const int *p（值不可改）/int * const p（指向不可改）；
  • void * 万能指针不能解引用；二级指针 int ** 用于「函数内修改外部指针」（malloc 封装的标准范式）。

6.2.3 字符串函数族

  • strlen（到 \0 为止）≠ sizeof（容量）；strcpy/strcat 不查长度、strncpy 不保证补 \0、strcmp 为 0 即相等；
  • strstr 找子串、strtok 切词（不可重入，多线程用 strtok_r）、sprintf/sscanf 格式化互转、atoi（失败返回 0，严肃场景用 strtol）；
  • int main(int argc, char *argv[]) 就是 ros2 run pkg node --ros-args 的入口签名。

6.2.4 内存管理

  • 内存四分区：代码段/数据段/栈/堆；static 局部变量只初始化一次、static 全局/函数限定本文件可见；
  • malloc/calloc/realloc 必须判 NULL；free 后置空；谁申请谁释放；valgrind --leak-check=full 查泄漏。

6.4 端到端实战（实测）：多文件编程 + trim + 堆字符串

三个源文件构成的小工程：strutil.h（接口声明 + 头文件守卫）、strutil.c（指针遍历实现 mystrlen/mystrcpy/trim/heap_strdup）、main6.c（命令行参数 + trim + 堆复制 + 释放）。

/* strutil.h（节选） */
#ifndef STRUTIL_H
#define STRUTIL_H
#include <stddef.h>
size_t mystrlen(const char *s);
void   mystrcpy(char *dest, const char *src, size_t cap);
void   trim(char *s);
char  *heap_strdup(const char *s);
#endif

/* strutil.c（节选）：指针遍历求长度、堆上复制 */
size_t mystrlen(const char *s) {
    const char *p = s;
    while (*p != '\0') p++;
    return (size_t)(p - s);          /* 指针相减 = 元素个数 */
}
char *heap_strdup(const char *s) {
    char *p = (char *)malloc(mystrlen(s) + 1);   /* 分配并判空 */
    if (p == NULL) return NULL;
    mystrcpy(p, s, mystrlen(s) + 1);
    return p;                        /* 调用方负责 free */
}

/* main6.c（节选）：argv 传参 + trim + 堆字符串 + free 后置空 */
char buf[64];
mystrcpy(buf, argv[1], sizeof(buf));
trim(buf);
char *heap = heap_strdup(buf);
printf("heap: [%s]\n", heap);
free(heap);
heap = NULL;

实测（gcc 13.3.0）：

$ gcc -Wall main6.c strutil.c -o app
$ ./app "  ros2 humble  "
trim 后: [ros2 humble] 长度=11
heap: [ros2 humble]

6.5 本章小结

  • 指针 + 堆 + 生命周期是理解 rclcpp 智能指针（SharedPtr）的前提；
  • 字符串函数族贯穿 ROS2 命令行与协议解析（NMEA 语句、topic 名拼接）；
  • 多文件 .h/.c + 头文件守卫 = ROS2 包组织的原型；
  • 堆上二维数组（二级指针 malloc）就是导航代价地图的内存形态。
