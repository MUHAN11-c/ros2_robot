本教程依据课程视频内容整理，编写格式参考 zhangzhiwei-zzw 的 ROS2 学习笔记： 章节采用数字编号（X.Y.Z），每个知识点按「案例以及案例分析 → 流程 → 实现（代码）→ 编译 → 执行 → 运行效果 → 小结」的顺序组织。

与参考站点不同的是：本教程全部「运行效果」均为本机实测（Ubuntu 24.04 + ROS2 Jazzy，源码工作空间位于 code/）， 每条输出都来自真实运行记录，存档于 out/verify/，可直接复现。
