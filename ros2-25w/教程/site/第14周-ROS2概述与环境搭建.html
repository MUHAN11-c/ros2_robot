第14章 ROS2 概述与环境搭建

第14章 ROS2 概述与环境搭建

本篇开始进入 ROS2 开发实战。本章先补齐工作空间、功能包与构建工具链的概念，再以课程第一个案例 Hello World（C++/Python 双实现）贯穿「创建功能包 → 编写源码 → 编辑配置 → 编译 → 执行」的完整开发流程。

本章对应代码：code/ws01_plumbing/src/cpp00_hello_world、py00_hello_world。

14.1 ROS2 简介

ROS2（Robot Operating System 2）是面向机器人的开源元操作系统，它并不是传统意义上的操作系统，而是构建在操作系统之上的机器人软件框架，核心解决的是机器人系统中节点间通信与工具链问题。

  • 组成体系：ROS2 由 DDS 通信层 + rcl（ROS Client Library）+ 上层客户端库（rclcpp/rclpy）+ 工具（colcon、rviz2、rosbag2、launch 等） 组成；
  • 优势：分布式（无 Master）、实时性更好、支持多平台、工业级 license 与安全性；
  • 版本：课程基于 Humble（Ubuntu 22.04）；本教程实测环境为 Jazzy（Ubuntu 24.04），两者 API 基本一致，差异处均以「兼容提示」标注。

兼容提示：本教程全部代码已在 Jazzy 上实际编译运行通过。Humble → Jazzy 的主要差异（如动作目标响应回调签名、rosbag2 读取 API 返回值等）会在对应章节标注。

14.2 环境搭建与测试

安装 ROS2 后，终端执行命令验证：

source /opt/ros/jazzy/setup.bash
ros2 --help          # 版本与命令帮助

再运行官方小海龟示例验证图形环境：

ros2 run turtlesim turtlesim_node    # 终端1：仿真器窗口
ros2 run turtlesim turtle_teleop_key # 终端2：键盘控制

运行效果：弹出小海龟窗口，键盘方向键可控制乌龟运动。

14.3 工作空间与功能包

工作空间（workspace）是存放 ROS2 工程源码的目录，典型结构如下（本教程共 6 个，对应第 14-25 周全部实战代码）：

ws01_plumbing/
├── build/      # 编译中间产物
├── install/    # 安装空间（source 它来使用工作空间）
├── log/        # 构建日志
└── src/        # 源码空间：一个功能包一个子目录

功能包（package）分两类：

类型 构建体系 关键文件
C++（ament_cmake） CMakeLists.txt package.xml、src/*.cpp
Python（ament_python） setup.py package.xml、setup.cfg、资源文件 resource/<包名>

编译统一使用 colcon：

cd ws01_plumbing
colcon build                       # 编译全部功能包
source install/setup.bash          # 叠加工作空间环境

实测编译输出（第 14 周工作空间，21 个功能包全部通过）：

Summary: 21 packages finished [1min]

14.4 Hello World（C++ 实现）

14.4.1 案例以及案例分析

需求：编写一个 C++ 节点，运行时输出日志 Hello World!(C++)。 流程：

  1. 创建功能包；
  2. 编写节点源文件；
  3. 编辑 CMakeLists.txt 与 package.xml；
  4. 编译；
  5. 执行。

14.4.2 实现

创建功能包：

cd ws01_plumbing/src
ros2 pkg create cpp00_hello_world --build-type ament_cmake --dependencies rclcpp

源文件 src/demo01_hello_world.cpp：

// 1.包含头文件；
#include "rclcpp/rclcpp.hpp"

int main(int argc, char ** argv)
{
    // 2.初始化 ROS2 客户端；
    rclcpp::init(argc, argv);
    // 3.创建节点并 spin；
    rclcpp::spin(std::make_shared<rclcpp::Node>("hello_world_node_cpp"));
    // 4.释放资源；
    rclcpp::shutdown();
    return 0;
}

CMakeLists.txt 关键内容：

find_package(rclcpp REQUIRED)
add_executable(demo01_hello_world src/demo01_hello_world.cpp)
ament_target_dependencies(demo01_hello_world rclcpp)
install(TARGETS demo01_hello_world DESTINATION lib/${PROJECT_NAME})

14.4.3 编译与执行

cd ws01_plumbing && colcon build --packages-select cpp00_hello_world
source install/setup.bash
ros2 run cpp00_hello_world demo01_hello_world

14.4.4 运行效果（实测）

[INFO] [1792040409.248314370] [hello_world_node_cpp]: Hello World!(C++)
[INFO] [1792040414.099408944] [rclcpp]: signal_handler(SIGINT/SIGTERM)

Ctrl+C 结束时 rclcpp 打出 signal_handler(SIGINT/SIGTERM)，节点正常退出。

14.5 Hello World（Python 实现）

14.5.1 案例以及案例分析

需求：与 14.4 相同，改用 Python（ament_python）实现，体会两种客户端库的工程组织差异。

14.5.2 实现

ros2 pkg create py00_hello_world --build-type ament_python --dependencies rclpy

源文件 py00_hello_world/demo01_hello_world_py.py：

# 1.导包；
import rclpy
from rclpy.node import Node


def main():
    # 2.初始化 ROS2 客户端；
    rclpy.init()
    # 3.创建节点并 spin；
    rclpy.spin(Node("hello_world_node_py"))
    # 4.释放资源；
    rclpy.shutdown()

setup.py 中注册入口：

entry_points={
    'console_scripts': [
        'demo01_hello_world_py = py00_hello_world.demo01_hello_world_py:main',
    ],
},

注意：ament_python 包需要 setup.cfg 指定脚本安装目录，否则 ros2 run 找不到可执行文件：

[develop]
script_dir=$base/lib/py00_hello_world
[install]
install_scripts=$base/lib/py00_hello_world

14.5.3 编译与执行

colcon build --packages-select py00_hello_world
source install/setup.bash
ros2 run py00_hello_world demo01_hello_world_py

14.5.4 运行效果（实测）

[INFO] [1792040414.541185411] [hello_world_node_py]: Hello World!(python)

14.6 本章小结

  • ROS2 是构建在 DDS 之上的机器人软件框架，节点是基本执行单元；
  • 工作空间 = src + build + install + log，source install/setup.bash 后才能使用；
  • C++ 包（ament_cmake）与 Python 包（ament_python）的开发流程同为「创建功能包 → 编码 → 配置 → colcon build → ros2 run」；
  • Python 包不要遗漏 setup.cfg 的脚本安装目录配置。
