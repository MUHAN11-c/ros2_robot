代码项目导览（code/）

本目录 code/ 是根据全套课程视频（第 14~25 周的代码实操部分）深度阅读后还原的 可构建 colcon 工作空间集合，与各周学习笔记一一对应。 总览与命名取证说明见 code/README.md。

一、工作空间与周的对应关系

工作空间 对应周 对应笔记
code/ws01_plumbing 第 14~18 周 阶段 5 各周笔记
code/ws02_middle 第 16 周 第16周
code/ws03_exercise 第 19~20 周 阶段 6 两周笔记
code/ws04_advanced 第 21 周 第21周
code/ws05_sensor 第 22~23 周 阶段 8 前两周笔记
code/ws06_sim_nav 第 24~25 周 阶段 8 后两周笔记

二、每周代码速查

第 14 周 ROS2 概述与环境搭建（ws01_plumbing）

  • cpp00_hello_world / py00_hello_world：HelloWorld C++/Python。

第 15 周 通信机制深度剖析（ws01_plumbing）

  • 接口包 base_interfaces_demo：Student.msg、AddInts.srv、Progress.action。
  • 话题：cpp01_topic（demo01_talker_str / demo02_listener_str / 自定义接口 demo03、demo04）、py01_topic。
  • 服务：cpp02_service（add_ints）、py02_service。
  • 动作：cpp03_action（get_sum，含连续反馈与取消）、py03_action。
  • 参数：cpp04_param（增删改查）、py04_param。

第 16 周 通信机制拓展与时间 API（ws02_middle）

  • cpp01_time：Time / Duration / Rate / 运算。
  • 期中大作业：cpp02_homework + py02_homework（turtlesim 话题/服务/动作/参数综合）。

第 17 周 工具应用实操（ws01_plumbing）

  • launch：cpp01_launch / py01_launch（Python、XML、YAML 三种格式 helloworld）。
  • rosbag2：cpp02_rosbag2（demo01_writer / demo02_reader）。
  • 坐标变换广播：cpp03_tf_broadcaster / py03_tf_broadcaster（静态 + 动态）。
  • 坐标变换监听：cpp04_tf_listener（lookupTransform + transform 点）。

第 18 周 乌龟案例与可视化（ws01_plumbing）

  • 乌龟跟随：cpp05_exercise / py05_exercise（exer01_spawn、exer02_tf_broadcaster、exer03_tf_listener + follow_launch.py、护航 escort_launch.xml）。
  • URDF 与 xacro：cpp06_urdf（rviz2 集成 URDF）、cpp07_xacro（属性/宏）。

第 19~20 周 Mycar 实战（ws03_exercise）

  • 接口：my_exer_interfaces（srv/cru.srv、action/Nav.action）。
  • 话题：my_exer01_topic_pub（圆周运动 + 动态调参）、py_exer01_topic_pub、my_exer02_topic_sub。
  • 服务：my_exer03_service_server / my_exer04_service_client。
  • 动作：my_exer05_action_server（nav_server，剩余距离连续反馈）/ my_exer06_action_client。
  • 集成：my_exer07_bringup（launch + 模型 + 配置）、my_exer08_follow（车辆跟随 + waypoints.csv）、my_exer09_multi_tf（多机器人 TF）。

第 21 周 高效通信与组件开发（ws04_advanced）

  • Lifecycle：lifecycle_cpp / lifecycle_py（on_configure/activate/…）。
  • 进程内通信：intra_process_cpp（IntraProcessSetting + 单线程执行器）。
  • 组件：demo_component（talker/listener 组件 + 注册宏）。
  • 参数事件：demo_param_events / demo_param_events_py。
  • 话题统计/过滤：demo_topic_tools。
  • 插件：plugin_base / plugin_impl / plugin_loader。

第 22~23 周 传感器实践（ws05_sensor/src/demo）

  • 里程计：cpp00_odom / py00_odom（odom2path）。
  • 雷达仿真：cpp01_laser_sim / py01_laser_sim（LaserScan）、cpp02_pointcloud_sim / py02_pointcloud_sim（PointCloud2）。
  • 相机仿真：cpp03_camera_sim / py03_camera_sim（Image）。
  • IMU：cpp04_imu_demo / py04_imu_demo。
  • GNSS：cpp05_gnss_demo / py05_gnss_demo（NavSatFix → Path）。

第 24~25 周 仿真 / 导航 / 多车 / 语音（ws06_sim_nav）

  • stage_ros2 仿真：demo_stage_sim（world + launch）。
  • ignition gazebo：demo_ign_sim（SDF world + ros_gz_bridge + launch）。
  • SLAM：demo_slam（slam_toolbox 在线同步建图 + cartographer）。
  • 导航服务器：demo_nav2（map_server/AMCL/规划/控制/行为树 + 生命周期管理器 + 示例地图）。
  • 多车编队：demo_formation（双车 stage + 跟随控制 + waypoints.csv）。
  • 语音控制：demo_voice（讯飞 SDK 集成骨架，密钥仅经环境变量注入）。

三、构建与验证状态

  • 全部 Python 节点（93 个 .py）通过语法检查；22 个 ament_python 包结构完整。
  • 全部 XML/URDF/SDF/YAML 通过格式校验；C++ 通过括号配平检查（未在无 ROS2 环境下编译）。
  • 依赖：turtlesim、tf2、rclcpp_action、rclcpp_lifecycle、rclcpp_components、pluginlib、 slam_toolbox、cartographer_ros、nav2_*、stage_ros2、ros_gz_bridge、teleop_twist_keyboard 等， 可按需 sudo apt install ros-humble-<包名>。
