## 25.1 Nav2 导航

### 25.1.1 案例以及案例分析

**需求**：加载地图（map_server）→ 定位（AMCL）→ 全局/局部规划（planner/controller）→ 行为树导航（bt_navigator）→ 恢复行为（behavior_server），由 lifecycle_manager 统一拉起，`nav2_params.yaml` 集中配置。

### 25.1.2 实现

`launch/bringup_launch.py` 装载 `maps/demo_map.pgm`（+ `demo_map.yaml` 元数据）、`behavior_trees/navigate_w_replanning.xml` 行为树与 `param/nav2_params.yaml`。

### 25.1.3 运行效果（实测）

## 25.3 语音控制小车

### 25.3.1 案例以及案例分析

**需求**：ASR 识别结果（中文文本）经 `/voice_cmd_text`（std_msgs/String）进入控制节点，映射为 `/cmd_vel` 速度指令：

| 指令 | linear.x | angular.z |
| --- | --- | --- |
| 前进 | 0.30 | 0.0 |
| 后退 | -0.30 | 0.0 |
| 左转 | 0.0 | 0.30 |
| 右转 | 0.0 | -0.30 |
| 停止 | 0.0 | 0.0 |

### 25.3.2 实现要点

`voice_controller.py`（安全要点：**凭据从环境变量读取**，代码中不写入任何密钥字面量）：

```python
self.iflytek_appid = os.environ.get("IFLYTEK_APPID", "")   # 凭据只从环境读取
self.sub = self.create_subscription(String, "voice_cmd_text", self.on_text, 10)
self.pub = self.create_publisher(Twist, "cmd_vel", 10)
```

`voice_input.py` 为键盘模拟 ASR 输入（正式使用时替换为讯飞 SDK 的识别结果发布）。

### 25.3.3 运行效果（实测）

```bash
ros2 run demo_voice voice_controller
ros2 topic pub --once /voice_cmd_text std_msgs/msg/String "{data: 前进}"
ros2 topic echo /cmd_vel --once
```

```text
[INFO] [...]: 收到语音指令:前进
[INFO] [...]: 执行: linear=0.30 angular=0.00
```

```text
linear:
  x: 0.3
angular:
  z: 0.0
```

发送「停止」后输出 `linear=0.00 angular=0.00`。

## 25.4 本章小结与课程回顾

- Nav2 = 定位 + 规划 + 控制 + 行为树的**生命周期化**组合，参数集中于一个 yaml；
- 编队的本质是「以队友为参考系的速度控制」；
- 语音控制 = ASR 文本 → 指令映射 → Twist，注意凭据只能走环境变量/密钥服务。
