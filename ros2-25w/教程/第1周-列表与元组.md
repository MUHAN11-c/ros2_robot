- **核心概念**：Python 是解释型、动态类型的高级语言，语法简洁、生态丰富（NumPy/OpenCV/ROS2 rclpy 都有 Python 接口），是机器人领域做原型验证的首选语言。

### 1.2.3 第3课 分支语句与嵌套结构详解

- **核心概念**：分支语句（if statement）让程序按条件走不同路径；Python 用缩进（推荐 4 空格）划分代码块，没有花括号。
- **单 / 双 / 多分支**：`if 条件:`、`if ... else ...`、`if ... elif ... else ...`。条件可以是比较表达式或布尔变量，`elif` 可有多个，`else` 最多一个且放最后。
- **典型练习**：奇偶数判断（`n % 2 == 0`）、正负数判断（注意 0 的归属）、登录判断（用户名密码与预设值比较）、成绩判断（分数段映射等级）、判断是否为员工（`in` 成员运算符查列表）。多分支练习强调「边界值」——比如 90 分算 A，89.5 分算什么。
- **if 嵌套**：外层条件成立才判断内层，如「已登录 且 是管理员才能进后台」。嵌套不超过 3 层，太深就拆函数。
- **随机数基础**：`import random`，`random.randint(a, b)` 生成 [a, b] 闭区间整数，`random.random()` 生成 [0,1) 浮点数，`random.choice(seq)` 从序列随机取一个。用在随机点名、猜拳游戏里。
- **猜拳游戏综合案例**：玩家输入 vs `random.choice(["石头","剪刀","布"])`，用多分支判断胜负，循环多局并统计胜率——把输入、类型、分支、循环串成完整小项目。

### 1.2.4 第4课 循环类型全面讲解

- **核心概念**：循环（loop）让重复工作交给计算机；Python 有 while 与 for 两种主要循环。
- **while 循环**：`while 条件:`，条件为真就反复执行，务必在循环体内更新条件变量，否则是死循环。死循环并非一无是处（服务器主循环就是 `while rclpy.ok()`），但初学阶段要警惕意外死循环（Ctrl+C 中断）。
- **break 与 continue**：`break` 立即跳出整个循环；`continue` 跳过本次剩余语句进入下一轮。常见用法：循环中「输入 quit 就 break」「数据非法就 continue 重来」。
- **for 循环**：`for 元素 in 序列:` 逐个取出元素，天然适合遍历字符串、列表、元组、字典。遍历中修改被遍历的列表是经典坑，应先构造新列表。
- **for 与 else 组合**：`for ... else ...` 中的 `else` 在循环**没有被 break 中断**时执行，常用于「查找失败」的兜底处理。
- **range 生成**：`range(stop)`、`range(start, stop)`、`range(start, stop, step)`，生成整数序列，左闭右开；`range` 是惰性对象，`list(range(3))` 才得到 `[0, 1, 2]`。配合 `for i in range(len(seq))` 是「下标遍历」，更 Pythonic 的写法是 `for item in seq` 或 `for i, item in enumerate(seq)`。

### 1.2.5 第5课 字符串、列表与元组详解与应用

- **核心概念**：字符串是不可变（immutable）的字符序列；列表是可变的有序容器；元组是不可变的有序容器；字典是键值对（key-value）映射。
- **字符串表示**：单引号、双引号等价，三引号可跨行；转义符号 `\n \t \\ \' \"`，`r"raw\path"` 原始字符串不转义（写文件路径很方便）。
- **索引与切片**：下标从 0 开始，支持负索引（`s[-1]` 是最后一个字符）；切片 `s[start:end:step]` 左闭右开、可省略、步长为负即反转。切片得到新字符串，原串不变。
- **查找 / 替换 / 分割**：`find()` 找不到返回 -1（`index()` 找不到抛 `ValueError`）、`count()` 计数、`replace(old, new)` 返回新串、`split(sep)` 拆成列表、`"sep".join(list)` 把列表拼回字符串。
- **大小写与空白处理**：`upper()` / `lower()` / `title()`、`strip()`（去掉首尾空白，另有 `lstrip` / `rstrip`），处理用户输入前先 `strip()` 是好习惯。
- **列表操作**：新增 `append` / `extend` / `insert`；修改用下标赋值；删除 `del` / `remove(值)` / `pop(下标)`；查找 `in`、`index`、`count`；排序 `sort()`（原地）与 `sorted()`（返回新列表），`reverse=True` 降序；复制注意 `copy()` 或切片 `[:]` 是浅拷贝；嵌套列表可表达二维表格（如多台机器人的多组传感器读数）。
- **遍历与推导式**：`for item in list`、`for i, item in enumerate(list)`（带下标）、`for a, b in zip(list1, list2)`（并行遍历）。列表推导式 `[表达式 for x in 序列 if 条件]` 一行生成新列表，简洁高效，但复杂逻辑仍应写普通循环。
- **元组**：用小括号定义，不可增删改，适合存放「成组的、不该被改动的数据」，如坐标 `(x, y)`、位姿 `(x, y, theta)`；元组比列表更省内存、可作字典的键。`max()` / `min()` / `len()` 等通用函数对列表和元组都适用。
- **字典**：`{key: value}`，键唯一且必须是不可变类型（字符串/数字/元组），值随意。新增/修改 `d[key] = v`、删除 `del d[key]`、安全取值 `d.get(key, 默认)`。遍历：`for k in d`、`for k, v in d.items()`、`for v in d.values()`。字典是「配置」「参数」「结构化记录」的天然载体——ROS2 参数服务器读出来的就是类似结构。
- **拆包（unpacking）**：`a, b, c = [1, 2, 3]`、`x, y = (3.0, 4.0)`、`first, *rest = lst`（星号收集剩余元素）、`a, b = b, a`（交换）。拆包让函数多返回值、坐标处理变得优雅。

四种容器的速查对照：

| 容器 | 特点 | 典型用途 |
| --- | --- | --- |
| str | 不可变序列 | `find/split/replace/strip`、切片 `[start:end:step]` |
| list | 可变有序 | `append/extend/insert/remove/pop/sort`、推导式 |
| tuple | 不可变有序 | 坐标 `(x, y)`、函数多返回值、字典的键 |
| dict | 键值映射 | `d[k]=v`、`d.get(k, 默认)`、`d.items()` |

## 1.3 重点与难点

1. **可变与不可变（immutable）**：列表可变、字符串和元组不可变。`str.replace()` 返回新串而非改原串；把列表传进函数并在函数里 `append`，外部列表也会变——这是「引用传递」的直觉来源，也是第 2 周讲传参细节的基础。
2. **切片的左闭右开**：`s[2:5]` 取下标 2、3、4；配合负步长 `[::-1]` 反转。NumPy 的数组切片沿用同一套语法，本周务必练熟。
3. **浅拷贝与深拷贝**：`list.copy()` / `lst[:]` 只复制第一层，嵌套列表里层仍是同一份引用；需要完全独立的副本用 `copy.deepcopy()`（第 3 周在 OpenCV 图像上会再次遇到）。
4. **字典键的唯一与不可变**：重复赋值同名键会覆盖旧值；列表不能作键，元组可以。
5. **列表推导式的边界**：它只是「生成新列表」的语法糖，不要塞进多层嵌套和副作用（如打印、写文件），否则可读性反而下降。

> **注意：** `input()` 永远返回字符串。忘了 `int()` 转换会让 `+` 变成字符串拼接（"5" + "3" == "53"），这是初学第一周最常见的 bug。

```python
# 示例3（场景：字符串处理 —— 解析一行激光雷达日志）
line = "  frame_id=laser; ranges=1.2,2.4,3.0; angle_min=-1.57  "
line = line.strip()                      # 去掉首尾空白
fields = line.split(";")                 # 按分号拆分
record = {}
for f in fields:
    k, v = f.strip().split("=")          # 拆包成键值
    record[k] = v
ranges = [float(x) for x in record["ranges"].split(",")]   # 列表推导式
print(record["frame_id"], ranges, max(ranges))             # laser [1.2, 2.4, 3.0] 3.0
```

```python
# 示例4（场景：列表/元组/字典 —— 管理机器人航点，即本章综合案例）
waypoints = [(0.0, 0.0), (1.5, 0.0), (1.5, 2.0)]   # 元组列表表示 (x, y)
waypoints.append((0.0, 2.0))
total = 0.0
for (x1, y1), (x2, y2) in zip(waypoints, waypoints[1:]):   # 相邻两点
    total += ((x2 - x1) ** 2 + (y2 - y1) ** 2) ** 0.5
print(f"总路程 {total:.2f} m")
# 推导式筛选 + sorted 排序
near = [(x, y) for x, y in waypoints if x ** 2 + y ** 2 < 5.0]
by_x = sorted(waypoints, key=lambda p: p[0])       # 按 x 排序（lambda 见第2周）
print(near, by_x)
```

```python
# waypoints.py —— 标准输入逐行接收命令：add 名称 x y / list / quit
waypoints = {"w0": (0.0, 0.0), "w1": (1.5, 0.0)}
import sys
for line in sys.stdin:
    parts = line.split()
    if not parts:
        continue
    cmd = parts[0]
    if cmd == "add":
        name, x, y = parts[1], float(parts[2]), float(parts[3])
        waypoints[name] = (x, y)
        print(f"已添加 {name} -> ({x}, {y})")
    elif cmd == "list":
        for name, (x, y) in sorted(waypoints.items(), key=lambda kv: kv[1][0]):
            print(f"  {name}: ({x:.2f}, {y:.2f})")
    elif cmd == "quit":
        print(f"共 {len(waypoints)} 个航点，退出")
        break
    else:
        print(f"未知命令: {cmd}")
```


## 1.6 与 ROS2 / 机器人开发的关联

1. **rclpy 节点的日常写法**：一个 rclpy 节点就是一个 Python 类（`class MyNode(Node)`），构造函数、方法、属性全靠第 1-2 周的 Python 基础；`self.declare_parameter('max_speed', 1.5)` 的缺省参数思想与本周变量初始化一脉相承。
2. **消息（Message）字段就是数据结构**：`geometry_msgs/Point` 对应 `(x, y, z)` 三元组，用元组/拆包处理位姿最顺手；`nav_msgs/Path` 的 `poses` 列表、传感器消息里的数组字段，都对应列表的遍历、切片与推导式。
3. **话题（Topic）数据的解析与过滤**：回调里常写「遍历 ranges，过滤掉 inf/NaN，取最小值」这类代码，正是 `for` + `if` + 列表推导式的组合，例如 `valid = [r for r in msg.ranges if 0.05 < r < 12.0]`。
4. **参数与配置**：ROS2 参数（Parameters）常以字典形式读写；launch 文件里的参数也常被解析成 dict——字典增删改查、`get(key, default)` 是必备技能。
5. **日志与终端输出**：`f"{value:.3f}"` 这样的格式化在 `self.get_logger().info()` 里天天用，控制小数位数能让日志可读性大幅提升。

## 1.7 自测与练习（含参考答案要点）

1. **题目**：写一个程序，输入一个整数，输出它是奇数还是偶数；如果是 0 单独提示「零」。
2. **题目**：给定列表 `distances = [0.8, 12.5, float('inf'), 3.2, -1.0, 2.0]`，用列表推导式过滤出「大于 0 且小于 10」的有效距离，并输出其个数与最小值。
3. **动手任务**：写一个「航点管理」脚本：用字典存 `{"name": (x, y)}` 形式的航点，支持循环输入 `add 名称 x y` / `list` / `quit` 三个命令；`list` 时按 x 坐标升序打印。验收标准：能正确增删查、非法命令有提示、`quit` 干净退出。
4. **题目**：解释 `a = [1, 2, 3]; b = a; b.append(4); print(a)` 的输出，并说明如何让 `b` 不影响 `a`。

> 参考答案要点：1) 用 `n % 2` 与 `n == 0` 分支，注意 0 既是偶数，需优先判断；2) `[d for d in distances if 0 < d < 10]`，配合 `len()` 与 `min()`，注意 `-1.0` 与 `inf` 都被过滤；3) 核心是 `while True` + `cmd = input().split()` + 多分支 + `dict.items()` 遍历与 `sorted(key=lambda kv: kv[1][0])`；4) `a` 也变成 `[1, 2, 3, 4]`，因为 `b = a` 只是同一个列表的另一个名字；隔离需 `b = a.copy()` 或 `b = a[:]`（浅拷贝），嵌套结构用 `copy.deepcopy()`。

## 1.8 常见问题（FAQ）

- **Q：`/` 和 `//` 有什么区别？** A：`7 / 2` 结果是 `3.5`（真除，得到浮点数），`7 // 2` 结果是 `3`（整除/地板除，丢掉小数部分）。求余数用 `%`。
- **Q：什么时候用列表、什么时候用元组？** A：数据需要增删改 → 列表；数据成组且不应被改动（坐标、颜色 RGB、函数多返回值）→ 元组。元组还可作字典的键，列表不行。
- **Q：`find()` 和 `index()` 有什么区别？** A：都返回首次出现的下标；找不到时 `find()` 返回 `-1`，`index()` 抛出 `ValueError`。想「找不到也不崩」用 `find()` 或 `in` 先判断。
- **Q：为什么我的 `if x = 1:` 报语法错误？** A：条件判断用 `==` 比较运算符，`=` 是赋值。Python 没有「条件里赋值」的写法（3.8+ 可用海象运算符 `:=`，本阶段不必掌握）。
- **Q：列表推导式和普通 for 循环怎么选？** A：一行能写清楚的「筛选/转换」用推导式；含多步逻辑、嵌套循环或副作用时用普通循环，可读性优先。

## 1.9 本章小结

- 分支/循环是「控制流」，四种容器是「数据组织」——二者组合即可写出完整小脚本；
- 列表可变、字符串与元组不可变；`str.replace()` 返回新串而非改原串；
- 推导式适合一行能写清的筛选/转换，复杂逻辑仍用普通循环；
- 与 ROS2 的关联：消息字段就是数据结构（`Point` ↔ 三元组、`Path.poses` ↔ 列表），参数读写形如字典操作。
