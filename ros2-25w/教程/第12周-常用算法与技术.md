# 第12章 常用算法与技术（algorithm/chrono/lambda/线程）

> 本章对应课程第 12 周：`<algorithm>` 算法族与仿函数/谓词、`<chrono>` 时间体系、`bind`/lambda、智能指针、CSV/多线程/状态机——这些技术在 ROS2 中无处不在。

## 12.1 案例以及案例分析

**需求**：用 `steady_clock` 测量耗时；用 lambda 捕获配置；多线程并发输出用互斥锁保护——分别对应 `rclcpp::Rate`、订阅回调绑定、多线程 executor 的底层形态。

## 12.2 知识点与实现

### 12.2.1 算法族（`<algorithm>`/`<numeric>`）

- 谓词定制行为：`count_if/find_if/sort/remove_if` + 仿函数或 lambda；
- 内建函数对象：`std::greater<>{}` 降序；`std::not_fn` 取反（`not1/not2` 已弃用）；
- 常用算法：`transform`（映射）、`accumulate`（折叠求和）、`copy_if + back_inserter`（过滤）、`binary_search/lower_bound`（有序二分）、`set_intersection`（集合运算，**要求输入有序**）、`std::shuffle + mt19937`（随机采样）；
- `for_each` 返回仿函数副本，可携带累计状态。

### 12.2.2 时间（`<chrono>`）

- 三件套：duration/time_point/clock；`100ms/1s` 字面量需 `using namespace std::chrono_literals`；
- **测耗时用 `steady_clock`**（单调，不受 NTP 校时影响）；日历时间戳用 `system_clock`；
- `sleep_for(时长)` 与 `sleep_until(时刻)`（无漂移定时）——`rclcpp::Rate/WallRate` 的底层。

### 12.2.3 bind、lambda 与多线程

- `std::bind(&Class::cb, this, _1)` 把成员函数适配成可调用对象；lambda 捕获 `[this]/[=]/[&]` 更直观（注意对象生命周期）；
- 智能指针：默认 `unique_ptr`，共享用 `make_shared`，`weak_ptr` 破循环引用；
- 线程：`std::thread + join()`（勿随意 detach）；共享数据 `std::mutex + lock_guard`；无锁计数用 `std::atomic`；
- 状态机：`enum class State` + 转移函数，机器人行为管理的基石（nav2 行为树是其扩展）。

## 12.4 端到端实战（实测）：速度序列算法流水线

课程自测题的实现：只用算法（count_if/accumulate/transform）完成「超速帧数、平均速度、超速裁剪」，并用 chrono 测量处理耗时：

```cpp
// speed.cpp
std::vector<double> speeds{0.8, 1.2, 0.6, 1.5, 0.9, 2.0, 1.1};

int over = std::count_if(speeds.begin(), speeds.end(),
                         [](double v) { return v > 1.0; });
double avg = std::accumulate(speeds.begin(), speeds.end(), 0.0) / speeds.size();
std::transform(speeds.begin(), speeds.end(), speeds.begin(),
               [](double v) { return std::min(v, 1.0); });   // 裁剪为上限

auto t0 = std::chrono::steady_clock::now();
std::this_thread::sleep_for(50ms);
auto dt = std::chrono::duration_cast<std::chrono::milliseconds>(
              std::chrono::steady_clock::now() - t0);
```

实测（g++ -std=c++17 -Wall -pthread）：

```text
超速帧数=4 平均=1.15714
裁剪后: 0.8 1 0.6 1 0.9 1 1 
控制周期耗时=50 ms
```

## 12.5 本章小结

- 把「循环 + 累加/变换」写成一行算法（count_if/accumulate/transform），减少越界与迭代器失效风险；
- `steady_clock` 测量、`system_clock` 日历——用错时钟测耗时会出现负值（真实事故高发点）；
- lambda 捕获 `this` 时保证对象比回调活得久；
- CSV/XML/YAML 三种数据格式的解析（stringstream/getline）是调试机器人系统的日常技能。
