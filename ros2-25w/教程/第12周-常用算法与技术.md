## 12.2 知识点梳理

### 12.2.1 第1课：C++ 常用算法原理与实践

- **核心概念**：函数对象（仿函数，functor）= 重载了 `operator()` 的类对象；谓词（predicate）= 返回 `bool` 的仿函数/函数，是一元（一参）或二元（两参）判定条件。算法 + 仿函数 = 可复用的行为参数。
- **一元谓词与二元谓词**：`find_if(v.begin(), v.end(), IsPositive{})`（一元）、`sort(v.begin(), v.end(), Less{})`（二元）。谓词让 `find_if/count_if/remove_if/sort` 的行为可定制。
- **内建函数对象**：`<functional>` 提供 `std::plus<T>/minus<T>/multiplies<T>/equal_to<T>/less<T>/greater<T>` 等，可直接当谓词用：`sort(v.begin(), v.end(), std::greater<int>())` 降序。
- **函数对象适配器与函数适配器**：C++11 前有 `bind1st/bind2nd/mem_fun` 等适配器（已弃用）；现代 C++ 用 `std::bind` 与 lambda 代替。理解适配器有助于读懂遗留代码。
- **取反匹配器（not1/取反谓词）**：`not1` 取反一元谓词、`not2` 取反二元谓词（C++17 弃用）；现代写法是 `std::not_fn(pred)` 或 lambda `[](const T& x){ return !pred(x); }`。
- **二元取反**：同上，用于 `sort` 自定义比较器取反得到降序；优先直接传 `std::greater<>{}`。
- **成员函数匹配器（mem_fn）**：`std::mem_fn(&Robot::start)` 把成员函数变成可调用对象，配合 `for_each` 批量调用：`for_each(v.begin(), v.end(), std::mem_fn(&Robot::start));`。
- **for_each 的返回值**：`for_each` 返回它所使用的仿函数**副本**（F），可携带累计状态：累加器、计数器都可从返回值取出。
- **遍历和绑定（bind）**：`std::bind` 固定函数部分参数生成新可调用对象，`std::placeholders::_1/_2` 表示占位参数；常用于把「两参回调」适配成「一参回调」。
- **transform 搬运**：`transform(first, last, out, op)` 把输入区间映射到输出区间（如米→弧度、摄氏→华氏）；一元/二元两版本。
- **find 与 find_if**：`find` 按值查找、`find_if` 按谓词查找，返回迭代器（找不到返回 `end()`）；O(n) 线性查找，有序容器用 `binary_search`。
- **adjacent_find**：查找相邻重复元素（`adjacent_find(v.begin(), v.end())`），常用于去重前检测、轨迹连续点异常检测。
- **二分查找**：有序序列上 `binary_search`（返回 bool）、`lower_bound`（首个 ≥ 值）、`upper_bound`（首个 > 值）、`equal_range`（相等区间）；O(log n)。
- **count/count_if**：统计等于值/满足谓词的元素个数（`count_if` 统计「正数个数」「超时帧数」）。
- **排序与 merge**：`sort`（快排，不稳定）、`stable_sort`（稳定）、`partial_sort`（取前 k 大/小）、`nth_element`（找第 k 小）；`merge` 把两个有序区间合并为一个有序区间（输出区间需预先分配）。
- **随机算法**：`std::shuffle(v.begin(), v.end(), std::mt19937(std::random_device{}()))`（C++11 起代替弃用的 `random_shuffle`）；蒙特卡洛定位、随机采样路径规划用它。
- **反转容器**：`reverse(v.begin(), v.end())`；`reverse_copy` 保留原数据。
- **拷贝算法**：`copy/copy_if/copy_n/copy_backward`，配合 `std::back_inserter` 向目标容器追加（避免预分配）。
- **替换**：`replace/replace_if/replace_copy`，批量改写满足条件的元素（如把超限速度裁剪为上限）。
- **算术生成算法**：`accumulate`（求和/自定义折叠）、`fill/fill_n`（填充）、`iota`（递增序列）、`inner_product`（点积/累加）。
- **交集/并集/差集**：`set_intersection/set_union/set_difference`，要求输入有序；常用于多传感器数据融合、目标集合比较。

```cpp
std::vector<int> a{1, 2, 3, 4}, b{3, 4, 5}, out;
std::set_intersection(a.begin(), a.end(), b.begin(), b.end(),
                      std::back_inserter(out));   // out = {3, 4}
```

> **注意：** 集合算法要求**输入区间已排序**，且输出容器要有足够容量（推荐 `std::back_inserter`）。对未排序数据直接调用是逻辑错误，不报错但结果错。

### 12.2.2 第2课：时间处理方法详解与 C++ 技术补充

#### 时间体系（`<chrono>`）

- **时间基础用法**：三件套——`duration`（时长，如 `std::chrono::milliseconds(100)`）、`time_point`（时间点）、`clock`（时钟）。`using namespace std::chrono_literals;` 后可写 `100ms / 1s / 5min` 字面量。
- **类型转换**：`duration_cast<milliseconds>(sec)` 显式转换时长单位（截断小数）；`time_point_cast` 转换时间点精度；注意 `duration_cast` 是截断不是四舍五入。
- **自定义时间单位**：`std::chrono::duration<int, std::ratio<1, 1000>>` 自定义 tick 单位；`std::chrono::hours/days` 等常用单位；机器人中「100Hz 控制周期」= `10ms`。
- **时间暂停方法**：`std::this_thread::sleep_for(100ms)`（睡时长）、`sleep_until(tp)`（睡到时刻，无漂移）、条件变量 `cv.wait_for/wait_until`（可被唤醒，适合事件驱动）。
- **时间戳**：`std::chrono::system_clock::now()` 是日历时间（受 NTP 调整，可回拨）；`to_time_t`/`from_time_t` 与 C 时间互转；`time_since_epoch().count()` 取自 epoch 的 tick 数。
- **稳定时钟（steady_clock）**：单调递增、不受系统时间调整影响，适合测量**耗时/超时/频率**（`auto t0 = steady_clock::now(); ... auto dt = steady_clock::now() - t0;`）。
- **高精度单调时钟**：`steady_clock` 的 `duration` 通常是纳秒级；`high_resolution_clock` 只是别名，不保证单调——测量性能一律用 `steady_clock`。

#### bind、lambda 与智能指针

- **bind 绑定函数的参数**：`std::bind(&Class::cb, this, _1, _2)` 固定对象与部分参数；`std::bind` + 成员函数 = 把「成员函数」变成自由可调用对象。
- **lambda 实现绑定参数**：`[this](auto msg){ this->on_msg(msg); }` 捕获 `this` 与局部变量，比 `bind` 更直观；`[=]` 值捕获、`[&]` 引用捕获、`[this]` 捕获成员。
- **智能指针**：`unique_ptr`（独占、零开销、不可拷贝可移动）、`shared_ptr`（引用计数共享）、`weak_ptr`（打破循环引用）、`make_unique/make_shared` 优先。避免裸 `new/delete`。

#### 数据格式、多线程与状态机

- **逗号分割值（CSV）**：`std::getline(ss, token, ',')` 或 `std::stringstream` 逐列解析；注意引号内含逗号、CRLF 行尾等边界；机器人常用于轨迹/标定数据交换。
- **XML 基础与语法**：标签 `<tag attr="v">text</tag>`、属性、嵌套、注释 `<!-- -->`、文档声明 `<?xml version="1.0"?>`；URDF 机器人描述就是 XML 格式。
- **YAML 格式**：缩进表层级、`key: value`、列表 `- item`、锚点 `&a/*a` 复用；ROS2 参数文件（`params.yaml`）、导航配置全是 YAML。
- **多线程基础**：`std::thread t(fn, args...)` 创建、`join()` 等待、`detach()` 分离（危险，慎用）；`std::mutex` + `std::lock_guard<std::mutex>` 保证互斥；`std::atomic` 无锁计数。
- **数据打印错乱问题**：多线程同时 `std::cout` 输出会交错——用互斥锁保护打印、或统一「消息入队 + 单线程输出」；这是理解线程安全的第一课。
- **分离线程**：`t.detach()` 后线程与主线程生命周期脱钩，主线程退出即强杀；必须保证线程不访问已析构对象。优先 `join` 或线程池。
- **有限状态机（FSM）**：状态 + 事件 + 转移表；用 `enum class State { Idle, Running, Error }` + `switch` 或 `std::map<State, std::function<void()>>` 实现；机器人行为树/导航状态管理的基石。

```cpp
using namespace std::chrono_literals;
auto t0 = std::chrono::steady_clock::now();
std::this_thread::sleep_for(50ms);
auto dt = std::chrono::duration_cast<std::chrono::milliseconds>(
              std::chrono::steady_clock::now() - t0);
std::cout << dt.count() << " ms\n";
```

> **注意：** 测量耗时/超时用 `steady_clock`，日历时间/时间戳用 `system_clock`。用 `system_clock` 测量耗时会因 NTP 校时产生负值——这是真实工程事故高发点。

## 12.3 重点与难点

1. **仿函数 vs lambda vs `std::bind`**：优先 lambda（可读、可内联优化）；`std::bind` 适合兼容旧接口；仿函数适合携带复杂状态或复用比较规则。
2. **`accumulate`/`transform` 的声明式思维**：把「循环 + 累加/变换」变成一行算法，减少下标越界与迭代器失效风险。
3. **chrono 的 clock 选择**：`steady_clock` 测量、`system_clock` 日历、`sleep_until` 无漂移定时——ROS2 `rclcpp::Rate`/`WallRate` 底层就是这套 API。
4. **多线程安全**：共享数据必加锁；`std::lock_guard` 保证异常安全；`detach` 慎用；理解「打印错乱」背后的内存可见性。
5. **状态机建模**：机器人系统天然是状态机（待机/运行/急停/错误），用 enum + 转移表而非散落的 bool 标志位。

**场景 1：仿函数、谓词与适配器（对应第1课）**

```cpp
// functor.cpp
#include <algorithm>
#include <cstdlib>
#include <functional>
#include <iostream>
#include <vector>

struct IsPositive {                    // 一元谓词
    bool operator()(int v) const { return v > 0; }
};

struct ByAbsLess {                     // 二元谓词：按绝对值比较
    bool operator()(int a, int b) const { return std::abs(a) < std::abs(b); }
};

struct Accumulator {                   // 携带状态的仿函数
    int sum = 0;
    void operator()(int v) { sum += v; }
};

int main() {
    std::vector<int> v{-3, 1, -2, 5, 0};
    std::cout << std::count_if(v.begin(), v.end(), IsPositive{}) << "\n";   // 2
    std::sort(v.begin(), v.end(), ByAbsLess{});                              // 按绝对值排
    Accumulator acc = std::for_each(v.begin(), v.end(), Accumulator{});      // 返回仿函数副本
    std::cout << acc.sum << "\n";                                            // -1
    std::sort(v.begin(), v.end(), std::greater<>{});                         // 内建函数对象降序
}
```

```bash
g++ -std=c++17 -Wall -o functor functor.cpp && ./functor
```

**场景 2：查找、排序、集合算法（对应第1课）**

```cpp
// algo.cpp
#include <algorithm>
#include <iostream>
#include <numeric>
#include <vector>

int main() {
    std::vector<int> a{1, 2, 3, 4, 5, 5}, b{4, 5, 6};
    std::cout << std::binary_search(a.begin(), a.end(), 3) << "\n";         // 1（须有序）
    std::cout << *std::lower_bound(a.begin(), a.end(), 5) << "\n";          // 5
    std::cout << std::adjacent_find(a.begin(), a.end()) - a.begin() << "\n";// 4（相邻重复位置）
    std::cout << std::accumulate(a.begin(), a.end(), 0) << "\n";            // 20

    std::vector<int> out;
    std::set_intersection(a.begin(), a.end(), b.begin(), b.end(),
                          std::back_inserter(out));                         // 交集 {4,5}
    for (int x : out) std::cout << x << " ";
    std::cout << "\n";
    std::reverse(out.begin(), out.end());                                   // 反转
    std::replace_if(out.begin(), out.end(), [](int x){ return x > 4; }, 4); // 替换
}
```

**场景 3：chrono 时间与稳定时钟测量（对应第2课）**

```cpp
// chrono_demo.cpp
#include <chrono>
#include <iostream>
#include <thread>

using namespace std::chrono_literals;

int main() {
    auto t0 = std::chrono::steady_clock::now();        // 单调时钟：测耗时
    std::this_thread::sleep_for(50ms);
    auto dt = std::chrono::duration_cast<std::chrono::milliseconds>(
                  std::chrono::steady_clock::now() - t0);
    std::cout << "elapsed " << dt.count() << " ms\n";

    auto tp = std::chrono::system_clock::now();        // 日历时间：时间戳
    std::time_t ts = std::chrono::system_clock::to_time_t(tp);
    std::cout << "timestamp " << ts << "\n";

    auto wake = std::chrono::steady_clock::now() + 100ms;   // sleep_until 无漂移定时
    std::this_thread::sleep_until(wake);
}
```

**场景 4：bind 与 lambda 绑定回调（对应第2课）**

```cpp
// bind_lambda.cpp
#include <functional>
#include <iostream>

class NodeLike {
public:
    void on_msg(const std::string& topic, int data) {
        std::cout << topic << " -> " << data << "\n";
    }
    void setup() {
        auto cb1 = std::bind(&NodeLike::on_msg, this,
                             std::placeholders::_1, std::placeholders::_2);
        cb1("scan", 1);                                     // bind 适配成员函数

        auto cb2 = [this](const std::string& t, int d) {    // lambda 捕获 this

        };
        cb2("odom", 2);

        int scale = 10;                                     // lambda 值捕获
        auto cb3 = [scale](int d) { std::cout << d * scale << "\n"; };
        cb3(3);
    }
};

int main() { NodeLike n; n.setup(); }
```

**场景 5：多线程 + 互斥锁 + CSV 解析（对应第2课）**

```cpp
// thread_csv.cpp
#include <fstream>
#include <iostream>
#include <mutex>
#include <sstream>
#include <string>
#include <thread>
#include <vector>

std::mutex g_mtx;                              // 保护共享输出/数据

void worker(int id) {
    std::lock_guard<std::mutex> lk(g_mtx);     // 作用域锁：异常安全
    std::cout << "[worker " << id << "] done\n";   // 加锁避免打印错乱
}

int main() {
    std::vector<std::thread> pool;
    for (int i = 0; i < 3; ++i) pool.emplace_back(worker, i);
    for (auto& t : pool) t.join();             // 等待全部完成（勿 detach）

    std::ofstream ofs("traj.csv");
    ofs << "1,0.5,0.25\n2,0.75,0.5\n";
    ofs.close();

    std::ifstream ifs("traj.csv");
    std::string line;
    while (std::getline(ifs, line)) {          // CSV 逐行解析
        std::stringstream ss(line);
        std::string cell;
        std::vector<double> row;
        while (std::getline(ss, cell, ',')) row.push_back(std::stod(cell));
        std::cout << "row size=" << row.size() << "\n";
    }
}
```

```bash
g++ -std=c++17 -Wall -pthread -o thread_csv thread_csv.cpp && ./thread_csv
# -pthread 链接 POSIX 线程库
```

**场景 6（补充）：有限状态机骨架（对应第2课）**

```cpp
// fsm.cpp
#include <iostream>
#include <string>

enum class State { Idle, Running, Error };     // 强类型枚举

State on_event(State s, const std::string& ev) {
    if (s == State::Idle && ev == "start") return State::Running;
    if (s == State::Running && ev == "fail") return State::Error;
    if (s == State::Error && ev == "reset") return State::Idle;
    return s;                                  // 未定义转移：保持原状态
}

int main() {
    State s = State::Idle;
    for (const std::string& ev : {"start", "fail", "reset"})
        s = on_event(s, ev);
    std::cout << (s == State::Idle ? "back to idle\n" : "other\n");
}
```

```bash
g++ -std=c++17 -Wall -o fsm fsm.cpp && ./fsm
```

## 端到端实战（实测）：速度序列算法流水线

课程自测题的实现：只用算法（count_if/accumulate/transform）完成「超速帧数、平均速度、超速裁剪」，并用 chrono 测量处理耗时：

```cpp
// speed.cpp
std::vector<double> speeds{0.8, 1.2, 0.6, 1.5, 0.9, 2.0, 1.1};

int over = std::count_if(speeds.begin(), speeds.end(),
                         [](double v) { return v > 1.0; });
double avg = std::accumulate(speeds.begin(), speeds.end(), 0.0) / speeds.size();
std::transform(speeds.begin(), speeds.end(), speeds.begin(),
               [](double v) { return std::min(v, 1.0); });   // 裁剪为上限

auto t0 = std::chrono::steady_clock::now();
std::this_thread::sleep_for(50ms);
auto dt = std::chrono::duration_cast<std::chrono::milliseconds>(
              std::chrono::steady_clock::now() - t0);
```

实测（g++ -std=c++17 -Wall -pthread）：

```text
超速帧数=4 平均=1.15714
裁剪后: 0.8 1 0.6 1 0.9 1 1 
控制周期耗时=50 ms
```

要点解析：

- 全程无手写 for 循环：`count_if` 数超速帧、`accumulate` 求均值、`transform` 就地裁剪——声明式一行算法替代三段循环；
- 裁剪用 `std::min(v, 1.0)` 映射原序列，`transform` 的输入/输出迭代器指向同一容器即「就地变换」；
- 计时用 `steady_clock` 单调时钟 + `duration_cast<milliseconds>`，与控制周期测量（`rclcpp::Rate`）同款思路；
- 平均值 `1.15714` 为 `0.8+1.2+0.6+1.5+0.9+2.0+1.1 = 8.1 / 7` 的浮点输出。

## 12.6 与 ROS2 / 机器人开发的关联

1. **时间 API 与 ROS2 时间**：`rclcpp::Time`/`rclcpp::Duration` 与 `std::chrono` 语义对齐（`now() - last_time` 测量控制周期）；`rclcpp::WallRate` 用 `steady_clock` 避免仿真时间暂停影响；`sleep_until` 实现无漂移控制循环。时间戳（`msg->header.stamp`）默认 `system_clock` 语义，跨机同步依赖 NTP/PTP。
2. **回调绑定**：`create_subscription` 的回调常用 `std::bind(&Node::cb, this, _1)` 或 lambda；理解 `std::placeholders` 才能读懂 rclcpp 内部 `AnySubscriptionCallback` 的分发。
3. **STL 算法在机器人数据流**：`transform` 做坐标/单位变换，`copy_if` 过滤离群点，`set_intersection` 做多传感器目标交集，`accumulate` 求航迹累计距离，`shuffle` 做蒙特卡洛粒子重采样。
4. **多线程与 executor**：`rclcpp::executors::MultiThreadedExecutor` + `callback_group::MutuallyExclusive/Reentrant` 本质是 `std::mutex` 与线程管理；理解「打印错乱」就理解了为什么回调里必须加锁或用互斥回调组。
5. **配置与数据交换**：ROS2 参数文件是 YAML、URDF/SDF 是 XML、轨迹/标定常以 CSV 存储；会解析这三种格式是调试机器人系统的日常技能。
6. **状态机与行为管理**：导航任务（待机/巡航/充电/急停）、机器人模式切换用 FSM 建模；nav2 的 behavior tree 可看作状态机的扩展形态。

## 12.7 自测与练习（含参考答案要点）

1. **概念题**：为什么测耗时必须用 `steady_clock` 而不是 `system_clock`？
2. **概念题**：`std::bind` 与 lambda 各自的适用场景？捕获 `this` 时要注意什么（对象生命周期）？
3. **动手任务**：用 `<algorithm>` 实现「找出速度序列中超速（>1.0 m/s）的帧数、平均速度、并把超速值裁剪为 1.0」。验收：只用算法（count_if/accumulate/transform），不手写 for 循环。
4. **动手任务**：实现一个三状态 FSM（Idle/Running/Error），事件 start/fail/reset 驱动转移；再加一个「事件队列」（`std::queue`）逐个消费事件。验收：非法事件保持原状态且打印警告。

> 参考答案要点：题 1——`system_clock` 受 NTP/用户改时间影响可能回拨，测耗时会出现负值；`steady_clock` 单调递增，专为测量设计。题 2——lambda 适合局部、短小、需要捕获局部变量的回调；`bind` 适合适配旧接口/固定成员函数；捕获 `this` 时要保证对象比回调活得久（否则悬垂）。题 3——`count_if(v.begin(), v.end(), [](double x){return x > 1.0;})`、`accumulate` 求均值、`transform` 就地裁剪。题 4——`enum class State` + `on_event()` 转移函数 + `std::queue<std::string> events` 逐个 `pop` 调用。

## 12.8 常见问题（FAQ）

- **Q：`random_shuffle` 为什么不能用了？** A：C++14 弃用、C++17 移除（依赖 `rand()` 且分布不均）；用 `std::shuffle` + `std::mt19937`。
- **Q：`set_intersection` 输出为什么是空的？** A：输入区间未排序；集合算法要求两个输入区间都已按同一比较器排序。
- **Q：`std::bind` 和 lambda 哪个性能好？** A：lambda 通常更好（编译器易内联、语义清晰）；性能差异在现代编译器下极小，选择以可读性为准。
- **Q：智能指针怎么选？** A：默认 `unique_ptr`（独占）；需要共享所有权用 `shared_ptr` + `make_shared`；`weak_ptr` 打破循环引用（缓存、观察者）。
- **Q：`detach` 的线程有什么风险？** A：主线程退出时被强杀、访问已析构对象导致 UB；除非有明确的线程池管理，否则用 `join`。

## 12.9 本章小结

- 把「循环 + 累加/变换」写成一行算法（count_if/accumulate/transform），减少越界与迭代器失效风险；
- `steady_clock` 测量、`system_clock` 日历——用错时钟测耗时会出现负值（真实事故高发点）；
- lambda 捕获 `this` 时保证对象比回调活得久；
- CSV/XML/YAML 三种数据格式的解析（stringstream/getline）是调试机器人系统的日常技能；
- 共享数据必加锁（`lock_guard` 作用域锁），线程用 `join` 而非随意 `detach`；
- 机器人行为天然是状态机：`enum class` + 转移函数/转移表，nav2 行为树是其扩展形态。
