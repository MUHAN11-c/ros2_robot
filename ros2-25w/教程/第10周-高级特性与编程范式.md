# 第10章 高级特性与编程范式（继承多态/模板/异常/IO）

> 本章对应课程第 10 周：继承与多态（虚函数/抽象类/虚析构）、函数模板与类模板、四种类型转换、异常体系与文件 I/O——读懂 rclcpp 继承体系与插件式架构的地基。

## 10.1 案例以及案例分析

**需求**：用抽象类 `Controller`（纯虚 `compute`）统一 PID 与 BangBang 两种控制器，放入多态容器轮询调用；再用函数模板 `clamp` 体会泛型；用异常做参数校验。

## 10.2 知识点与实现

### 10.2.1 继承

- `class Derived : public Base`；public 继承保持访问级别，private 成员对派生类不可见；
- 派生类对象 = 基类子对象 + 新增成员；构造先基类后派生（初始化列表调用指定基类构造），析构相反；
- 同名成员遮蔽（`Base::f()` 显式访问）；多继承慎用，菱形继承用虚继承解决。

### 10.2.2 虚函数与抽象类

- 通过**指针/引用**调用 `virtual` 函数才触发动态联编（vtable）；按值传参会**切片**；
- 纯虚函数 `virtual void f() = 0;` 使类成为抽象类（接口契约）；派生类全部实现才能实例化；
- **基类析构必须 virtual**，否则 `delete Base*` 泄漏；C++11 加 `override` 让编译器检查重写；
- 向上转换安全隐式；向下转换用 `dynamic_cast`（运行期检查，失败得 nullptr）。

### 10.2.3 模板

- 函数模板自动推导/显式指定；显式特化为特定类型定制；优先级：非模板 > 特化 > 通用模板；
- 类模板 `template<typename T> class Box`；成员函数懒实例化；**模板实现必须放头文件**（实例化发生在使用处）。

### 10.2.4 类型转换、异常与 I/O

- `static_cast`（编译期）/`dynamic_cast`（运行期）/`const_cast`/`reinterpret_cast`（危险，仅底层）；
- `throw` → 栈解旋（RAII 对象自动析构）→ `catch (const std::exception& e)` 按引用捕获；ROS2 回调未捕获异常会终止 executor；
- `ofstream/ifstream + getline + <iomanip>` 完成配置与 CSV 读写。

## 10.3 运行效果（实测）

```text
0.575
1
3
caught demo
```

编译命令：`g++ -std=c++17 -Wall w10_poly.cpp -o w10 && ./w10`（PID 输出 0.575、BangBang 输出 1、clamp 得 3、异常被捕获）。

## 10.4 本章小结

- 「抽象基类 + 派生实现」是 rclcpp 节点、`LifecycleNode`、nav2 插件的通用范式；
- 多态容器 `std::vector<std::unique_ptr<Sensor>>` 让新增设备不改主流程（开闭原则）；
- `create_subscription<T>` 是类模板——理解实例化机制才看得懂模板编译错误；
- 实时控制回路里更常用错误码/`std::optional`，异常留给「罕见且不可局部处理」的错误。
