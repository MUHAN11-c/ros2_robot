# 端到端核对验证报告（课程视频 × 本机复现）

> 本报告是深度对照的**端到端版**：不再只对照静态截图，而是回到课程视频文件本身，定位老师「实际运行演示」的段落并抽帧，与 `out/verify/` 中本机的复现输出做**逐条核对**。每条核对链 = 视频文件与时间点 → 视频可见的命令/输出 → 本机复现命令/输出 → 判定。

## ROS2 实战篇核对（第五~八篇，第 14~25 周）

## 核对方法

1. 用 ffprobe 获取目标演示视频时长，在末段（运行结果展示区）抽帧（`out/stills/e2e_*.png`）；
2. 读图提取「视频里的命令与输出」；
3. 在本机按相同机制复现（数据源不同处如实标注），输出存 `out/verify/`；
4. 逐字段比对并给出判定；不一致处修复代码后重跑。

## 过程中发现并修复的问题

1. **lifecycle_py 命名/文案偏差**（本报告③）：节点名与五段日志按视频修正，基类误写为未导入的 `Node` 一并修复（`LifecycleNode`）；
2. **ros2 守护进程缓存损坏**（环境坑，影响面广）：`ros2 node list`/`ros2 lifecycle get` 长时间返回空/"Node not found"，而服务实际已上图——根因是 ros2 daemon 状态陈旧。解法：`ros2 daemon stop` 后重试（daemon 停止时 CLI 直接发现）。此前若干「Node not found」均由此引起，非代码问题。
