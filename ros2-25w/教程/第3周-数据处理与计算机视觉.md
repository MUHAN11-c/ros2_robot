### 3.2.2 第2课 NumPy 数组深入讲解与操作

- **核心概念**：ndarray（N-dimensional array）= 连续内存 + 数据类型（dtype）+ 形状（shape）+ 步长（strides）的多维数组，同构、支持向量化运算，比 Python 列表快一个数量级。
- **创建数组**：`np.array([1,2,3])`、`np.zeros((2,3))`、`np.ones`、`np.full((2,2), 7)`、`np.arange(0, 10, 2)`、`np.linspace(0, 1, 5)`、`np.random.rand(2,3)` / `np.random.randint(0, 10, (2,3))`、`np.eye(3)` 单位矩阵；注意 `np.array([1,2])` 默认 `int64`，混合类型会被提升为 `float64`。
- **常用属性**：`a.shape` 形状（元组）、`a.ndim` 维数、`a.dtype` 元素类型、`a.size` 元素总数、`a.itemsize` 单元素字节数、`a.nbytes` 总字节。拿到传感器数组先看 `shape` 和 `dtype`，能避免一大半 bug。
- **索引与切片**：与列表同语法，多维用 `a[行, 列]`，如 `a[1, 2]`、`a[:, 0]` 取第一列、`a[0:2, 1:3]` 子矩阵；切片得到**视图（view）**，改切片会改原数组，需 `copy()` 才独立。布尔索引 `a[a > 0]`、花式索引 `a[[0, 2]]` 是数据筛选利器。
- **切片实战 - 反转图片**：图像就是 `uint8` 的三维数组 `（H, W, 3）`。`img[:, ::-1]` 左右翻转、`img[::-1, :]` 上下翻转、`img[::-1, ::-1]` 中心翻转——纯切片零拷贝完成图像翻转。
- **形状变换**：`a.reshape(3, 4)`（元素总数不变）、`a.resize`（可改原数组）、`a.ravel()`/`a.flatten()` 拍平（flatten 返回副本）、`a.T` 转置、`a[np.newaxis, :]` 加维度。`reshape(-1, 3)` 中的 `-1` 表示自动推算，把 N 个 3 维点整理成 N×3 矩阵常用。
- **级联合并**：`np.concatenate((a, b), axis=0/1)`、`np.vstack`（垂直堆叠）、`np.hstack`（水平堆叠）、`np.stack`（沿新轴堆叠）、`np.append`。要求非拼接维度一致，否则报 `ValueError`。
- **数组拆分**：`np.split(a, 3, axis=0)`、`np.hsplit`、`np.vsplit`；切分点数量必须能整除对应维度长度。四宫格切图、把彩色图三通道拆开处理都用得上。

### 3.2.3 第3课 数据统计分析与读写操作

- **核心概念**：拷贝语义、聚合（aggregation）、矩阵运算、广播（broadcasting）、排序与持久化。
- **拷贝**：`b = a` 是别名（同一块内存）；`b = a.copy()` 深拷贝数据；`b = a.view()` 是视图（共享内存但 shape 可不同）。判断 `b.base is a` 或 `np.shares_memory(a, b)` 可分辨。
- **聚合统计**：`sum()/mean()/max()/min()/std()/var()/median()`，带 `axis` 参数（`axis=0` 沿列压缩、`axis=1` 沿行压缩、不写则全局）；`argmax()/argmin()` 返回最值下标（找最近障碍物就是 `argmin`）；`np.percentile(a, 95)` 求分位数（剔除激光野值常用）。
- **矩阵运算**：算数运算符作用于数组是**逐元素**运算（`a * b` 对应位置相乘）；矩阵乘法用 `a @ b` 或 `np.dot(a, b)`；转置 `a.T`；求逆 `np.linalg.inv(a)`、解线性方程组 `np.linalg.solve(A, b)`、特征值 `np.linalg.eig(a)`——运动学/标定计算的常用件。
- **广播机制**：形状兼容时，较小数组沿长度为 1 的维度扩展，无需显式复制。规则：从尾部维度对齐，相等或为 1 即可广播；典型应用 `a - a.mean(axis=0)`（每列去均值）、`img / 255.0` 归一化、给图像加常量偏置。
- **排序**：`np.sort(a)`（返回副本）/`a.sort()`（原地）、`np.argsort(a)` 返回排序下标（据此取 Top-K 或同步重排多个数组）、`np.argmax`；`axis` 指定排序维度。
- **读写**：`np.save("a.npy", a)` / `np.load("a.npy")`（二进制、保 dtype、快）；`np.savez("a.npz", x=a, y=b)` 存多个；`np.savetxt("a.csv", a, delimiter=",")` / `np.loadtxt`（文本格式，便于人工查看）；数据集/日志实验建议存 `.npy`，跨语言交换用 CSV。

### 3.2.4 第4课 OpenCV 安装与数据传递

- **核心概念**：OpenCV（Open Source Computer Vision Library）是工业级计算机视觉库，`cv2` 模块的图像即 ndarray（BGR 顺序、`uint8`）。
- **安装与窗口**：`pip install opencv-python`；`cv2.namedWindow("win")` 建窗口，`cv2.imshow("win", img)` 显示，`cv2.waitKey(0)` 等按键（括号内是毫秒数，0 表示永久等待），`cv2.destroyAllWindows()` 收尾。headless 环境（服务器/无显示器）改用 `opencv-python-headless` 并用文件读写代替窗口。
- **读写图片**：`img = cv2.imread(path, cv2.IMREAD_COLOR)`（读失败返回 `None`，务必检查！）、`cv2.imwrite(path, img)`。三种读取模式：`IMREAD_COLOR` 彩色（BGR 三通道）、`IMREAD_GRAYSCALE` 灰度（单通道）、`IMREAD_UNCHANGED` 保留 alpha 通道。
- **摄像头与视频**：`cap = cv2.VideoCapture(0)` 打开摄像头（参数是设备号或视频文件路径），`cap.isOpened()` 检查、`ret, frame = cap.read()` 逐帧读、`cap.get(cv2.CAP_PROP_FPS)` 查帧率、`cap.release()` 释放。循环读帧 + `waitKey(1)` 就是最小视频流程序。
- **视频录制**：`fourcc = cv2.VideoWriter_fourcc(*"mp4v")`，`out = cv2.VideoWriter(path, fourcc, fps, (width, height))`，逐帧 `out.write(frame)`，最后 `out.release()`；注意尺寸要与帧的 `shape[1], shape[0]` 一致。
- **鼠标控制**：`cv2.setMouseCallback("win", on_mouse)` 注册回调，回调签名 `on_mouse(event, x, y, flags, param)`，用 `event == cv2.EVENT_LBUTTONDOWN` 等事件实现点击取点、画框选 ROI（区域）。
- **滑块（trackbar）**：`cv2.createTrackbar("H_min", "win", 0, 179, callback)` + `cv2.getTrackbarPos("H_min", "win")`，实时调 HSV 阈值找颜色时必备，比改代码重跑高效得多。
- **色彩空间**：BGR（OpenCV 默认显示存储顺序）、RGB、GRAY（灰度）、HSV（H 色调 0-179、S 饱和度 0-255、V 明度 0-255）；HSV 把「颜色」与「亮度」解耦，抗光照变化好，颜色识别首选。
- **颜色空间转换**：`cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)`、`cv2.COLOR_BGR2HSV` / `cv2.COLOR_HSV2BGR`、`cv2.COLOR_BGR2RGB`。
- **深拷贝浅拷贝**：`img2 = img` 是别名；`img2 = img.copy()` 深拷贝；切片 `img[0:10, 0:10]` 是视图。图像处理里「原图被改花」几乎都是忘了 `copy()`。

### 3.2.5 第5课 OpenCV 图像绘制与基础处理

- **核心概念**：图像本质是 Mat（在 Python 里就是 ndarray），绘图函数直接在数组上改像素；常用于在图像上标注检测结果。
- **mat 属性**：`img.shape` → `(H, W, C)`（灰度图为 `(H, W)`）、`img.dtype`（通常 `uint8`）、`img.size`；OpenCV 的坐标系是 **(x, y)**，x 是列、y 是行，原点在左上角。
- **分离合并通道**：`b, g, r = cv2.split(img)`、`cv2.merge([b, g, r])`；只处理某一通道（如提取蓝色掩膜）时先 split，改完再 merge。
- **绘图 API**（颜色都是 BGR 元组，`thickness=-1` 表示填充）：
  - `cv2.line(img, (x1,y1), (x2,y2), (0,255,0), 2)` 画直线；
  - `cv2.rectangle(img, (x1,y1), (x2,y2), color, 2)`、`cv2.circle(img, center, r, color, 2)`；
  - `cv2.ellipse(img, center, (a,b), angle, startAngle, endAngle, color, 2)`；
  - `cv2.polylines(img, [pts], True, color, 2)` 画多边形（pts 是 `np.int32` 的点集），`cv2.fillPoly` 填充；
  - `cv2.putText(img, text, org, font, scale, color, thickness)` 画文本。
- **绘制中文**：`cv2.putText` 不支持中文（会显示 `???`），需借助 PIL：`Image.fromarray(...)` + `ImageDraw.text(...` 再 `np.array(...)` 转回 ndarray，或用 `cv2.freetype` 模块加载中文字体文件。
- **算术运算**：加减乘除是**饱和运算**（`uint8` 超过 255 截断为 255）：`cv2.add(img1, img2)`、`cv2.subtract`、`cv2.addWeighted(img1, 0.7, img2, 0.3, 0)`；用 NumPy 直接 `img + 10` 则会**回绕**（250+10=4），这是两种加法的关键差异。
- **图像融合**：`cv2.addWeighted(src1, alpha, src2, beta, gamma)` 实现两张等尺寸图像的加权混合，是水印、曝光合成的基础。
- **几何变换**：缩放 `cv2.resize(img, (w, h))` 或按比例 `fx=, fy=`，插值方式 `cv2.INTER_LINEAR/INTER_AREA（缩小）/INTER_CUBIC（放大）`；翻转 `cv2.flip(img, 1)`（1 左右、0 上下、-1 中心）；旋转 `cv2.getRotationMatrix2D(center, angle, scale)` 得 2×3 矩阵再 `cv2.warpAffine(img, M, (w, h))`。

### 3.2.6 第6课 图像卷积、滤波处理与边缘检测

- **核心概念**：卷积（convolution）是「用一个小矩阵（卷积核/滤波器 kernel）在图像上滑动，对应元素相乘再求和」，输出每个像素是其邻域的加权和。图像的模糊、锐化、边缘提取都可归结为选不同的核。
- **卷积计算**：3×3 核与 3×3 邻域逐元素相乘后求和得到一个输出像素；边缘处需要 padding（补零 `cv2.BORDER_CONSTANT` 或复制 `cv2.BORDER_REPLICATE`）以保持尺寸。核顺时针旋转 180° 再滑动求和才是严格卷积，图像处理里核对称时卷积与相关（correlation）等价，OpenCV 的 `filter2D` 实际做的是相关。
- **滤波处理**：
  - `cv2.filter2D(img, -1, kernel)` 通用卷积，`-1` 表示输出与原图同深度；
  - `cv2.blur(img, (5,5))` 均值滤波（盒式），简单但易糊；
  - `cv2.GaussianBlur(img, (5,5), sigmaX)` 高斯滤波，按高斯权重加权，保边效果好于均值，去高斯噪声首选；
  - `cv2.medianBlur(img, 5)` 中值滤波，取邻域中位数，对**椒盐噪声**特效，且比高斯更保边；
  - `cv2.bilateralFilter(img, d, sigmaColor, sigmaSpace)` 双边滤波，同时考虑空间距离与灰度相似度，**磨皮美颜**效果（保边平滑），但计算量大。
- **边缘检测**：
  - **索贝尔算子（Sobel）**：`cv2.Sobel(img, cv2.CV_64F, dx, dy, ksize=3)` 分别求 x/y 方向梯度，`cv2.convertScaleAbs` 取绝对值回 `uint8`，`cv2.addWeighted` 合并；对噪声有一定抑制；
  - **沙尔算子（Scharr）**：`cv2.Scharr`，比 Sobel 更精确的小核梯度算子，常用于精细边缘；
  - **拉普拉斯算子（Laplacian）**：`cv2.Laplacian(img, cv2.CV_64F)` 二阶导，边缘响应强但对噪声敏感，一般先高斯滤波再拉普拉斯（LoG 思想）；
  - **Canny 边缘检测**：`cv2.Canny(img, threshold1, threshold2)`，流程是高斯平滑 → 求梯度 → 非极大值抑制 → 双阈值 + 滞后连接，效果干净，是边缘检测默认选择。
- **阈值处理**：`cv2.threshold(gray, thresh, maxval, cv2.THRESH_BINARY)` 二值化（还有 `THRESH_BINARY_INV`、`THRESH_TRUNC`、`THRESH_TOZERO`、`THRESH_OTSU` 大津法自动找阈值）；`ret, binary = ...` 中 `ret` 是实际使用的阈值。阈值分割是「把前景从背景里抠出来」的第一板斧。
- **自适应阈值**：`cv2.adaptiveThreshold(gray, 255, cv2.ADAPTIVE_THRESH_MEAN_C/ADAPTIVE_THRESH_GAUSSIAN_C, cv2.THRESH_BINARY, blockSize, C)`，逐邻域计算阈值，应对**光照不均**（阴影、逆光）场景；`blockSize` 取奇数邻域边长，`C` 是常数偏置。

四种滤波的选型速查：

| 滤波 | API | 擅长 | 代价 |
|---|---|---|---|
| 均值 | `cv2.blur` | 快速简单平滑 | 边缘最糊 |
| 高斯 | `cv2.GaussianBlur` | 高斯噪声、通用预处理 | 边缘略糊 |
| 中值 | `cv2.medianBlur` | 椒盐噪声、更保边 | 稍慢 |
| 双边 | `cv2.bilateralFilter` | 保边平滑（美颜、深度图） | 最慢 |

## 3.3 重点与难点

1. **视图 vs 副本**：NumPy 切片是视图、`copy()` 是副本；OpenCV 图像同理，`img2 = img` 只是别名。裁剪 ROI 后直接改像素会影响原图——想要独立数据必须 `copy()`。
2. **广播的对齐规则**：从尾部维度向前对齐，维度相等或其中之一为 1。`shape=(3,1)` 与 `(4,)` 能广播成 `(3,4)`；`(2,3)` 与 `(3,2)` 不能。
3. **BGR 不是 RGB**：OpenCV 读图默认 BGR；用 Matplotlib 显示或与 PyTorch/ROS 里的 RGB 数据交互时必须转换，否则红蓝颠倒。
4. **`uint8` 的饱和与回绕**：`cv2.add` 饱和截断到 255，NumPy 的 `img + 10` 会回绕。做亮度调整推荐 `cv2.add` 或先转 `float32` 运算再 `clip` 回 0-255。
5. **边缘检测参数**：Canny 双阈值「低阈值 2 倍左右是高阈值」的经验起点（如 50/150）；阈值太高边断、太低噪声多。实际项目里用滑块实时调是最有效的方法。
6. **核尺寸（kernel size）的取舍**：滤波核越大越模糊、越抗噪；Sobel/Laplacian 的 ksize 必须是奇数（1, 3, 5, 7）。

> **注意：** `cv2.imread` 读不到文件时返回 `None` 而不是抛异常，后面所有操作都会报 `'NoneType' object has no attribute ...'`。养成 `if img is None: raise FileNotFoundError(path)` 的习惯。

## 3.6 与 ROS2 / 机器人开发的关联

1. **cv_bridge：图像消息与 ndarray 的桥**：`sensor_msgs/Image` 订阅后用 `CvBridge().imgmsg_to_cv2(msg, "bgr8")` 转成 OpenCV 图像处理，再 `cv2_to_imgmsg()` 发回话题——本周所有 OpenCV 操作都直接跑在这条链路上（颜色识别找球、巡线、二维码识别都是这么做的）。
2. **NumPy 处理 LaserScan / IMU / JointState**：`np.array(msg.ranges)` 后可用 `np.isinf` 过滤野值、`argmin` 找最近障碍、`np.median` 平滑；IMU 的加速度/角速度序列做零偏校正与滑动平均，用的全是本周的聚合与广播。点云 `sensor_msgs/PointCloud2` 也常转成 N×3 的 ndarray 处理。
3. **滤波与边缘检测的落点**：导航前的地面分割、车道线/边缘线检测（Sobel + Canny + 阈值）、AprilTag 前的图像预处理（高斯/双边去噪），都是「滤波 → 边缘 → 阈值」流水线的变体；双边滤波的保边平滑也用于深度图去噪。
4. **HSV 阈值 + 滑块调参**：机器人比赛里「找指定颜色的色块/锥桶」流程就是 HSV 转换 + `cv2.inRange` 阈值 + 轮廓提取；用滑块确定 H/S/V 范围后写死到参数文件，是标准调参姿势。
5. **可视化与调试**：节点调试时把检测结果绘框、写文字后发布到 `image` 话题，用 `rqt_image_view` 或 Foxglove 查看；Matplotlib/Jupyter 则用于离线分析 rosbag 导出的数据（`np.load` 回放实验结果）。
6. **性能意识**：图像帧 640×480×3 ≈ 900KB，逐像素 Python 循环会拖垮实时性——一律用 NumPy 向量化和 OpenCV 的 C 实现；采集放线程、处理放回调，正是上周多线程知识的用武之地。

## 3.8 常见问题（FAQ）

- **Q：`cv2.imread` 返回 None 怎么排查？** A：常见原因是路径不对（相对路径取决于当前工作目录）、文件名含中文/特殊字符、文件损坏。用绝对路径验证，读失败立刻 `raise` 并打印路径。
- **Q：shape 是 (480, 640, 3)，哪个是宽哪个是高？** A：NumPy 约定是 (行, 列, 通道) = (高 H, 宽 W, 通道 C)；而 OpenCV 的 `resize` 参数是 (宽, 高)，`img.shape[1], img.shape[0]` 才对——这是高频笔误点。
- **Q：高斯滤波、中值滤波、双边滤波怎么选？** A：高斯噪声/一般平滑 → 高斯；椒盐噪声 → 中值；既要平滑又要保边（美颜、深度图）→ 双边（但慢）。
- **Q：Canny 的两个阈值怎么定？** A：经验起点是低:高 = 1:2 ~ 1:3（如 50/150），再配合滑块微调；图像先高斯滤波能显著减少伪边缘。
- **Q：Jupyter 里 imshow 图像发白/颜色怪？** A：Matplotlib 期望 RGB 而 OpenCV 是 BGR，先 `img = cv2.cvtColor(img, cv2.COLOR_BGR2RGB)`；若用 `plt.imshow` 显示灰度图，加 `cmap="gray"`。

- BGR 不是 RGB：与 Matplotlib/ROS RGB 数据交互前先转换；
