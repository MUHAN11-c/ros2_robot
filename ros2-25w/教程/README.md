# ROS2 机器人应用开发工程师 · 教程（前25周）

> 本教程依据课程视频内容整理，编写格式参考 [zhangzhiwei-zzw 的 ROS2 学习笔记](https://zhangzhiwei-zzw.github.io)：
> **章节采用数字编号（X.Y.Z），每个知识点按「案例以及案例分析 → 流程 → 实现（代码）→ 编译 → 执行 → 运行效果 → 小结」的顺序组织。**
>
> 与参考站点不同的是：本教程全部「运行效果」均为**本机实测**（Ubuntu 24.04 + ROS2 Jazzy，源码工作空间位于 [`code/`](../code/README.md)），
> 每条输出都来自真实运行记录，存档于 `out/verify/`，可直接复现。

## 环境说明

| 项目 | 课程环境 | 本教程实测环境 |
| --- | --- | --- |
| 系统 | Ubuntu 22.04 | Ubuntu 24.04 |
| ROS2 | Humble | **Jazzy**（API 基本一致，差异处已在文中标注） |
| 构建 | colcon | colcon |

## 章节目录

见 [SUMMARY.md](SUMMARY.md)。全书覆盖课程全部 25 周：

- **第一~四篇（第 1~13 周）基础篇**：Python / C / C++ / Linux 与 Shell——每章示例均在本机实际运行，运行效果为真实输出；
- **第五~八篇（第 14~25 周）ROS2 实战篇**：与 `code/` 中 6 个工作空间、63 个功能包一一对应，「运行效果」来自 `out/verify/` 的实测存档，并通过 [深度对照报告](深度对照报告.md) 与课程视频帧逐系列比对。

## 约定

- 代码块标注语言：`cpp` / `python` / `xml` / `yaml` / `bash` / `c`；
- 「运行效果」小节中的输出均为本机实测；ROS2 章节的通过/受阻状态见 [验证矩阵.md](验证矩阵.md)；
- 课程（Humble）与本教程（Jazzy）的 API 差异，在正文以「> 兼容提示」标出。
