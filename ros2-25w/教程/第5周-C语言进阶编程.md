# 第5章 C 语言进阶编程（运算符/控制流/数组）

> 本章对应课程第 5 周：运算符与类型转换、分支与循环（含 switch 状态机雏形）、一维/二维数组与经典算法（翻转、冒泡、最值、频次统计）——机器人状态机、控制循环、传感器缓冲区的雏形。

## 5.1 案例以及案例分析

**需求**：对一组传感器采样值完成「翻转 → 冒泡排序 → 找最大值」，综合运算符、循环与数组下标控制。

## 5.2 知识点与实现

### 5.2.1 运算符与类型转换

- 整数除法截断（`5/2==2`），均值要写 `(double)sum / n`；
- `&&`/`||` 短路求值：`if (p != NULL && p->x > 0)` 防空指针；
- `==` 写成 `=` 是最高频 bug；混合有符号/无符号比较被转为无符号（`-1 < 1u` 为假）；
- 优先级拿不准就加括号；`i++` 与 `++i` 别混用在同一表达式。

### 5.2.2 分支与循环

- `if/else if/else` 范围判断；`switch(整型)+case 常量+break` 适合状态机；
- `while` 先判后执行、`do-while` 至少一次；`for(初始化;条件;步进)` 适合已知次数；
- `break/continue` 只影响最内层循环；水仙花数练习 = 数字拆位（`n%10`、`n/10%10`）。

### 5.2.3 数组

- 连续内存、下标从 0 起、`a[i] == *(a+i)`；**越界不报错直接踩内存**；
- 元素个数 `sizeof(a)/sizeof(a[0])` 只在定义作用域有效，传参后退化为指针；
- 初始化列表未写全的元素补 0；二维数组按行优先存储，`m[i][j]` 背后是线性换算；
- 经典算法：翻转（首尾双指针）、冒泡（每轮冒出最大值，可提前结束）、打擂台找最值、桶计数统计字母频次。

## 5.4 端到端实战（实测）：成绩统计 + 字母频次

二维数组按行/按列两个方向的遍历统计，加上桶计数频次统计——一个程序覆盖本章三个核心场景。

```c
/* grade.c（节选）—— 按行求每人总分、按列求每科总分、桶计数统计字母 */
#include <stdio.h>
#include <string.h>

int main(void)
{
    int score[3][4] = {
        {80, 92, 77, 65},
        {95, 88, 90, 84},
        {70, 66, 75, 80}
    };

    for (int i = 0; i < 3; i++) {              /* 按行：每个学生 */
        int sum = 0;
        for (int j = 0; j < 4; j++) sum += score[i][j];
        printf("学生%d 总分=%d 平均=%.1f\n", i, sum, (double)sum / 4);
    }
    for (int j = 0; j < 4; j++) {              /* 按列：每门课 */
        int sum = 0;
        for (int i = 0; i < 3; i++) sum += score[i][j];
        printf("课程%d 总分=%d 平均=%.1f\n", j, sum, (double)sum / 3);
    }

    char text[] = "ros2 robot uses c language";
    int cnt[26] = {0};
    for (int i = 0; text[i] != '\0'; i++)
        if (text[i] >= 'a' && text[i] <= 'z') cnt[text[i] - 'a']++;
    for (int i = 0; i < 26; i++)
        if (cnt[i] > 0) printf("%c:%d ", 'a' + i, cnt[i]);
    printf("\n长度=%zu\n", strlen(text));
    return 0;
}
```

实测（`gcc -Wall grade.c -o grade && ./grade`）：

```text
== 每个学生（按行） ==
学生0 总分=314 平均=78.5
学生1 总分=357 平均=89.2
学生2 总分=291 平均=72.8
== 每门课（按列） ==
课程0 总分=245 平均=81.7
课程1 总分=246 平均=82.0
课程2 总分=242 平均=80.7
课程3 总分=229 平均=76.3
== 字母频次（top 显示非零项） ==
a:2 b:1 c:1 e:2 g:2 l:1 n:1 o:3 r:2 s:3 t:1 u:2 
长度=26
```

## 5.5 本章小结

- 分支/循环 = 状态机与控制周期（`while (rclcpp::ok())` 就是 while 的形态）；
- `LaserScan.ranges[]`、图像缓冲、代价地图都是「连续内存 + 下标」的数组模型；
- 对 ranges 取最小值做最近障碍判断，就是打擂台思想的直接应用；
- 统一写 `i < n` 防 off-by-one 越界——C 不替你做边界检查。
