# 第7章 C 语言数据结构与文件操作（结构体/联合体/枚举/文件）

> 本章对应课程第 7 周：内存函数（memset/memcpy）、结构体（ROS2 消息类型的 C 原型）、联合体与枚举、文件读写——完成「读文件 → 结构体数组 → 排序 → 写文件」的完整数据流水线。

## 7.1 案例以及案例分析

**需求**：把结构体记录写入二进制文件，再**随机读取**第 2 条——rosbag 索引「按记录号定位」的朴素原理。

## 7.2 知识点与实现

### 7.2.1 内存函数与结构体

- `memset` 清零、`memcpy`（不重叠）/`memmove`（可重叠）拷贝、`memcmp` 按字节比较；
- 结构体聚合字段，同类型可整体赋值；嵌套结构体链式访问 `r.bat.voltage`；
- `sizeof(struct)` ≠ 成员之和——**内存对齐**产生填充；`#pragma pack(1)` 用于通信协议（牺牲性能）；
- 结构体数组 + 冒泡排序 = 小型数据库；传参用指针 `const struct S *` 只读不拷贝；
- 堆上结构体数组：`malloc(n * sizeof(struct S))`，数量运行时才定的场景。

### 7.2.2 联合体与枚举

- `union` 所有成员共享内存，`sizeof` 取最大成员；同一时刻只有一个成员有效；
- 枚举替代魔法数字表达状态（`enum State { IDLE, RUN, ERROR }`）；
- 经典组合是 tagged union：`type 枚举 + union`，用枚举标记当前有效成员（协议解析常用）。

### 7.2.3 文件操作

- `fopen(模式 r/w/a/rb/wb)` 必须判 `NULL`，`perror` 打原因；用完 `fclose`（落盘）；
- 逐字符 `fgetc/fputc`、按行 `fgets/fputs`、格式化 `fprintf/fscanf`、块读写 `fread/fwrite`（返回**块数**）；
- `feof` 正确姿势是**先读后判**；`while (!feof(fp))` 是经典错误；
- 随机读取：`fseek(fp, N*sizeof(Rec), SEEK_SET)`；文件大小 `fseek(END)+ftell` 或 `stat`；
- 读写混合时需 `fseek/fflush` 切换方向；stdio 带缓冲，崩溃/断电丢数据多源于没 `fclose/fflush`。

## 7.3 运行效果（实测）

```text
随机读第2条: id=2 value=2.5
data.bin 总大小 = 48 字节
```

编译命令：`gcc -Wall w7_binfile.c -o w7 && ./w7`（3 条 `struct Rec` 每条 16 字节）。

## 7.4 本章小结

- 结构体 = `.msg` 消息的 C 原型；理解对齐与指针成员才能理解 DDS 序列化与消息 `SharedPtr`；
- tagged union（枚举 + 联合体）是机器人状态与变体数据的通用手法；
- rosbag 二进制记录、YAML/地图/日志落盘全是 `fopen + fread/fwrite/fprintf` 的应用形态；
- 长时间运行的节点若日志不 `fflush`，崩溃会丢最后一段数据——缓冲区机制决定记录器设计。
