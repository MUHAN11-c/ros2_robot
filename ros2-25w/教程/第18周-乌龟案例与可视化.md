## 18.1 静态坐标变换

### 18.1.1 案例以及案例分析

**需求**：广播两个坐标系间的**静态**相对关系（camera ← laser，偏移 x=1 y=2 z=3）。命令行与编码两种方式。

### 18.1.2 实现

命令行：

```bash
ros2 run tf2_ros static_transform_publisher --x 1 --y 2 --z 3 --frame-id camera --child-frame-id laser
```

C++ 编码（`cpp03_tf_broadcaster/src/demo01_static_tf_broadcaster.cpp`，参数从命令行依次传入 x y z roll pitch yaw 父坐标系 子坐标系）：

```cpp
// 3-1.创建静态广播器；
tf_broadcaster_ = std::make_shared<tf2_ros::StaticTransformBroadcaster>(this);
// 3-2.组织 TransformStamped 消息；
ts.header.stamp = this->now();
ts.header.frame_id = father;
ts.child_frame_id = child;
ts.transform.translation.x = x;
// 欧拉角 → 四元数；
tf2::Quaternion qtn;
qtn.setRPY(roll, pitch, yaw);
ts.transform.rotation.x = qtn.x();
...
// 3-3.发布；
tf_broadcaster_->sendTransform(ts);
```

### 18.1.3 运行效果（实测）

```bash
ros2 run cpp03_tf_broadcaster demo01_static_tf_broadcaster 1 2 3 0 0 0 camera laser
ros2 topic echo /tf_static --once
```

```text
transforms:
- header:
    stamp:
      sec: 1792039550
    frame_id: camera
  child_frame_id: laser
  transform:
    translation:
      x: 1.0
      y: 2.0
      z: 3.0
    rotation:
      x: 0.0
      y: 0.0
      z: 0.0
      w: 1.0
```

Python 版（`py03_tf_broadcaster`）输出一致。

## 18.2 动态坐标变换

### 18.2.1 案例以及案例分析

**需求**：订阅乌龟位姿 `/turtle1/pose`，将**世界坐标系 world 相对乌龟 turtle1** 的动态关系实时发布（`TransformBroadcaster`）。

### 18.2.2 运行效果（实测）

启动乌龟后运行动态广播器，`ros2 topic echo /tf --once`：

```text
transforms:
- header:
    frame_id: world
  child_frame_id: turtle1
  transform:
    translation:
      x: 5.544444561004639
      y: 5.544444561004639
```

乌龟运动时 `translation` 以约 60Hz 实时更新——这就是「动态」的含义。

## 18.3 坐标监听与实操案例

### 18.3.1 坐标系变换（监听）

**需求**：监听 camera 与 laser 间的变换，将「laser 下的坐标点」变换到 camera 坐标系，或打印两坐标系关系。

实测（`cpp04_tf_listener`，配合 18.1 的静态广播）：

```text
[INFO] [...]: -----------转换完成的坐标帧信息-----------
[INFO] [...]: 新坐标帧:父坐标系:camera,子坐标系:laser,偏移量(1.00,2.00,3.00)
```

> 兼容提示：`lookupTransform("camera","laser",tf2::TimePointZero)` 中第三个参数在 rclcpp 中使用 `tf2::TimePointZero`（0 代表最新可用变换）。

### 18.3.2 坐标点变换监听（补充实测）

**需求**：订阅 `turtle1` 坐标系下的坐标点，利用 tf 缓存把它变换到 `world` 坐标系输出——「坐标系变换」之外的第二种监听形态。

C++ 实现（`cpp04_tf_listener/src/demo02_point_listener.cpp`）核心：

```cpp
// 订阅 /turtle1/point (PointStamped)，回调中经 tf 缓存变换到 world
geometry_msgs::msg::PointStamped out;
tf2::doTransform(*point, out,
    buffer_->lookupTransform("world", point->header.frame_id, tf2::TimePointZero));
```

Python 实现（`py03_tf_broadcaster/demo02_point_listener_py.py`）：

```python
self.buffer = Buffer()
self.listener = TransformListener(self.buffer, self)   # Jazzy 需传入节点对象
out = self.buffer.transform(point, "world", timeout=rclpy.duration.Duration(seconds=1.0))
```

> 兼容提示（Python 两处易错点）：① `TransformListener(buffer)` 单参数写法在 Jazzy 下订阅不生效，必须传节点对象；② 必须显式 `import tf2_geometry_msgs`，否则 `buffer.transform()` 报 `Type ... is not loaded or supported`（转换器靠该模块注册）。

端到端实测（静态广播 world→turtle1 平移 (1,2,0)，注入 turtle1 系下的点）：

```bash
ros2 run tf2_ros static_transform_publisher --x 1 --y 2 --z 0 --frame-id world --child-frame-id turtle1
ros2 run cpp04_tf_listener demo02_point_listener
ros2 topic pub --once /turtle1/point geometry_msgs/msg/PointStamped "{header: {frame_id: turtle1}, point: {x: 0.5, y: 0.5, z: 0}}"
```

```text
[INFO] [...]: [point_listener_node_cpp]: 坐标点(0.50,0.50) 变换到 world 系下: (1.50,2.50)
[INFO] [...]: [point_listener_node_cpp]: 坐标点(1.00,1.00) 变换到 world 系下: (2.00,3.00)
```

Python 版输出相同（(0.5,0.5)→(1.5,2.5)）。数学自检：world 系偏移 (1,2) + turtle1 系点坐标 = (1.5,2.5) ✓。

### 18.3.3 乌龟跟随（实操）

**需求**：生成两只乌龟，乌龟 t2 始终跟随 turtle1（保持距离 2m）。

实现分三部分：

1. **广播器**（exer02）：订阅 `/<turtle>/pose`，发布 `world → <turtle>`（乌龟名由参数 `turtle` 指定）；
2. **监听器**（exer03）：参数 `father_frame`/`child_frame`，计算两龟位移与朝向差，按比例发布 `/<father>/cmd_vel`：
   `linear.x = 0.5 * sqrt(dx²+dy²)`、`angular.z = 1.0 * atan2(dy,dx) - father_theta`；
3. **launch**（follow_launch.py）：一次生成乌龟 t2、两个广播器（turtle 参数 t1/turtle1、t2）、一个监听器。

实测 `ros2 launch cpp05_exercise follow_launch.py` 可见 t2 生成且全程跟随第一只乌龟（键盘控制 turtle1 时 t2 自动跟随，视频效果一致）。

**乌龟护航**（escort_launch.xml）：监听器在两龟之间再加一层目标点偏移（保持固定方位跟随），XML 版 launch 组织节点。

## 18.4 URDF 建模与 Xacro 优化

### 18.4.1 URDF 集成 rviz2

**需求**：用 URDF 描述两轮差速小车（base_footprint → base_link → 左右驱动轮 + 前万向轮），经 robot_state_publisher 发布 `/robot_description` 与 `/tf`，rviz2 可视化。

实测 `ros2 launch cpp06_urdf display_urdf_launch.py`，三个进程正常拉起：

```text
[INFO] [robot_state_publisher-1]: process started with pid [408700]
[INFO] [joint_state_publisher-2]: process started with pid [408701]
[INFO] [rviz2-3]: process started with pid [408702]
```

单独运行 robot_state_publisher 加载 urdf02_car.urdf 的实测日志：

```text
[INFO] [...]: [robot_state_publisher]: Robot initialized
```

URDF 非法时会直接解析报错，可用于语法校验。

### 18.4.2 Xacro 优化

用 **property（属性）+ macro（宏）** 消除 URDF 中左右轮的重复定义：

```xml
<xacro:property name="wheel_radius" value="0.05"/>
<xacro:macro name="wheel_macro" params="wheel_name lr yaw">
    <joint name="${wheel_name}_joint" type="continuous">
        <origin xyz="0 ${lr*0.16} 0" rpy="0 0 ${yaw}"/>
        ...
```

实测展开（验证宏/属性语法）：

```bash
xacro xacro/xacro_car.xacro
```

输出为展开后的标准 URDF XML（`out/verify/ws01/c_xacro_expand.log`），可经 robot_state_publisher 正常加载。

## 18.5 本章小结

- 静态/动态广播分别使用 `StaticTransformBroadcaster` 与 `TransformBroadcaster`；
- 监听端 `Buffer + TransformListener + lookupTransform`，时间参数传 `tf2::TimePointZero`；
- 跟随/护航实操 = 广播器 × 2 + 监听器（速度公式线性化）+ launch 集成；
- URDF 描述结构，Xacro 消除重复；`xacro` 命令可离线展开验证。
