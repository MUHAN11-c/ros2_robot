## 这个方向是做什么的

机器人软件的工业界通用语是 C++：机械臂以 1 kHz（每毫秒一次）的频率解算控制律，自动驾驶系统里感知与规划的延迟以毫秒计，ROS2 的核心节点几乎都用 C++ 编写。Python 适合做实验与验证，但**上真机、进产品、抢实时**，最后都要落到 C++。本方向的目标：从入门到能写出**实时、稳定、可维护**的机器人 C++ 工程。

一个生活化的例子：点外卖时，平台要在几秒内把几十万订单分配给骑手——分配策略（算法）好比你的机器人逻辑，而 C++ 好比那个能在高峰期也不崩的调度系统本身：**同样的策略，跑得快不快、稳不稳，看的就是它。**

本方向覆盖三个层次：

| 层次 | 内容 | 在机器人上的样子 |
|---|---|---|
| 筑基工具 | 语法、指针与内存、类、STL | 能读懂并改写一个 ROS2 示例节点 |
| 本科核心 | 现代类设计、RAII、移动语义、模板入门 | 写出不泄漏内存、异常安全的模块 |
| 研究生级 | 并发、模板元编程、CMake 工程、库剖析 | 实时控制线程、SLAM 后端工程化 |

!!! note "和别的方向什么关系"
    C++ 是机器人三大应用方向（SLAM/规控/具身）共同的"施工工具"。SLAM 方向的 Eigen/Ceres、规控方向的 OSQP 与实时线程、仿真接口，全部由本方向的深层章节支撑。工具不牢，地图上的资源点再多也捡不走——这是本方向存在的意义。

第一阶的主线串法：以《Effective C++》为骨架，每读完一组条款就回来刷本站对应章，并用一条铁律验收——**凡是 new 出来的东西，都要说得出谁在什么时候 delete；说不出来，就换成智能指针。** 建议顺序：

1. 条款 1-17 → 本站类型系统、类设计、RAII 三章；
2. 条款 18-31 → 设计模式、异常安全两章；
3. 条款 32-55 → 继承多态、模板入门、编译模型三章；
4. 全程穿插《Effective Modern C++》对应条款，把老规则升级到 C++11/14 语境。

## 教材书单总表

看教材前先对齐"C++ 标准"这张时间线（本站以 C++17 为基线）：

| 标准 | 年份 | 关键特性 | 机器人生态里的样子 |
|---|---|---|---|
| C++98/03 | 1998/2003 | 模板、STL 标准化 | 老代码与老教材的"考古层" |
| C++11 | 2011 | 智能指针、移动语义、Lambda、线程库 | 现代机器人代码的底座 |
| C++14 | 2014 | 泛型 Lambda、返回值推导 | 顺手的小糖 |
| C++17 | 2017 | 结构化绑定、optional/variant、并行算法 | ROS2 与主流库的公共基线 |
| C++20 | 2020 | Concepts、Ranges、协程 | 新库逐步采用，读源码会遇到 |
| C++23 | 2023 | 更多范围与工具类 | 暂按"认识即可"处理 |

## 常见问题

**Q1：要先学 Python 再学 C++ 吗？**
不是硬前置。本站把两者并列在筑基（[15_Python与工具链](15_Python与工具链/10_Python与NumPy入门_面向机器人.md)）：Python 用于快速验证算法、处理数据，C++ 用于真机与实时部分。 robotics 的常态是"Python 原型 + C++ 落地"，两个都会是最优解。

**Q2：《C++ Primer》七百多页要全读吗？**
不要。第〇阶 7 章已经把主干抽出来并改成入门讲法，Primer 只作为"教材对照"字典：本站每章开头会告诉你这一章对应 Primer 哪几节，读不懂本站时去查原文即可。从头到尾硬啃 Primer 是劝退率最高的路线。

**Q3：C++11/14/17/20/23，到底学哪个标准？**
以 **C++17 为基线**（ROS2 与主流库的公共交集），C++11/14 的现代特性是地基（本站第一阶覆盖），C++20 的 Concepts 等放在第三阶（[160_Concepts与Policy](10_C++语言核心/160_Concepts与Policy.md)）。新标准是加分项，不是入场券。

**Q4：《STL 源码剖析》讲的是老式 SGI STL，会不会过时？**
容器与迭代器的**设计思想**没有过时——这份理解会让你在用 Eigen、读任何模板库时受益。具体的实现细节请以 cppreference 与现行标准为准，遇到老实现与现代实现不一致的地方，以本站深层章（[50_内存分配策略与pmr](20_并发与系统编程/50_内存分配策略与pmr.md)）的现代对应物补齐。

**Q5：什么时候可以开始碰 ROS2？**
筑基第 4 章（指针与内存）之后就可以去 [40_ROS2初体验_小海龟仿真](../07_机器人学导论/40_ROS2初体验_小海龟仿真.md) 玩起来，建立兴趣；系统性地用 C++ 写 ROS2 节点，建议放在第一阶 RAII/类设计之后，否则写出来的节点会在内存与回调线程上反复踩坑。

**Q6：需要背 STL 容器的复杂度表吗？**
要"会用"不要"硬背"：vector 尾插 O(1)、map 查询 O(log n)、unordered_map 平均 O(1)，这三条覆盖九成场景；其余用到时查 cppreference，写多了自然长在手上。真想知道"为什么是这个复杂度"，那就是《STL源码剖析》登场的时候。

**Q7：在 Windows 还是 Linux 上学？**
筑基两栖皆可：环境搭建章给出 Windows 直装与 WSL 双方案（见 [00_C++学习地图与环境搭建](00_入门/00_C++学习地图与环境搭建.md)）。但 ROS2 与 SLAM 生态以 Ubuntu 为主，最迟在第一阶结束前，把主战场迁到 Linux（或 WSL2）。

**Q8：先学 C 语言打基础吗？**
不是必须。本站直接从现代 C++ 起步（[10_第一个程序_变量与基本类型](00_入门/10_第一个程序_变量与基本类型.md)），只在指针与数组处点一句"C 语言里怎么写"作对照。学校若教 C，正常跟课即可，两者底层内存模型一致，互相不冲突。

**Q9：学到什么程度可以进实验室或找机器人方向的实习？**
最低配：筑基 7 章自测全部通过 + 第一阶 RAII/类设计三章过关 + 能用 Git 提交规范的 commit。进组第一周大概率是"读懂别人写的节点"，那时 [10_设计哲学与架构演进](50_ROS2工程化/10_设计哲学与架构演进.md) 会救你一命。

**Q10：模板看不懂，是不是说明不适合干这行？**
不是。模板是"库作者语法"，第一次看不懂是常态——先会用模板库（vector 就是模板），需要读库源码（Eigen、Ceres）时再按 [120_函数模板与类模板基础](10_C++语言核心/120_函数模板与类模板基础.md) 一路补上来。成长顺序是"用 → 读 → 写"，别在第一步就逼自己写模板元编程。
