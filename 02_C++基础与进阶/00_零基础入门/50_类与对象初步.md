## 1. 从生活到概念：图纸与实物

想象一座精密的**人偶**工坊：一张**图纸**决定了人偶"有哪些部件、会做什么动作"，但图纸本身不是人偶；照图纸造出来的、能活动的每一个实体才是。同一张图纸可以造出许多人偶，每个人偶的电量、位置各不相同。

程序里对应的两个词：

- **类（Class）** = 图纸：定义"有哪些数据、有哪些行为"；
- **对象（Object）** = 实物：按图纸创建出来的具体实体，每个对象有自己独立的一份数据。

> ⚠ **类比在哪里失效**：图纸和实物是两种纸/材质，但 C++ 的类只是编译期的一段**描述**，本身几乎不占运行内存；内存是在创建对象那一刻才分配的。另外本章的"类"还没有继承、多态这些进阶特征——那是后续篇目的事。

## 2. struct 复习：先把数据打包

> 📖 教材对照：C++ Primer 第5版 §7.1

上一章你已初见 `struct`。它解决的问题很单纯：**把几个相关的变量装进一个包**，免得函数参数写一长串。

```cpp
#include <iostream>
#include <string>
using namespace std;

struct RobotState {        // struct：只装数据，不装行为
    string name;
    double x;              // 位置 x（米）
    double y;              // 位置 y（米）
    double battery;        // 电量（百分比）
};

int main() {
    RobotState r1 = {"alpha", 1.5, 2.0, 87.0};   // 按声明顺序给成员赋值
    r1.battery = 80.0;                            // 点号访问并修改成员

    cout << r1.name << " 在 (" << r1.x << ", " << r1.y << ")"
         << "，电量 " << r1.battery << "%" << endl;
    return 0;
}
```

```text
alpha 在 (1.5, 2)，电量 80%
```

struct 有个天然烦恼：**数据裸奔**。任何代码都能写 `r1.battery = 999;`——电量冲到 999%，规则全靠大家自觉。数据一多、代码一长，"谁都能随手改"就是 bug 温床。

| | struct（裸数据包） | class（数据+行为+规则） |
|---|---|---|
| 装什么 | 只有数据 | 数据 + 操作数据的函数 |
| 谁能改数据 | 任何人、任何地方 | 由类自己决定（见 3.2） |
| 保证一致性 | 靠约定 | 类内的函数负责守规矩 |

> ◇ C++ 里 `struct` 和 `class` 的唯一默认区别：struct 成员默认公开，class 成员默认私有。习惯上，**纯数据包用 struct，带行为的用 class**。

## 3. class：数据与操作绑在一起

> 📖 教材对照：C++ Primer 第5版 §7.1、§7.2

### 3.1 第一个类：数据 + 成员函数

**成员变量（Member Variable）** 是类里声明的数据；**成员函数（Member Function）** 是类里定义的、操作这些数据的函数。两者写在一起，就叫"类内定义"：

```cpp
#include <iostream>
#include <string>
using namespace std;

class Robot {                       // 图纸开始画了
public:                             // 公开区（见 3.2）
    string name_;                   // 成员变量：叫什么
    int battery_;                   // 成员变量：电量百分比

    void report() {                 // 成员函数：机器人自己的行为
        cout << "我是 " << name_ << "，电量 " << battery_ << "%" << endl;
    }
};

int main() {
    Robot r1;                       // 照图纸造一台（创建对象）
    Robot r2;                       // 再造一台：两台数据互不干扰
    r1.name_ = "alpha";  r1.battery_ = 90;
    r2.name_ = "beta";   r2.battery_ = 70;

    r1.report();                    // r1 调用 report，用的是 r1 自己的数据
    r2.report();
    return 0;
}
```

```text
我是 alpha，电量 90%
我是 beta，电量 70%
```

注意 `r1.report()` 的读法："请 r1 这个对象执行 report"——同一个函数，作用在哪个对象上，就用哪个对象的数据。

### 3.2 public / private：封装的意义

**封装（Encapsulation）** 是 OOP 的第一根支柱：把数据藏起来（`private`），只通过指定的窗口（`public` 函数）访问，让规则由类自己来守。

```cpp
#include <iostream>
#include <string>
using namespace std;

class Robot {
private:                        // 私有区：类外面的代码碰不到
    string name_;
    int battery_;

public:                         // 公开区：对外的"服务窗口"
    Robot(string name, int battery) {   // 构造函数：与类同名、不写返回类型
        name_ = name;
        battery_ = battery;
    }
    void charge(int wh) {               // 想充电？必须走这个窗口
        battery_ += wh;
        if (battery_ > 100) battery_ = 100;   // 规则由类守：永远不超 100
    }
    void report() {
        cout << name_ << " 电量 " << battery_ << "%" << endl;
    }
};

int main() {
    Robot r("alpha", 90);
    // r.battery_ = 999;      // 取消注释：编译报错！battery_ 是私有的
    r.charge(50);             // 90 + 50 想冲到 140？类内规则封顶 100
    r.report();
    return 0;
}
```

```text
alpha 电量 100%
```

| 访问级别 | 谁能用 | 用途 |
|---|---|---|
| `public:` | 任何人 | 对外提供的服务窗口（行为） |
| `private:` | 只有类自己的成员函数 | 内部数据与内部细节，防止外界乱改 |

**封装的意义一句话：让"非法状态"无法被构造出来。** 电量 999、位置跑到无穷远——这些荒谬状态从编译期就被挡在门外。

### 3.3 构造函数：出生仪式

**构造函数（Constructor）** 在对象创建的那一刻自动执行，负责把成员设置成合法初值。它有三个要点：与类同名、不写返回类型、可以重载（多个版本共存）。

```cpp
#include <iostream>
using namespace std;

class Motor {
public:
    Motor() : rpm_(0) {                     // 版本一：默认构造（无参数）
        cout << "默认构造: 0 rpm" << endl;
    }
    Motor(int rpm) : rpm_(rpm) {            // 版本二：带参构造
        cout << "带参构造: " << rpm_ << " rpm" << endl;
    }
    int rpm() const { return rpm_; }
private:
    int rpm_;
};

int main() {
    Motor m1;              // 调用默认构造。注意：不写括号！
    Motor m2(180);         // 调用带参构造
    cout << m2.rpm() << endl;
    return 0;
}
```

```text
默认构造: 0 rpm
带参构造: 180 rpm
180
```

冒号后面那截 `: rpm_(rpm)` 叫 **成员初始化列表（Member Initializer List）**，是给成员"接生"的规范写法。它和"在函数体里赋值"的区别：

| | 初始化列表 `: rpm_(rpm)` | 函数体里 `rpm_ = rpm;` |
|---|---|---|
| 发生时机 | 成员出生**直接带值** | 先默认出生，再改一遍 |
| 性能 | 一步到位 | 可能多做一次赋值 |
| 必须| `const` 成员、类类型成员只能用它初始化 | 对这些成员直接报错 |

> 📖 教材对照：C++ Primer 第5版 §7.1.2（this 与构造函数）、§7.5.1（构造函数初始值列表）

**习惯约定**：成员变量名加下划线后缀（`rpm_`），一眼区分"这是成员"还是"这是参数"。

### 3.4 析构函数：告别仪式

**析构函数（Destructor）** 在对象消亡时自动执行，名字是 `~类名`，不接收参数。它回答的问题是："这台机器人下线前，要不要归还点什么？"

```cpp
#include <iostream>
#include <string>
using namespace std;

class Robot {
public:
    Robot(string name) : name_(name) {
        cout << name_ << " 上线" << endl;      // 出生时自动调用
    }
    ~Robot() {                                  // 析构：波浪号 + 类名
        cout << name_ << " 下线" << endl;      // 消亡时自动调用
    }
private:
    string name_;
};

int main() {
    Robot a("alpha");
    cout << "--- 进入内层块 ---" << endl;
    {
        Robot b("beta");       // 局部对象：活在这一对花括号里
    }                          // 离开花括号，b 立刻析构
    cout << "--- 离开内层块 ---" << endl;
    return 0;                  // main 结束，a 析构
}
```

```text
alpha 上线
--- 进入内层块 ---
beta 上线
beta 下线
--- 离开内层块 ---
alpha 下线
```

两个对象，出生顺序 a→b，消亡顺序 b→a——**后造的先走**（像栈一样）。析构函数"必然、自动、确定时机"地执行，正是上一章智能指针能自动归还内存的底层机制。

> 📖 教材对照：C++ Primer 第5版 §13.1（析构函数，直觉版）

### 3.5 this 指针：对象如何指认"自己"

成员函数被调用时，编译器偷偷传进来一个指针 **this**，指向"正在执行本次调用的那个对象自己"。平时看不见它，但两种场合会显式用到：

```cpp
#include <iostream>
using namespace std;

class Counter {
public:
    Counter& add(int n) {
        value_ += n;
        return *this;          // *this 就是"我自己"：返回自己以支持链式调用
    }
    int value() const { return value_; }
private:
    int value_ = 0;            // 类内默认初始化：成员的"出厂默认值"
};

int main() {
    Counter c;
    c.add(1).add(2).add(3);    // 链式调用：上一步返回自己，下一步接着用
    cout << c.value() << endl;
    return 0;
}
```

```text
6
```

`c.add(1)` 返回的就是 c 自己，所以能立刻接着 `.add(2)`——链式调用能成立，全靠 `return *this`。

## 4. 类外定义成员函数：.h / .cpp 分离初见

> 📖 教材对照：C++ Primer 第5版 §7.3

真实工程不会把所有代码塞进一个文件。标准做法是**声明与实现分离**：头文件（.h）写"类长什么样"，源文件（.cpp）写"函数具体怎么做"。完整三文件示例：

**battery.h（声明：类长什么样）**

```cpp
#ifndef BATTERY_H          // "包含保护"：防止头文件被重复包含，先照抄
#define BATTERY_H
#include <string>

class Battery {
public:
    Battery(std::string brand, double capacityWh);  // 只有声明，函数体在 .cpp
    void charge(double wh);
    double level() const;
private:
    std::string brand_;
    double remainWh_;      // 剩余电量（瓦时）
    double capacityWh_;    // 总容量（瓦时）
};
#endif
```

**battery.cpp（实现：函数怎么做）**

```cpp
#include "battery.h"           // 包含自己对应的头文件

// 作用域符 :: 读作"属于"：Battery::charge 即"Battery 类的 charge 函数"
Battery::Battery(std::string brand, double capacityWh)
    : brand_(brand), remainWh_(capacityWh * 0.5), capacityWh_(capacityWh) {}
    // 约定：出厂时电量为总容量的一半

void Battery::charge(double wh) {
    remainWh_ += wh;
    if (remainWh_ > capacityWh_) {
        remainWh_ = capacityWh_;       // 充满为止，绝不充爆
    }
}

double Battery::level() const {
    return remainWh_ / capacityWh_;    // 返回 0~1 的比例
}
```

**main.cpp（使用：拿图纸造实物）**

```cpp
#include <iostream>
#include "battery.h"
using namespace std;

int main() {
    Battery bat("樱机动力", 100.0);   // 造一块 100 Wh 的电池（出厂 50 Wh）
    cout << "当前电量: " << bat.level() << endl;
    bat.charge(30.0);                 // 充 30 Wh
    cout << "充电后: " << bat.level() << endl;
    return 0;
}
```

**编译与运行**（注意把所有 .cpp 一起交给编译器）：

```bash
g++ main.cpp battery.cpp -o battery_app -std=c++17
./battery_app            # Windows 下运行 battery_app.exe
```

```text
当前电量: 0.5
充电后: 0.8
```

| 文件 | 装什么 | 为什么 |
|---|---|---|
| `xxx.h` | 类的声明、成员函数签名 | 让其他文件"知道有这个东西"（`#include` 复制声明） |
| `xxx.cpp` | 成员函数的实现 | 实现细节只编译一次，改实现不必重编全世界 |
| `main.cpp` | 使用方 | 只 `#include "xxx.h"`，不关心实现 |

> ◇ 头文件里的字符串前缀写 `std::string` 而不是 `using namespace std;`——头文件会被别人包含，擅自放开命名空间等于替所有人做决定，是工程大忌。ROS 源码里到处是 `std::`，就是这个原因。

## 5. 动手算一算：对象数组与 vector\<机器人\>

类是"图纸"，容器装的是"实物"——`vector<Robot>` 就是"一支机器人小队"。手动演算下面这段：构造 3 台，逐台检查电量：

| 步骤 | fleet 内容（名字:电量） | 动作 |
|---|---|---|
| 1 | （空） | 造 alpha:90，放入小队 |
| 2 | [alpha:90] | 造 beta:75，放入小队 |
| 3 | [alpha:90, beta:75] | 造 gamma:98，放入小队 |
| 4 | [alpha:90, beta:75, gamma:98] | 遍历，逐台 report |

```cpp
#include <iostream>
#include <string>
#include <vector>
using namespace std;

class Robot {
public:
    Robot(string name, int battery) : name_(name), battery_(battery) {}
    string name() const { return name_; }       // 读取器的标准写法：const、只返回值
    int battery() const { return battery_; }
private:
    string name_;
    int battery_;      // 电量百分比
};

int main() {
    vector<Robot> fleet;                       // 一支空的小队
    fleet.push_back(Robot("alpha", 90));       // 造一台，直接放进小队
    fleet.push_back(Robot("beta", 75));
    fleet.push_back(Robot("gamma", 98));

    for (const Robot& r : fleet) {             // const 引用遍历：不拷贝对象（上一章）
        cout << r.name() << " 电量 " << r.battery() << "%" << endl;
    }
    cout << "小队共 " << fleet.size() << " 台" << endl;
    return 0;
}
```

```text
alpha 电量 90%
beta 电量 75%
gamma 电量 98%
小队共 3 台
```

因为成员是私有的，外界只能通过 `name()`、`battery()` 这些公开读取器看数据——封装在容器场景里依然生效。

## 6. 小贴士：std::pair 与结构化绑定

函数想一次返回"两个东西"（比如最重部件的名字和重量），不用专门造一个 struct，标准库提供了现成的 **键值对（Pair）** 模板 `std::pair`：

```cpp
#include <iostream>
#include <string>
#include <vector>
#include <utility>       // std::pair 所在的头文件
using namespace std;

// first 是名字，second 是重量
pair<string, double> heaviestPart(const vector<pair<string, double>>& parts) {
    pair<string, double> best = parts[0];
    for (const pair<string, double>& p : parts) {
        if (p.second > best.second) {    // 逐个比较重量
            best = p;
        }
    }
    return best;
}

int main() {
    vector<pair<string, double>> parts = {
        {"lidar", 0.45}, {"battery", 1.20}, {"arm", 0.90}
    };

    pair<string, double> result = heaviestPart(parts);
    cout << result.first << " 最重，" << result.second << " kg" << endl;

    auto [name, weight] = heaviestPart(parts);   // C++17 结构化绑定：一行拆开两个值
    cout << name << " 重 " << weight << " kg" << endl;
    return 0;
}
```

```text
battery 最重，1.2 kg
battery 重 1.2 kg
```

`auto [name, weight] = ...` 叫**结构化绑定（Structured Binding）**：把 pair 的 first、second 一次性拆进两个新变量，可读性大幅提升（auto 的完整故事下一章讲）。C++ 的 map 遍历出的每个元素就是 pair，这个语法到下一章天天用。

## 7. 和机器人有什么关系：把两轮差速小车抽象成类（贯穿实例）

**差速驱动（Differential Drive）** 是最常见的移动机器人底盘：左右两个独立驱动的轮子，靠"两轮速度差"转弯。现在把它完整建模成类——成员变量是它的状态，成员函数是它的行为。完整程序约 80 行，分 4 块走读，拼起来即可编译运行。

**块 1/4：数据与出生（成员变量 + 构造函数）**

```cpp
// diff_drive.cpp —— 编译：g++ diff_drive.cpp -o diff_drive -std=c++17
#include <iostream>
#include <cmath>        // cos、sin 在这里
#include <iomanip>      // setprecision：控制小数位数，照抄即可
using namespace std;

struct Pose {              // 位姿：位置 (x, y)（米）+ 朝向 theta（弧度）
    double x, y, theta;
};

class DiffDriveRobot {
private:                       // 状态全部私有：外界不能乱改
    double vLeft_;             // 左轮线速度（米/秒）
    double vRight_;            // 右轮线速度（米/秒）
    double x_, y_, theta_;     // 当前位姿
    double wheelBase_;         // 两轮间距（米）

public:
    DiffDriveRobot(double x0, double y0, double theta0, double wheelBase)
        : x_(x0), y_(y0), theta_(theta0),        // 成员初始化列表（3.3 节）
          wheelBase_(wheelBase), vLeft_(0.0), vRight_(0.0) {}
    // 出生即合法：位置、朝向、轮距在构造时一次定好，速度默认静止
```

**块 2/4：观察与指令（getPose / printStatus / setWheelSpeed）**

```cpp
    void setWheelSpeed(double vl, double vr) {   // 下指令：设定左右轮速
        vLeft_ = vl;
        vRight_ = vr;
    }

    Pose getPose() const {                       // 只读查询：当前位姿
        return Pose{x_, y_, theta_};             // 用 struct Pose 打包返回
    }

    void printStatus() const {                   // 只读打印（const 表示不改成员）
        cout << fixed << setprecision(3)         // 小数固定保留 3 位
             << "位姿: x=" << x_ << "  y=" << y_
             << "  theta=" << theta_ << " rad" << endl;
    }
```

**块 3/4：运动（update 位姿积分——差速驱动运动学直觉版）**

机器人每走一小步 dt 秒，位姿如何变化？两个直觉公式：

$$v = \frac{v_L + v_R}{2} \qquad \omega = \frac{v_R - v_L}{W}$$

（$v_L$、$v_R$ 是左、右轮速，$W$ 是轮距，$\omega$ 读作"欧米茄"，表示角速度。）

两轮同速则直线走（$\omega = 0$）；右快左慢则向左转（$\omega > 0$，逆时针为正）。把 dt 切得足够小，每步"先转再走"，就是**位姿积分（Pose Integration）**：

```cpp
    void update(double dt) {                     // 前进 dt 秒
        double v = (vLeft_ + vRight_) / 2.0;         // 车体线速度 = 两轮平均
        double w = (vRight_ - vLeft_) / wheelBase_;  // 角速度 = 轮速差 ÷ 轮距
        theta_ = theta_ + w * dt;                    // 第一步：先转
        x_ = x_ + v * cos(theta_) * dt;              // 第二步：沿新朝向前进
        y_ = y_ + v * sin(theta_) * dt;
    }
};   // 类定义到此结束
```

**手动演算一个周期**（轮距 W = 0.3 m，dt = 0.1 s，两轮各 0.5 m/s）：v = (0.5+0.5)/2 = 0.5，ω = (0.5−0.5)/0.3 = 0，theta 不变，每步 x 增加 0.5 × cos(0) × 0.1 = 0.05 m；10 步后 x = 0.5 m。

**块 4/4：让小车跑起来（main）**

```cpp
int main() {
    DiffDriveRobot robot(0.0, 0.0, 0.0, 0.30);   // 原点出发，朝向 x 正方向，轮距 0.3 m
    robot.printStatus();

    robot.setWheelSpeed(0.5, 0.5);               // 两轮同速：直行
    for (int i = 0; i < 10; i++) {
        robot.update(0.1);                       // 每步 0.1 秒，共 1 秒
    }
    robot.printStatus();                         // 预期 x≈0.5

    robot.setWheelSpeed(0.3, 0.7);               // 右快左慢：向左转
    robot.update(0.5);                           // 转 0.5 秒
    robot.printStatus();
    return 0;
}
```

**完整运行输出**：

```text
位姿: x=0.000  y=0.000  theta=0.000 rad
位姿: x=0.500  y=0.000  theta=0.000 rad
位姿: x=0.696  y=0.155  theta=0.667 rad
```

读一遍输出：直行 1 秒前进 0.5 m（朝向没变）；随后 ω = (0.7−0.3)/0.3 ≈ 1.333 rad/s，转 0.5 秒朝向变成 0.667 rad，期间继续以 v = 0.5 m/s 前进，于是位置拐到了 (0.696, 0.155)。**这正是 ROS 导航包里差速底盘运动学的最小雏形**——真实机器人只是把 `setWheelSpeed` 换成发电机指令、把 `update` 换成里程计更新。

> ◇ 注意块 2、3 的 `getPose`、`printStatus` 都标了 `const`——"只读"承诺写进函数签名，编译器帮你把关。能 const 的成员函数一律 const，是类设计的黄金习惯。

## 8. 常见错误与自救

| 错误现象 | 原因 | 怎么改 |
|---|---|---|
| `Motor m1();` 不报错，但什么也没发生 | 这声明了一个"返回 Motor 的函数 m1"，不是造对象 | 无参构造**不写括号**：`Motor m1;` |
| 编译报错 "private" 相关 | 在类外直接访问私有成员 | 走 public 函数（或补一个读取器） |
| 构造函数报错"无法初始化 const 成员" | 在函数体里赋值 | 改用成员初始化列表 |
| 链接报错 undefined reference | 只写了 .h 声明，忘了编译 .cpp 实现 | `g++ main.cpp battery.cpp ...` 一起编译 |
| 两个对象的数据"串台" | 想改成员却定义了普通函数，或忘了成员变量各自独立 | 成员函数通过 this 隐式绑定调用对象，检查是否误用全局变量 |
| 头文件被包含两次报"重定义" | 没加包含保护 | .h 里加 `#ifndef/#define/#endif` 三件套 |
| 在头文件里写 `using namespace std;` | 污染所有包含者 | 头文件内写全 `std::` 前缀 |

## 9. 动手练习

**练习 1**：定义 `Rectangle` 类：私有成员宽、高，构造函数，`area()`、`perimeter()` 两个 const 成员函数；main 里造一个 3×4 的并打印面积和周长。
**练习 2**：给第 7 节的 `DiffDriveRobot` 增加成员函数 `void resetPose()`，把位姿重置回原点、朝向 0，速度清零。
**练习 3**：找茬——`Robot make() { Robot r("x", 1); return r; } int main() { Robot m = make(); m.report(); }` 里 `r` 是局部对象，返回后它不是就销毁了吗？
**练习 4**：用 `vector<Robot>` 建一支 5 台的小队，统计电量低于 20 的有几台。

??? details "练习解答"

    **练习 1**：
    ```cpp
    #include <iostream>
    using namespace std;

    class Rectangle {
    public:
        Rectangle(double w, double h) : w_(w), h_(h) {}
        double area() const { return w_ * h_; }
        double perimeter() const { return 2 * (w_ + h_); }
    private:
        double w_, h_;
    };

    int main() {
        Rectangle r(3, 4);
        cout << "面积 " << r.area() << "，周长 " << r.perimeter() << endl;
        return 0;
    }
    ```
    ```text
    面积 12，周长 14
    ```

    **练习 2**：加在 `public:` 区即可：
    ```cpp
        void resetPose() {               // 回原点：四个状态成员一起清
            x_ = 0.0;
            y_ = 0.0;
            theta_ = 0.0;
            vLeft_ = 0.0;
            vRight_ = 0.0;
        }
    ```
    验证：直行一段后调用 `robot.resetPose(); robot.printStatus();`，应输出 `位姿: x=0.000  y=0.000  theta=0.000 rad`。

    **练习 3**：不是坑。`return r;` 会**拷贝**一份 r 返回给 main（局部对象 r 本身确实销毁了，但拷贝出来的一份安然无恙，由 m 接管）。这是值返回语义，与上一章"不要返回局部变量的地址"并不矛盾——返回**值**安全，返回局部变量的**地址/引用**才危险。

    **练习 4**：
    ```cpp
    #include <iostream>
    #include <string>
    #include <vector>
    using namespace std;

    class Robot {
    public:
        Robot(string name, int battery) : name_(name), battery_(battery) {}
        int battery() const { return battery_; }
    private:
        string name_;
        int battery_;
    };

    int main() {
        vector<Robot> fleet = {
            Robot("a", 90), Robot("b", 15), Robot("c", 8),
            Robot("d", 73), Robot("e", 19)
        };
        int low = 0;
        for (const Robot& r : fleet) {
            if (r.battery() < 20) low++;
        }
        cout << "低电量机器人: " << low << " 台" << endl;
        return 0;
    }
    ```
    ```text
    低电量机器人: 3 台
    ```

## 本章速查卡

| 想做的事 | 写法 |
|---|---|
| 定义类 | `class X { public: ... private: ... };`（别忘了分号） |
| 成员变量 / 成员函数 | 类内声明 `int x_;` / `void f() { ... }` |
| 构造函数 | `X(int v) : x_(v) {}`（与类同名、无返回类型） |
| 默认构造的调用 | `X m;`（不写括号！） |
| 析构函数 | `~X() { ... }`（自动调用，后造的先走） |
| 返回"自己" | `return *this;`（this 指向当前对象） |
| 类外定义成员 | 返回类型 `X::f(...) { ... }` |
| 只读成员函数 | 尾部加 `const`：`int x() const { return x_; }` |
| 双文件分离 | .h 声明（含 `#ifndef` 保护），.cpp 实现，main 里 `#include "x.h"` |
| 对象容器 | `vector<Robot> fleet; fleet.push_back(Robot(...));` |
| 函数返回两个值 | `pair<A, B> f();` + `auto [a, b] = f();` |
