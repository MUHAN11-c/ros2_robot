## 1. 从生活到概念：内存是一排储物柜

把计算机内存想象成一条长走廊，两边是一排**储物柜**：

- 每个柜子有一个**柜号**，比如 1002 号——这就是**地址（Address）**；
- 每个柜子里可以放**东西**——这就是变量的**值（Value）**；
- 你给柜子贴的**名字标签**（比如 `score`）——这就是**变量名（Variable Name）**。

**变量名是给人看的，地址是机器用的。** 你喊"score"，编译器知道去 1002 号柜子取东西。

> ⚠️ **类比在哪里失效**：真实内存的地址是一个巨大的二进制数（64 位机器上可达 2^64 个），且不同类型占的柜子数不同（`int` 常占 4 格、`double` 占 8 格）；"柜子"之间还有栈与堆之分（第 6 节讲）。比喻只帮你建立"名字 ↔ 编号 ↔ 内容"的三层关系。

本章要学的两个工具，用储物柜的话说就是：

- **取地址 &**：问"这个变量住在几号柜？"——得到柜号；
- **解引用（Dereference）`*`**：拿着柜号"去这个柜子把东西取出来/放进去"。

## 2. 取地址与解引用：`&` 和 `*`

> 📖 教材对照：C++ Primer 第5版 §2.3

### 2.1 第一次拿到地址

```cpp
#include <iostream>
using namespace std;

int main() {
    int score = 95;              // 在某个柜子里放了一个 95，柜子上贴着标签 score
    int* p = &score;             // 定义"指针变量" p，存的是 score 的柜号
                                 // & 读作"取地址"；int* 表示"指向 int 的指针"

    cout << "score 的值:   " << score << endl;
    cout << "score 的地址: " << &score << endl;   // &score：score 住在几号柜
    cout << "p 存的地址:   " << p << endl;        // p 里装的就是那个柜号
    cout << "p 指向的值:   " << *p << endl;       // * 读作"解引用"：按柜号取东西

    *p = 100;                    // 按柜号把柜子里的东西换成 100
    cout << "改过之后 score = " << score << endl;  // score 也变成 100 了！
    return 0;
}
```

```text
score 的值:   95
score 的地址: 0x7ffd8a3c4b7c
p 存的地址:   0x7ffd8a3c4b7c
p 指向的值:   95
改过之后 score = 100
```

（地址那一行**每次运行都可能不同**，两行地址相同才重点。）

用文字画出此刻内存里的关系：

```text
变量名     地址          柜子里的值
score     0x7ffd...b7c  [ 100 ]   ← score 和 *p 看的是同一个柜子
p         0x7ffd...b80  [ 0x7ffd...b7c ]  ← p 这个柜子里放的是"另一个柜子的柜号"
```

**指针（Pointer）** 就是"专门存放地址的变量"。`*p` 出现在定义里（`int* p`）表示"p 是个指针"，出现在语句里（`*p = 100`）表示"顺着 p 里存的地址去操作那个柜子"——同一个符号，两种身份，初学时务必分清。

### 2.2 空指针 nullptr：不指任何东西的指针

```cpp
#include <iostream>
using namespace std;

int main() {
    int* p = nullptr;            // 空指针（nullptr）："哪个柜子都不指"，先占个位

    if (p == nullptr) {          // 使用前先检查，是保命习惯
        cout << "p 现在是空的，不能解引用" << endl;
    }

    int score = 95;
    p = &score;                  // 之后随时可以让它指向真正的东西
    cout << *p << endl;
    return 0;
}
```

```text
p 现在是空的，不能解引用
95
```

定义指针时拿不准指谁，就先 `= nullptr`，比让它装着随机垃圾值安全得多（为什么，见第 4 节）。

## 3. 指针与数组的关系（简讲）

> 📖 教材对照：C++ Primer 第5版 §3.5.3

数组名在大多数场合会自动变成"指向第一个元素的指针"，所以指针能像下标一样在数组上滑动：

```cpp
#include <iostream>
using namespace std;

int main() {
    int arr[4] = {10, 20, 30, 40};

    int* p = arr;                // 数组名自动变成"指向首元素的指针"
    cout << *p << endl;          // 10

    p = p + 1;                   // 指针 +1：挪到"下一个元素"（不是挪 1 个字节！）
    cout << *p << endl;          // 20

    cout << *(arr + 2) << endl;  // arr[2] 的本质就是 *(arr + 2)
    cout << arr[2] << endl;      // 和上一行完全等价
    return 0;
}
```

```text
10
20
30
30
```

理解到"下标访问背后是指针运算"这一层就够了，数组章节的越界危险在这里同样成立：指针滑出数组边界再解引用，就是未定义行为。

## 4. 野指针与段错误：三种最常见的崩溃

**段错误（Segmentation Fault）** 是操作系统对"你访问了不属于自己的内存"的当场处决。它几乎总由**野指针（Wild Pointer，指向无效地址的指针）** 引起。三个高发场景，建议每个都亲手编译一次，熟悉崩溃的"味道"：

**场景一：解引用空指针。**

```cpp
#include <iostream>
using namespace std;

int main() {
    int* p = nullptr;
    cout << "马上要崩溃了..." << endl;
    cout << *p << endl;          // 解引用空指针：段错误！
    cout << "这句话永远执行不到" << endl;
    return 0;
}
```

```text
马上要崩溃了...
段错误（核心已转储）      ← Linux 典型提示；Windows 下是"程序已停止工作"
```

**场景二：使用未初始化的指针。** `int* p;` 里装的是上一个程序留下的随机垃圾值，`*p` 等于"按一个随机柜号去撬别人的柜子"——可能崩，可能更糟：**悄悄改坏了别的数据**。

**场景三：悬空指针（Dangling Pointer，指向已失效内存的指针）。**

```cpp
#include <iostream>
using namespace std;

int* makeNumber() {
    int x = 42;                  // 局部变量：函数一结束，这个柜子就被回收了
    return &x;                   // 危险！返回一个"已经失效的柜号"
}                                // 编译器通常警告: address of local variable

int main() {
    int* p = makeNumber();       // p 指着一个"已经被拆掉"的柜子
    cout << *p << endl;          // 未定义行为：可能碰巧打印 42，也可能是垃圾值
    return 0;
}
```

```text
42        ← 最危险的情况：看起来"对了"，其实是踩在已经回收的内存上
```

| 场景 | 危险动作 | 自救方法 |
|---|---|---|
| 空指针 | 对 `nullptr` 解引用 | 使用前 `if (p != nullptr)` 判断 |
| 未初始化 | 定义后直接用 | 定义时立刻初始化（拿不准就 `= nullptr`） |
| 悬空指针 | 使用"别人已经归还的内存" | 不返回局部变量的地址；谁申请谁释放、用完置 `nullptr` |

> 💡 自救总原则：**指针要么指向一个"确定活着"的东西，要么是 nullptr，不存在第三种状态。** 写到任何 `*p` 之前先问自己一句：p 现在指着谁？它还活着吗？

## 5. 引用：变量的"别名"

> 📖 教材对照：C++ Primer 第5版 §2.3.1

**引用（Reference）** 就是给已有变量起的**别名（Alias）**：不新开柜子，只是同一个柜子多贴一张标签。就像**雷电将军**和**影**指的是同一位存在——两个名字，同一个对象。

```cpp
#include <iostream>
using namespace std;

int main() {
    int a = 10;
    int& b = a;       // b 是 a 的别名。引用在定义时就必须初始化！
    // int& c;        // 错！引用必须初始化，这行编译直接报错

    b = 20;           // 给 b 赋值，其实就是给 a 赋值
    cout << "a = " << a << endl;    // a = 20

    int other = 99;
    b = other;        // 注意：这不是"让 b 改绑到 other"，而是把 99 写进 a
    cout << "a = " << a << endl;    // a = 99
    cout << "b = " << b << endl;    // b = 99（b 从一而终，永远是 a 的别名）

    cout << &a << " 与 " << &b << endl;   // 打印出的两个地址完全相同
    return 0;
}
```

```text
a = 20
a = 99
b = 99
0x7ffd8a3c4b8c 与 0x7ffd8a3c4b8c
```

引用与指针最容易混，一张表分清：

| 对比项 | 指针 `int* p` | 引用 `int& r` |
|---|---|---|
| 本质 | 存地址的变量（真有"自己的柜子"） | 别名（不占新柜子，编译器实现不深究） |
| 必须初始化 | 否（可先不指，但要冒险） | **是**，定义时必须绑定 |
| 中途"改指"别人 | 可以 `p = &other;` | **不能**，绑定了就一辈子是它 |
| 可以为空 | 可以 `= nullptr` | 不能，必须绑一个真变量 |
| 使用语法 | `*p` 解引用后才能碰值 | 直接当原变量用 `r = 20;` |

**记忆口诀：指针像"可转寄的快递单"，引用像"曾用名"——名字定了就不再换人。**

## 6. 值传递 vs 引用传递：swap 的两个版本

> 📖 教材对照：C++ Primer 第5版 §6.2.1（传值参数与传引用参数）

上一章你可能有疑问：为什么函数里改形参，外面的变量不跟着变？现在能回答了。**逐步演算**下面两个版本的 swap（交换两个数）：

**版本 A：值传递（Pass by Value）**——形参收到的是"复印件"。

```cpp
void swapA(int x, int y) {   // x、y 是 a、b 的复印件
    int tmp = x;             // 第 1 步：tmp = 1
    x = y;                   // 第 2 步：x = 2
    y = tmp;                 // 第 3 步：y = 1
}                            // 函数结束，复印件 x、y 直接销毁
```

演算表（调用 `swapA(a, b)`，此时 `a=1, b=2`）：

| 步骤 | a（原件） | b（原件） | x（复印件） | y（复印件） |
|---|---|---|---|---|
| 进入函数 | 1 | 2 | 1 | 2 |
| `tmp = x` | 1 | 2 | 1 | 2 |
| `x = y` | 1 | 2 | 2 | 2 |
| `y = tmp` | 1 | 2 | 2 | 1 |
| 函数返回 | **1** | **2** | 销毁 | 销毁 |

复印件换得热火朝天，原件纹丝不动。

**版本 B：引用传递（Pass by Reference）**——形参就是原件的别名。

```cpp
void swapB(int& x, int& y) { // x、y 是实参本尊的别名
    int tmp = x;
    x = y;
    y = tmp;
}
```

演算表（调用 `swapB(a, b)`，此时 `a=1, b=2`）：

| 步骤 | a（=x，同一柜子） | b（=y，同一柜子） | tmp |
|---|---|---|---|
| 进入函数 | 1 | 2 | — |
| `tmp = x` | 1 | 2 | 1 |
| `x = y` | 2 | 2 | 1 |
| `y = tmp` | 2 | 1 | 1 |
| 函数返回 | **2** | **1** | 销毁 |

改的就是原件，交换成功。完整可运行版：

```cpp
#include <iostream>
using namespace std;

void swapA(int x, int y) {       // 版本 A：值传递（无效）
    int tmp = x; x = y; y = tmp;
}

void swapB(int& x, int& y) {     // 版本 B：引用传递（有效）
    int tmp = x; x = y; y = tmp;
}

int main() {
    int a = 1, b = 2;
    swapA(a, b);
    cout << "值传递后:   a=" << a << " b=" << b << endl;
    swapB(a, b);
    cout << "引用传递后: a=" << a << " b=" << b << endl;
    return 0;
}
```

```text
值传递后:   a=1 b=2
引用传递后: a=2 b=1
```

### 6.1 const 引用传参：只读 + 不拷贝的标准写法

引用传参能改原件；但很多时候我们只想"读"不想"改"，同时不想拷贝——标准写法是 **常量引用（Const Reference，`const T&`）**：

```cpp
#include <iostream>
#include <string>
using namespace std;

// const string&：承诺"只读不改"，同时避免整串拷贝
int countChar(const string& s, char target) {
    // s[0] = 'x';   // 试着取消注释：编译报错！const 保护了原件
    int count = 0;
    for (char c : s) {          // 把 s 里的每个字符挨个取出来
        if (c == target) {
            count++;
        }
    }
    return count;
}

int main() {
    string msg = "hello robotics";
    cout << "o 出现了 " << countChar(msg, 'o') << " 次" << endl;
    return 0;
}
```

```text
o 出现了 3 次
```

| 传参写法 | 能否改原件 | 是否拷贝 | 适用 |
|---|---|---|---|
| `T x`（值传递） | 否 | 拷贝一份 | 小对象（int、double） |
| `T& x`（引用） | 是 | 不拷贝 | 需要修改原件（如 swap） |
| `const T& x`（常量引用） | 否（const 保护） | 不拷贝 | **只读大对象，默认首选** |

## 7. new/delete 与内存泄漏直觉

> 📖 教材对照：C++ Primer 第5版 §12.1.1

前面变量都住在"自动档"的柜子里（函数结束自动回收）。`new` 让你手动去另一片区域（**堆（Heap）**）申请柜子，用完必须手动 `delete` 归还：

```cpp
#include <iostream>
using namespace std;

int main() {
    int* p = new int(7);       // 在堆区申请一个柜子，放入 7，柜号存进 p
    cout << *p << endl;

    *p = *p + 1;               // 通过指针使用它，和普通指针一样
    cout << *p << endl;

    delete p;                  // 用完归还！否则这格内存一直被占着
    p = nullptr;               // 归还后立刻置空，防止误用成悬空指针
    return 0;
}
```

```text
7
8
```

如果忘了 `delete`，就是**内存泄漏（Memory Leak）**：柜子被你占着、又再没人能用——程序每处理一帧数据漏一格，跑几小时就把内存吃光，机器人当场卡死。真实程序里还有更隐蔽的泄漏路径（中途抛异常、提前 return 绕过 delete），手动管理防不胜防。

于是现代 C++ 给出了"自动档"：

```cpp
#include <iostream>
#include <memory>
using namespace std;

int main() {
    unique_ptr<int> p(new int(7));   // 智能指针：离开作用域时自动归还
    cout << *p << endl;              // 用法和普通指针一样：*p 取值
    return 0;                        // 不需要写 delete——离开 main 自动释放
}
```

```text
7
```

这行代码就是**智能指针（Smart Pointer）** 的 `unique_ptr`——把"归还"这件事交给编译器，想忘都忘不掉。进阶篇（智能指针与 RAII）会把它讲透，现在知道"**新代码用智能指针，几乎不裸写 new/delete**"即可。

## 8. 和机器人有什么关系

### 8.1 大型点云传参必须 const 引用：一次拷贝 100 MB 的教训

**点云（Point Cloud）** 是激光雷达扫出的一堆三维点。估算一下体量：一帧高线束雷达约 400 万个点，每点存 x、y、z、强度 4 个 double（每字节 8 字节）：

$$4{,}000{,}000 \times 4 \times 8\ \text{字节} = 128{,}000{,}000\ \text{字节} \approx 128\ \text{MB}$$

如果函数写成值传递 `double closest(const vector<double> cloud)`，**每调用一次就把整帧点云复印一遍**——128 MB 的 memcpy 可能要几十毫秒，而规划周期只有 100 ms。写出 `const vector<double>& cloud`，传的只是一个 8 字节的地址：

| 写法 | 每次调用实际传递 | 直觉耗时 | 原件是否安全 |
|---|---|---|---|
| `vector<double> cloud`（传值） | 复印 128 MB 数据 | 几十毫秒级 | 安全但浪费到不可接受 |
| `const vector<double>&`（常量引用） | 8 字节地址 | 纳秒级 | const 保证只读，安全 |

```cpp
#include <iostream>
#include <vector>
using namespace std;

// const 引用：只递"柜号"，零拷贝，且承诺不改点云
double closestDist(const vector<double>& cloud) {
    double best = cloud[0];            // 初值取第一个元素（上一章的老规矩）
    for (double d : cloud) {
        if (d < best) best = d;
    }
    return best;
}

int main() {
    vector<double> cloud(2000000, 3.14);   // 模拟 200 万个点（内存里约 16 MB）
    cout << "最近点: " << closestDist(cloud) << " 米" << endl;
    return 0;
}
```

```text
最近点: 3.14 米
```

> 💡 今后看到 ROS 2 回调函数签名 `void onScan(const sensor_msgs::msg::LaserScan::SharedPtr msg)`，你就知道那个"只读+引用"的意图了：消息又大又不能改。

### 8.2 链表初见：用 next 指针把数据串起来

**链表（Linked List）** 是指针最经典的用法：每个节点装着"数据 + 下一个节点的地址"，数据在内存里可以东一块西一块，靠指针串成一条链。先混个脸熟，`struct` 下一章细讲：

```cpp
#include <iostream>
using namespace std;

struct Node {          // 一个"节点"：数据 + 指向下一个节点的指针
    int value;
    Node* next;        // 下一个节点的地址；最后一个节点的 next 是 nullptr
};

int main() {
    // 手工搭一条 3 个节点的链：10 -> 20 -> 30
    Node n3{30, nullptr};        // 尾节点：后面没有了
    Node n2{20, &n3};            // 中间节点：next 指向 n3
    Node n1{10, &n2};            // 头节点：next 指向 n2

    // 从头遍历到尾：cur 依次指向每个节点，直到走到空
    for (Node* cur = &n1; cur != nullptr; cur = cur->next) {
        cout << cur->value;              // cur->value 是 (*cur).value 的简写
        if (cur->next != nullptr) {
            cout << " -> ";
        }
    }
    cout << endl;
    return 0;
}
```

```text
10 -> 20 -> 30
```

三个新记号：`Node n3{30, nullptr}` 按顺序给 struct 成员赋值；`cur->value` 等价 `(*cur).value`（"顺着指针取成员"专用箭头）；`cur = cur->next` 是"挪到下一个节点"。ROS 内部的话题订阅队列、TF 树，底层都是这类"节点+指针"结构。

## 9. 常见错误与自救

| 错误现象 | 原因 | 怎么改 |
|---|---|---|
| 段错误（Segmentation Fault） | 解引用了 nullptr 或野指针 | 定位到崩溃行，检查指针"指着谁、还活着吗" |
| `swap` 写了却没交换 | 形参写成值传递 | 形参改成 `int& x, int& y` |
| 返回局部变量地址，输出随机 | 悬空指针（场景三） | 改为返回值本身，或由调用方传入存储位置 |
| 函数里改了 vector，外面没变 | 值传递拷贝了一份 | 改成 `vector<T>&`（要改）或 `const vector<T>&`（只读） |
| `delete` 后又用指针 | 悬空指针 | `delete` 后立刻 `p = nullptr;` |
| 程序越跑越卡、内存占用暴涨 | 忘了 `delete`（内存泄漏） | 用智能指针 `unique_ptr` 接管 |
| 引用编译报错 "uninitialized" | `int& r;` 没初始化 | 引用定义时必须绑定 |

## 10. 动手练习

**练习 1**：定义 `int a = 5;`，用指针把 a 改成 50，只通过指针打印验证。
**练习 2**：写函数 `double maxOf(const vector<double>& v)`，用 const 引用返回最大值（空容器先打印提示并返回 0）。
**练习 3**：找茬——指出下面三行各自的问题：
`int* p; cout << *p;`；`delete p; cout << *p;`；`int& r;`
**练习 4**：手工搭一条 4 节点链表（值 2、4、6、8），遍历求和输出。

??? details "练习解答"

    **练习 1**：
    ```cpp
    #include <iostream>
    using namespace std;

    int main() {
        int a = 5;
        int* p = &a;          // p 拿到 a 的柜号
        *p = 50;              // 按柜号改柜子里的东西
        cout << *p << endl;   // 只通过指针打印
        return 0;
    }
    ```
    ```text
    50
    ```

    **练习 2**：
    ```cpp
    #include <iostream>
    #include <vector>
    using namespace std;

    double maxOf(const vector<double>& v) {   // const 引用：零拷贝、只读
        if (v.empty()) {                      // empty()：是否一个元素都没有
            cout << "空容器" << endl;
            return 0;
        }
        double best = v[0];                   // 初值取第一个元素
        for (double d : v) {
            if (d > best) best = d;
        }
        return best;
    }

    int main() {
        vector<double> dists = {1.2, 0.8, 2.5, 1.9};
        cout << "最大距离: " << maxOf(dists) << " 米" << endl;
        return 0;
    }
    ```
    ```text
    最大距离: 2.5 米
    ```

    **练习 3**：
    - 第 1 行：`p` 未初始化就解引用，野指针，未定义行为。应 `int* p = nullptr;` 并在指向有效变量后再解引用。
    - 第 2 行：`delete` 之后 p 是悬空指针，再解引用是未定义行为。应 `delete p; p = nullptr;`。
    - 第 3 行：引用定义时必须初始化，`int& r;` 直接编译报错。应写成 `int& r = 某个已有变量;`。

    **练习 4**：
    ```cpp
    #include <iostream>
    using namespace std;

    struct Node { int value; Node* next; };

    int main() {
        Node n4{8, nullptr};
        Node n3{6, &n4};
        Node n2{4, &n3};
        Node n1{2, &n2};

        int sum = 0;
        for (Node* cur = &n1; cur != nullptr; cur = cur->next) {
            sum += cur->value;    // 每个节点的值累加
        }
        cout << "链表总和: " << sum << endl;
        return 0;
    }
    ```
    ```text
    链表总和: 20
    ```

## 本章速查卡

| 想做的事 | 写法 |
|---|---|
| 取地址 | `&x` |
| 定义指针 / 空指针 | `int* p = &x;` / `int* p = nullptr;` |
| 解引用（读/写） | `*p` |
| 通过指针取成员 | `p->field`（等价 `(*p).field`） |
| 定义引用 | `int& r = x;`（必须初始化） |
| 修改原件的传参 | `void f(T& x)` |
| 只读大对象的传参 | `void f(const T& x)` ← 默认首选 |
| 堆申请 / 归还 | `new T(...)` / `delete p;` |
| 自动归还（推荐） | `unique_ptr<T> p(new T(...));` |
| 遍历链表 | `for (Node* cur = head; cur != nullptr; cur = cur->next)` |
