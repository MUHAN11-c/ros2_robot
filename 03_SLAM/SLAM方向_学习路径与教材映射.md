## 这个方向是做什么的

SLAM（Simultaneous Localization and Mapping，同步定位与建图）回答两个纠缠在一起的问题：**我在哪？周围长什么样？**难就难在" simultane­ously "——没有地图就没法定位，没有定位又画不出地图。它是扫地机器人、AR 眼镜、自动驾驶、无人机自主飞行共同的"空间自觉"。

一个生活化的例子：你走进一个陌生的商场，一边走一边在脑子里画平面图，同时随时知道自己"在星巴克旁边、要左转去优衣库"——你没有 GPS 在室内导航，靠的是眼睛（视觉）、脚步感觉（惯性）和对已走过路段的记忆（回环检测）。**SLAM 就是把这套本事装进机器人的芯片里。**

本方向覆盖三个层次：

| 层次 | 内容 | 在机器人上的样子 |
|---|---|---|
| 筑基准备 | C++、Eigen、李群李代数、概率基础 | 能跑通十四讲的环境与代码 |
| 本科核心 | 视觉 SLAM 框架：前端里程计 + 后端优化 + 回环 | 读懂 ORB-SLAM 这类经典系统 |
| 研究生级 | 概率估计理论、因子图、多传感器融合（LIO） | 读懂并动手搭 VINS / LIO 系统 |

再补一句实话：SLAM 是机器人方向里"数学密度"最高的一类，也正因如此，它是检验前两个方向学习成果的最佳试金石——你在数学方向点亮的线代与李群锚点、在 C++ 方向攒下的模板与并发装备，在这里全部派上用场。

先把行话翻译成"人话"（后文反复出现）：

| 术语 | 一句话解释 |
|---|---|
| 视觉里程计（VO） | 只靠相机逐帧估计"我走了多远" |
| VIO / LIO | 视觉+惯性 / 激光+惯性的融合里程计 |
| 回环检测 | 认出"这里我来过"，把累计误差拉回来 |
| 因子图 | 把观测关系画成图，转成一个最小二乘问题 |
| 词袋（BoW） | 把图像变成"单词集合"，用于快速认地方 |
| 建图 | 把走过的环境拼成可用的地图 |

经典 SLAM 系统的"四件套"结构，先混个脸熟（第一阶会逐一展开）：

| 部件 | 干什么 | 十四讲对应 |
|---|---|---|
| 前端（视觉里程计） | 逐帧估计运动 | 第 7-9 讲 |
| 后端（优化） | 把所有观测拧成一个一致解 | 第 10-11 讲 |
| 回环检测 | 认出旧地，消除累积漂移 | 第 12 讲 |
| 建图 | 输出可用于导航的地图 | 第 13 讲 |

精读一章系统论文的固定动作，五步走：

1. 先读系统框图，标出"四件套"各自在哪；
2. 列出所有传感器与坐标系，画出坐标树草图；
3. 找到核心公式（通常是残差与协方差定义），手推一遍；
4. 带着问题读源码：数据从哪进、优化变量有哪些、结果从哪出；
5. 跑公开数据集复现指标，记下你与论文数字的差距。

把"段位"落到具体系统上（各精读章实际选定的系统以其正文为准）：

| VINS-Mono / VINS-Fusion | 相机 + IMU | 滑窗 VIO 标杆 | 中高级 |
| LOAM / LeGO-LOAM | 激光 | 特征提取式激光里程计鼻祖 | 高级 |
| LIO-SAM / FAST-LIO | 激光 + IMU | 因子图 / 迭代滤波 LIO 代表 | 高级 |
| Point-LIO 等新范式 | 激光 + IMU | 退化场景下的高频新方案 | 前沿 |

## 常见问题

**Q1：数学和 C++ 底子不够，能直接看十四讲吗？**
能"看"，很难"学"。十四讲第 4 讲（李代数）和第 6 讲（非线性优化）是两道数学门槛，第 9 讲之后代码量陡增。建议至少先完成：C++ 筑基 7 章 + Eigen 预备章（见"第一阶"小节的三大前置），再开十四讲，效率天差地别。

**Q2：先学视觉 SLAM 还是激光 SLAM？**
推荐从视觉入手：十四讲提供了完整的"理论-代码-调试"闭环，且视觉数学（相机模型、对极几何、BA）是两者共同的底座。激光惯性（LIO）放在第二、三阶，以 [40_综合项目/Mini-LIO](40_综合项目/10_Mini-LIO.md) 为落点，此时你的因子图与李群储备正好接上。

**Q3：能不能跳过手推公式，直接学 GTSAM/g2o 调库？**
短期可以出活，长期会卡死在调参与改进上。调库的每一步（构建因子、线性化、边缘化）背后都是教材里的数学；反过来，手推过一遍 GraphSLAM 再看 GTSAM 文档，是"秒懂"体验。两条线都要走，顺序上建议"先推后调"。

**Q4：本方向导航还在重写，会不会学到一半断头？**
不会断头：第〇阶入门章 [10_SLAM是什么_从零理解定位与建图](00_零基础入门/10_SLAM是什么_从零理解定位与建图.md) 已完成，第一阶理论（[10_SLAM理论基础](10_SLAM理论/10_SLAM理论基础.md)）与第三阶正文（[20_入门级精读](30_系统精读/20_入门级精读.md)，全梯度见"第三阶"小节）也都在线，全景图见 [SLAM方向总大纲](SLAM方向_总大纲.md)。个别入口（如学习地图）缺失时，按本页表格的路径走即可。

**Q5：SLAM 方向还吃香吗，要不要转具身智能？**
SLAM 的"空间感知"能力正是具身智能机器人的底层组件之一，两者不是替代关系而是叠层关系。本站第三阶的 [60_前沿精读](30_系统精读/60_前沿精读.md) 会持续更新新范式；站内具身智能等其他方向可在数理基础共通的前提下并行拓展。先把十四讲主线走完，选择权自然回到你手上。

**Q6：SLAM 学完，和"导航规划"是什么关系？**
SLAM 交付"我在哪 + 地图长啥样"，导航规划在此基础上回答"怎么去"——路径搜索、避障、轨迹跟踪是规控方向的主场。定位与建图做不稳，上层规划就是空中楼阁，所以 SLAM 常被叫作自主移动的"地基"。

**Q7：十四讲代码跑不动、依赖装不上怎么办？**
三步自救：优先按书与仓库的环境说明锁定一致的 Ubuntu 版本；其次善用包管理器与仓库 issue（环境报错九成有人踩过）；最后用本站 [20_Linux命令行与Git入门](../02_C++基础与进阶/15_Python与工具链/20_Linux命令行与Git入门.md) 把 apt、git submodule 的基本操作补齐。环境问题不是你笨，是所有人的必经之路。

**Q8：一定要有激光雷达或实体机器人才能学吗？**
不需要。十四讲全程可用公开数据集（笔记本即可跑）；激光方向的 KITTI、EuRoC 等公开数据集配合 [10_Mini-LIO](40_综合项目/10_Mini-LIO.md) 也只吃一台普通电脑。真机是锦上添花，不是入场券。

**Q9：SLAM 与"定位"是一回事吗？**
定位通常假设地图已经有了，只解决"我在哪"；SLAM 更难一步，地图本身也在同时构建。工程上两者常共用同一套滤波/优化工具——学完第二阶你会发现，它们只是"已知条件多与少"的区别。

**Q10：学完 SLAM 能做什么工作？**
自动驾驶（定位建图组）、机器人公司（导航组）、AR/VR（空间感知）、无人机（感知飞控）都在招 SLAM 工程师。岗位的共同要求就是本页这条阶梯：数学（李群 + 因子图）、C++ 工程力、至少精通一条系统线——三者缺一，面试都会露怯。

**Q11：可以把 SLAM 当"纯软件"学吗？**
入门阶段可以（公开数据集 + 仿真全覆盖），但调参的尽头是传感器——IMU 内参、相机标定、时间同步这些"脏活"决定系统上限。学完 Mini-LIO 后若能借到一台带 IMU 的设备录一次自己的数据，理解会再上一个台阶。
