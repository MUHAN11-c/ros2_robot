## 1. 从生活到概念:环形跑道上的"加法"

想象一条**环形跑道**。跑步的人可以痛快地说"再跑 200 米"——里程**可以加**;但"你在跑道哪个位置"却是个**环**(跑 400 米回到原点),位置的坐标没有全局的加减法:0 米 + 400 米 = 0 米,"加"在这里失灵。

旋转正是这样一条环:

- 两次旋转**复合**(第 2 讲的矩阵乘/四元数乘)永远合法——像"先跑 200 再跑 200";
- 但把两个旋转矩阵**相加**,结果连旋转都不是(不正交)——像"把两个位置坐标相加,得到的不在环上"。

◎ 类比:李群是**弯的跑道本身**;李代数是跑道某点贴着的**切线**——切线是笔直的数轴,加减乘除随便来。**指数映射**就是"沿切线走 θ 步,落回跑道上";**对数映射**是"从跑道上一点,问你是沿切线走了几步到的"。类比失效点:跑道只有一圈,旋转的李代数向量以 $\theta = \pi$ 为界(走超过半圈,对数映射会"抄近路"往回认)——第 5 节的坑之一。

## 2. 概念是什么

### 2.1 群:只有"乘法"的俱乐部

**群(Group)** 是一个集合 + 一种运算,满足四条:封闭、结合、有单位元、有逆。第 2 讲已经说过 SO(3)/SE(3) 是"合法旋转俱乐部"——现在你知道术语了:**它们是群,而且还是"光滑的群"(李群,Lie Group)**,群元素随参数连续变化。

麻烦也正在"光滑":优化算法的最小二步是 $\boldsymbol{x} \leftarrow \boldsymbol{x} + \Delta\boldsymbol{x}$——**加法**。群只有乘法,怎么办?

### 2.2 李代数:单位元处的切线

对旋转矩阵的连续族 $R(t)$(比如机器人正在匀速转),在单位元 $I$ 附近研究它:$R(0) = I$,$\dot R(0)$ 是初始切向量。对正交条件 $R^{\mathsf T}R = I$ 两边求导可得

$$
\dot R(0)^{\mathsf T} + \dot R(0) = 0 \quad\Longrightarrow\quad \dot R(0) \text{ 是反对称矩阵}
$$

**反对称矩阵(antisymmetric)**:$a^{\mathsf T} = -a$,三维正好 3 个自由度,与向量一一对应:

$$
\boldsymbol{\phi}^{\wedge} = \begin{bmatrix} 0 & -\phi_3 & \phi_2 \\ \phi_3 & 0 & -\phi_1 \\ -\phi_2 & \phi_1 & 0 \end{bmatrix},\qquad
\boldsymbol{\phi}^{\wedge}\boldsymbol{u} = \boldsymbol{\phi}\times\boldsymbol{u}
$$

这 3 维向量空间(配上叉积当"乘法")就叫 **so(3)**——SO(3) 的**李代数**。同理 SE(3) 的李代数 **se(3)** 是 6 维"旋量"$\boldsymbol{\xi} = [\boldsymbol{\phi};\ \boldsymbol{\rho}]$(旋转 3 维 + 平移 3 维),矩阵形式 $\boldsymbol{\xi}^{\wedge} = \begin{bmatrix}\boldsymbol{\phi}^{\wedge} & \boldsymbol{\rho}\\ 0 & 0\end{bmatrix}$。

◇ 关键顿悟:**so(3) 的向量 $\boldsymbol{\phi} = \theta\boldsymbol{n}$ 就是第 2 讲的轴角!** 那时它是"另一种记法",现在它升级为"李群的局部坐标"——老朋友,新身份。

### 2.3 指数映射:沿切线走,落回跑道

数学事实(推导见教材,这里认结论+验证):以 $\boldsymbol{\phi} = \theta\boldsymbol{n}$ 为切方向走 θ,对应的群元素是

$$
R = \exp(\boldsymbol{\phi}^{\wedge}) = I + \frac{\sin\theta}{\theta}\boldsymbol{\phi}^{\wedge} + \frac{1-\cos\theta}{\theta^2}(\boldsymbol{\phi}^{\wedge})^2
$$

——**罗德里格斯公式**!第 2 讲 §2.3 见过的"轴角→矩阵"正是 so(3) 的指数映射。反方向:

$$
\boldsymbol{\phi} = \ln(R)^{\vee},\qquad \theta = \arccos\frac{\mathrm{tr}(R)-1}{2},\qquad \boldsymbol{n} = \frac{1}{2\sin\theta}\begin{bmatrix} R_{32}-R_{23}\\ R_{13}-R_{31}\\ R_{21}-R_{12} \end{bmatrix}
$$

SE(3) 的指数映射只多一块"V 矩阵"(平移部分的修正):

$$
T = \exp(\boldsymbol{\xi}^{\wedge}) = \begin{bmatrix} R & V\boldsymbol{\rho}\\ 0 & 1 \end{bmatrix},\quad
V = I + \frac{1-\cos\theta}{\theta^2}\boldsymbol{\phi}^{\wedge} + \frac{\theta-\sin\theta}{\theta^3}(\boldsymbol{\phi}^{\wedge})^2
$$

### 2.4 BCH:两个小扰动的复合 ≈ 相加

$\exp(a)\exp(b) \ne \exp(a+b)$(群乘法不可交换,第 2 讲的旧账)。但 **BCH 公式**保证:**当 a、b 都很小时**

$$
\ln(e^{a^{\wedge}} e^{b^{\wedge}})^{\vee} \approx a + b \quad(\text{差一个二阶小量})
$$

这正是优化的救星:迭代的每一步扰动都足够小,李代数里就能放心做加法。本讲 §3 的数值实验会亲眼看到"近似"有多准(残差 ~10⁻⁴)。

### 2.5 扰动模型:两种"加一点"

对位姿 $R$ 加扰动有两种约定,后端代码里都会见到:

| 模型 | 写法 | 直觉 |
|---|---|---|
| 左扰动 | $R' = \exp(\delta\boldsymbol{\phi}^{\wedge})\,R$ | 在**世界系**看,多转了一点 |
| 右扰动 | $R' = R\,\exp(\delta\boldsymbol{\phi}^{\wedge})$ | 在**自身系**看,多转了一点 |

数值上两者与"李代数直接加 $\boldsymbol{\phi}+\delta\boldsymbol{\phi}$"都只差一阶小量(§3 实测 4.6×10⁻⁴)——优化里推雅可比时,选一种约定**坚持到底**即可(混用是第 5 节高频翻车点)。

## 3. 动手算一算

### 3.1 手算:exp([0, 0, π/2])

θ = π/2,$\boldsymbol{n} = \boldsymbol{z}$。代入罗德里格斯:$\sin\theta/\theta = 2/\pi$,$(1-\cos\theta)/\theta^2 = 2/\pi^2$,

$$
R = I + \frac{2}{\pi}\begin{bmatrix}0&-1&0\\1&0&0\\0&0&0\end{bmatrix} + \frac{2}{\pi^2}\begin{bmatrix}-1&0&0\\0&-1&0\\0&0&0\end{bmatrix}
= \begin{bmatrix}0&-1&0\\1&0&0\\0&0&1\end{bmatrix}
$$

——正是 $R_z(90°)$。**验证代码在本节末尾**。

### 3.2 手算:log(R_z(90°))

$\mathrm{tr}(R) = 1 \Rightarrow \cos\theta = 0 \Rightarrow \theta = \pi/2$;$2\sin\theta = 2$,反对称部分 $(R_{32}-R_{23},\ R_{13}-R_{31},\ R_{21}-R_{12}) = (0,0,2)$,故 $\boldsymbol{\phi} = \tfrac{\pi/2}{2}(0,0,2) = (0,0,\pi/2)$——回到了出发的向量。**exp 与 log 互为逆**。

### 3.3 数值实验:BCH 近似有多准、扰动差多远

用 numpy 从零实现(完整代码 §3.4),三个实验的**实测输出**:

```text
log 往返最大差 = 0.0
se3 往返最大差 = 4.44e-16
BCH: log(exp a exp b) - (a+b) = [2.01e-04 2.30e-05 2.50e-04]
左扰动 vs 右加角向量 最大差 = 0.0004606628729026535
```

读数:BCH 残差 ~2×10⁻⁴(扰动量级 0.02 的**二阶**——完美吻合"差二阶小量"的理论);左扰动与"李代数加法"差 4.6×10⁻⁴(δφ 量级 0.002 的一阶余项)——**优化尺度上,这些误差可以忽略;但它们不是零,别当精确等式用**。

### 3.4 从零实现之一:Python/numpy(so(3) + se(3) 全套)

```python
import numpy as np

def hat(w):
    return np.array([[0, -w[2], w[1]], [w[2], 0, -w[0]], [-w[1], w[0], 0]])

def so3_exp(w):                       # 罗德里格斯:R = I + (sinθ/θ)W + ((1-cosθ)/θ²)W²
    th = np.linalg.norm(w)
    W = hat(w)
    if th < 1e-8: return np.eye(3) + W          # 小角一阶:θ→0 时 sinθ/θ→1, (1-cosθ)/θ²→1/2
    return np.eye(3) + np.sin(th)/th*W + (1-np.cos(th))/th**2*(W@W)

def so3_log(R):
    cos = (np.trace(R)-1)/2
    th = np.arccos(np.clip(cos, -1, 1))
    if th < 1e-8: return np.array([R[2,1]-R[1,2], R[0,2]-R[2,0], R[1,0]-R[0,1]])/2
    return th/(2*np.sin(th))*np.array([R[2,1]-R[1,2], R[0,2]-R[2,0], R[1,0]-R[0,1]])

def se3_exp(xi):                      # xi = [w(3); v(3)]
    w, v = xi[:3], xi[3:]
    th = np.linalg.norm(w); W = hat(w)
    if th < 1e-8: V = np.eye(3) + 0.5*W
    else: V = np.eye(3) + (1-np.cos(th))/th**2*W + (th-np.sin(th))/th**3*(W@W)
    T = np.eye(4); T[:3,:3] = so3_exp(w); T[:3,3] = V@v
    return T

def se3_log(T):
    w = so3_log(T[:3,:3]); W = hat(w); th = np.linalg.norm(w)
    if th < 1e-8: V = np.eye(3) + 0.5*W
    else: V = np.eye(3) + (1-np.cos(th))/th**2*W + (th-np.sin(th))/th**3*(W@W)
    return np.concatenate([w, np.linalg.solve(V, T[:3,3])])

# 一行对账
R = so3_exp([0, 0, np.pi/2])
print(np.round(R, 4))                          # 应得 Rz(90°)
print(np.abs(so3_exp(so3_log(R)) - R).max())   # 应为 0
```

实测输出:

```text
[[ 0. -1.  0.]
 [ 1.  0.  0.]
 [ 0.  0.  1.]]
0.0
```

### 3.5 从零实现之二:纯 C++(不依赖任何库,SLAM 工程的母语)

C++ 版只需做 so(3)(SE(3) 的 V 矩阵照 §2.3 公式平移即可)。**作者实测时踩过一个坑**:先用单位轴 $[\boldsymbol{n}]_\times$ 当 W、却保留 $\tfrac{1-\cos\theta}{\theta^2}$ 系数——系数与矩阵**配错对**,算出的"Rz(90°)"主对角是 0.59/0.64。修正:W 必须取**全向量** $\boldsymbol{\phi}^{\wedge}$(系数里的 θ 分母才成立)。这个坑请记进你的调试笔记。

```cpp
#include <cmath>
#include <cstdio>
struct V3 { double x, y, z; };
double norm(V3 a) { return std::sqrt(a.x*a.x + a.y*a.y + a.z*a.z); }
void hat(V3 w, double W[3][3]) {              // [w]x 反对称阵
    W[0][0]=0;    W[0][1]=-w.z; W[0][2]= w.y;
    W[1][0]= w.z; W[1][1]=0;    W[1][2]=-w.x;
    W[2][0]=-w.y; W[2][1]= w.x; W[2][2]=0;
}
void so3_exp(V3 w, double R[3][3]) {          // 罗德里格斯
    double W[3][3], W2[3][3];
    hat(w, W);
    for (int i = 0; i < 3; ++i)
        for (int j = 0; j < 3; ++j) {
            W2[i][j] = 0;
            for (int k = 0; k < 3; ++k) W2[i][j] += W[i][k]*W[k][j];
        }
    double th = norm(w);
    double s = (th < 1e-8) ? 1.0 : std::sin(th)/th;
    double c = (th < 1e-8) ? 0.5 : (1-std::cos(th))/(th*th);
    for (int i = 0; i < 3; ++i)
        for (int j = 0; j < 3; ++j)
            R[i][j] = (i==j ? 1.0 : 0.0) + s*W[i][j] + c*W2[i][j];
}
V3 so3_log(double R[3][3]) {
    double cos_th = (R[0][0]+R[1][1]+R[2][2]-1)/2;
    double th = std::acos(cos_th > 1 ? 1 : (cos_th < -1 ? -1 : cos_th));
    if (th < 1e-8) return {0, 0, 0};
    double f = th/(2*std::sin(th));
    return {f*(R[2][1]-R[1][2]), f*(R[0][2]-R[2][0]), f*(R[1][0]-R[0][1])};
}
int main() {
    double R[3][3];
    so3_exp({0, 0, M_PI/2}, R);
    for (int i = 0; i < 3; ++i)
        printf("  [ %8.4f %8.4f %8.4f ]\n", R[i][0], R[i][1], R[i][2]);
    V3 back = so3_log(R);
    printf("log(exp) = [%.6f %.6f %.6f]  期望 [0 0 %.6f]\n",
           back.x, back.y, back.z, M_PI/2);
    return 0;
}
```

实测输出(编译器 zig cc,无任何第三方库):

```text
  [   0.0000   -1.0000    0.0000 ]
  [   1.0000    0.0000    0.0000 ]
  [   0.0000    0.0000    1.0000 ]
log(exp) = [0.000000 0.000000 1.570796]  期望 [0 0 1.570796]
```

## 4. 和机器人有什么关系:优化的变量终于有了住址

| 场景 | 怎么用李代数 |
|---|---|
| **位姿图优化**(g2o/GTSAM 的 `Pose3` 节点) | 节点内部存 $\mathrm{SE}(3)$;迭代更新时算 $\exp(\delta\boldsymbol{\xi}^{\wedge})\,T$——增量活在 se(3) 里 |
| **BA(光束法平差)** | 相机位姿与路标点的修正量全部是李代数扰动,雅可比按扰动模型求 |
| **IMU 预积分**(VINS) | 两帧间的相对旋转增量在 so(3) 上累积,预积分量 = 一串小指数映射的连乘 |
| **误差状态卡尔曼滤波(ESKF)** | 名义状态在群上走,误差状态在李代数上加减——"大步走弯路,小步走直线" |
| **姿态控制器** | 姿态误差取 $\log(R_{\text{目标}}R_{\text{当前}}^{\mathsf T})$ 得到三维误差角,直接喂给 PID |

◇ 一句话:**凡是"位姿 + 优化/滤波"的代码,状态住在李群里、增量住在李代数里,exp/log 是每天的通勤班车**。你以后翻开 GTSAM 的 `between()`、g2o 的 `oplusImpl`,看到的正是本讲这两行公式。

## 5. 常见错误与自救

| 错误现象 | 原因 | 怎么改 |
|---|---|---|
| 小角度时结果 NaN | $\sin\theta/\theta$、$(1-\cos\theta)/\theta^2$ 在 θ→0 是 0/0 | 按泰勒展开处理:θ<10⁻⁸ 时用一阶近似 $I + \boldsymbol{\phi}^{\wedge}$(本讲代码的 `if th < 1e-8`) |
| exp 结果"差一点"且对角线不对 | 系数与矩阵配错对($[\boldsymbol{n}]_\times$ 配了含 θ² 的系数) | W 一律取全向量 $\boldsymbol{\phi}^{\wedge}$(§3.5 的真实踩坑) |
| 把 $\ln(e^a e^b) = a+b$ 当精确等式 | BCH 只保证一阶 | 扰动量级大时要留二阶项;优化迭代里每步扰动小,才可放心用 |
| 雅可比推出来对不上仿真 | 左扰动/右扰动混用 | 全文统一一种约定(推荐左扰动),推完用数值差分校验 |
| 旋转 180° 附近 log 跳变/不稳 | $\theta\to\pi$ 时 $\sin\theta\to0$,轴不可辨识 | 避免 180° 附近的参数化;或用四元数做"中转"再取 log |
| se(3) 的平移部分直接取 $T$ 的 t | 平移被 V 矩阵"耦合"过 | $\boldsymbol{\rho} = V^{-1}\boldsymbol{t}$,别偷懒 |

## 6. 动手练习

**练习 1(手算 exp)**:用罗德里格斯算 $\exp([0,\ \pi/2,\ 0]^{\wedge})$,写出矩阵。

??? details "练习 1 解答"

    θ = π/2,轴 = y。$\tfrac{\sin\theta}{\theta} = 2/\pi$,$\tfrac{1-\cos\theta}{\theta^2} = 2/\pi^2$,$W^2$ 的左上 2×2 为 $\mathrm{diag}(-1,0,-1)$(绕 y 轴):

    $$R = \begin{bmatrix} 1-\tfrac{2}{\pi^2} & 0 & \tfrac{2}{\pi}\\ 0 & 1 & 0\\ -\tfrac{2}{\pi} & 0 & 1-\tfrac{2}{\pi^2} \end{bmatrix} \approx \begin{bmatrix}0.797&0&0.637\\ 0&1&0\\ -0.637&0&0.797\end{bmatrix}$$

    即 $R_y(90°)$——与第 2 讲 §2.2 的三兄弟矩阵一致。

**练习 2(往返验证)**:证明(或用 §3.4 代码验证)对任意 $\boldsymbol{\phi}$,$\ln(\exp(\boldsymbol{\phi}^{\wedge}))^{\vee} = \boldsymbol{\phi}$(θ < π 时)。

??? details "练习 2 解答"

    代码验证:随机取 100 个 $\|\boldsymbol{\phi}\| < 3$ 的向量,`np.abs(so3_exp(so3_log(R)) - R).max()` 全部 < 10⁻¹²(本讲实测为 0.0)。解析理由:exp 沿"切线方向 θ 步"唯一落在某旋转上,而 log 用 θ = arccos((tr−1)/2) ∈ (0, π) 取的正是这根切线的原参数——两条映射互逆,除非 θ 越过 π(log 会认"反方向的短弧")。

**练习 3(小角展开)**:θ 很小时,罗德里格斯退化成什么?为什么这给出了"旋转矩阵的一阶近似"?

??? details "练习 3 解答"

    $\sin\theta/\theta \to 1$,$(1-\cos\theta)/\theta^2 \to \tfrac12$。而 $W^2$ 是有界的,故第二项是 $O(\theta^2)$ 可丢:$R \approx I + \boldsymbol{\phi}^{\wedge}$。**旋转 ≈ 单位阵 + 反对称扰动**——这就是 §2.5 扰动模型与无数雅可比推导的出发点(C++ 实测:小角 10⁻⁶ 时 $R_{21}-R_{12} = +2.000\times10^{-6} = 2\phi_3$,一阶公式精确到该量级)。

**练习 4(se3 特例)**:纯平移($\boldsymbol{\phi}=0$,$\boldsymbol{\rho}=(1,2,3)$)时 se3_exp 给出什么?V 矩阵此刻是多少?

??? details "练习 4 解答"

    θ=0 → V = I(按展开式),$R = I$,故 $T = \begin{bmatrix}I & (1,2,3)\end{bmatrix}$——纯平移变换,李代数与群"长得一样"(切线没弯)。代码路径走 `th < 1e-8` 分支,V = I + 0.5W = I。

## 综合习题:一次优化的"心跳"(全章知识串联)

位姿图优化的一次迭代:当前位姿 $R_0 = \exp([0.1,\ 0.2,\ 0.3]^{\wedge})$,求解器送来增量 $\delta\boldsymbol{\phi} = [0.001,\ -0.002,\ 0.0015]$。

**(a) 起点在哪**(§2.2/§2.3):$\boldsymbol{\phi}_0 = [0.1,0.2,0.3]$ 是"哪种表示"?它与第 2 讲哪个表示同源?

**(b) 求解器的天真想法**(§1/§2.4):直接算 $\exp((\boldsymbol{\phi}_0+\delta\boldsymbol{\phi})^{\wedge})$;再按左扰动算 $\exp(\delta\boldsymbol{\phi}^{\wedge})R_0$。两者差多少(数量级)?

**(c) 为什么允许差这么多**(§2.4 BCH、§2.5):说明 (b) 的差与优化的收敛性为何不冲突。

**(d) 落回工程**(§4):g2o 里这一步对应哪个操作?如果 δ 是 6 维的 $\delta\boldsymbol{\xi}$,SE(3) 的更新公式长什么样?

**(e) 实现并复现** (§3.3/§3.4):用 §3.4 的代码复现 (b) 的数值(期望 4.6×10⁻⁴)。

??? details "综合习题完整解答"

    **(a)** $\boldsymbol{\phi}_0$ 是 so(3) 李代数向量 = **轴角**(θ≈0.373 rad,轴 ≈ (0.27, 0.53, 0.80))——第 2 讲 §2.3 的老朋友,本讲给它升了籍贯。

    **(b)** 代码实测(§3.3 第四行输出):$\|\exp((\boldsymbol{\phi}_0+\delta)^{\wedge}) - \exp(\delta^{\wedge})R_0\|_{\max} \approx 4.6\times10^{-4}$。

    **(e) 复现代码**:

    ```python
    R0 = so3_exp(np.array([0.1, 0.2, 0.3]))
    dphi = np.array([0.001, -0.002, 0.0015])
    left = so3_exp(dphi) @ R0                # 左扰动更新
    right = so3_exp(so3_log(R0) + dphi)      # 李代数直接加
    print(np.abs(left - right).max())        # → 4.606628729026535e-04
    ```

    **(c)** 两种写法差的是 $\|\delta\boldsymbol{\phi}\|$ 的**一阶**小量(0.0027 的量级 → 残差 4.6×10⁻⁴);优化每步都重新测量误差、重新求解,BCH 的二阶误差在迭代中自行被吸收——只要每步扰动小、且**始终用同一种约定**,收敛不受影响。真正致命的不是近似,而是**左右扰动混用**(系统偏差)。

    **(d)** g2o 的 `oplusImpl` / GTSAM 的 `retract`:$T \leftarrow \exp(\delta\boldsymbol{\xi}^{\wedge})\,T$(左乘 6 维指数映射,平移部分带着 V 矩阵耦合,§2.3)。你在调试器里看到的"一个 6 维小向量让 4×4 矩阵动了"——引擎就是本讲的两行公式。
