# ROS 2 综合学习文档网站设计

## 用户补充（优先于初版结构）

用户要求的是“综合所有参考内容后的完整离线详细学习文档”，不能让读者逐项跳转外站补齐正文。40章均扩展为自足教材：至少5个深入讲解小节、完整操作/配置解释、一个贯穿案例与至少3道带答案练习。参考来源退到章末折叠区。增加无需JavaScript的连续阅读HTML、完整Markdown、可下载项目源码和整个离线网站压缩包。优先交付离线内容；在线发布可作为附加入口，不能替代本地成果。

## 意图

把官方 ROS 2 文档、维护者示例、两套已下载的中文教程，以及当前目录里的控制与机器人参考工程，整理为可以连续学习和随时查阅的中文知识网站。内容主线为 ROS 2 Jazzy / Ubuntu 24.04；Jazzy 是本项目选用的版本，不称其为最新发行版。

## 交付与默认选择

- 新目录 `ros2-learning-hub/`，名称“ROS 2 学习图谱”。现有 `ros2-control-learning-web/` 作为深入学习控制框架的实验室纳入导航。
- 使用无需安装依赖的 HTML/CSS/JavaScript 静态网站，直接打开或本地 HTTP 服务均可阅读。无后端，无远程字体、CDN 或登录依赖。内容和交互均在本地。
- 默认用 Sites 提供仅本人可见的在线版本，源码和本地入口保留；如用户要求仅本地，则跳过注册与发布。
- 视觉由实施者决定：纸白、墨绿与橙色重点的技术手册风格，清楚的侧栏、章节层级、图解与宽屏代码对照。

## 信息结构

1. 学习首页：推荐起点、阶段路线、生态全景和最近阅读。
2. 系统课程：约 36–42 个有正文的单元，覆盖安装、工作空间、CLI、rclcpp/rclpy、接口、话题/服务/动作、参数、launch、QoS、执行器、组件、生命周期、时间、tf2、URDF、RViz、rosbag、控制、导航、机械臂、仿真、感知、嵌入式、测试、性能、安全、部署、多机器人及迁移。
3. 写法对照：至少 12 组任务对应的 C++/Python、Python/XML/YAML launch、CMake/Python 包、QoS、参数与控制配置差异。明确等价部分、选择条件和不等价之处。
4. 资料库：至少 70 条官方、维护者或教程作者的一手链接，支持分类、版本与关键词筛选。逐条说明用途、版本、核查状态及日期。列出本次纳入的全部资料，不声称覆盖互联网上所有 ROS 2 资源。
5. 实战项目：通信入门、DiffBot 控制、移动机器人导航、机械臂规划、嵌入式/多机协作；每项有前提、阶段成果、验证命令和参考实现。
6. 排错与术语：按发现不了节点、收不到消息、TF/时间不一致、构建/依赖、控制器状态等症状组织。

## 课程质量

- 每章包含学习目标、概念解释、操作步骤、代码或命令、预期结果、常见错误、练习及参考来源。
- 明确标识完整示例、终端命令、局部片段和概念示意。完整 C++/Python 基础通信示例随站点提供项目文件与构建说明。
- 使用原创中文讲解与示例，链接到原教程与官方源码。不批量复制第三方教程全文；保留引入内容的许可与出处。
- 对 Humble、Jazzy、Rolling 及独立版本生态作显式区分。Nav2、MoveIt、Gazebo、ros2_control 使用对应版本文档；无法读取或仅确认入口的资料如实注明。
- 核查日期为 2026-11-06。网页与浏览器交互的测试，不等同于 ROS 工程编译、硬件或仿真运行验证。

## 交互

- 全文搜索课程、资料和对照；支持中文、英文、包名与 API。
- 深链接路由、侧栏、面包屑、页内目录、上一章/下一章。
- 代码复制、语言切换或并排对照、练习展开、学习完成标记、书签。
- 学习进度保存在当前浏览器；不可用或损坏时正常降级。
- 资源筛选、路线切换、课程打印/导出 Markdown。
- 手机侧栏、键盘导航、可见焦点、减弱动画适配。

## 验收

- 课程、资源和对照的 ID 唯一，内部引用与章节链接可解析；外部来源状态可追溯。
- 搜索、筛选、路由刷新/返回、代码复制、进度保存、导出、手机菜单均可使用。
- 390px 与桌面宽度无整页横向溢出；长代码只在代码容器内滚动。
- 本地 HTTP 页面可访问，浏览器无应用脚本错误；可用时验证 `file://` 入口。
- 若发布成功，返回实际部署地址；若托管服务不可用，交付完整本地版本并明确原因。

## 留给实施者的选择

章节的最终拆分、图解形式、颜色细节、样例数量、测试组织、端口与内部文件组织，可根据资料核查结果决定。以可学习、可检索、可追溯为准，不为凑数量编造内容。

## 2026-11-06 版式与图解设计审查版

本节优先于初版中的视觉自由选择。用户已认可 GitBook 式双栏方向：左侧章节树，右侧宽正文；同一知识点共用原理说明，在正文中用语言标签切换代码，也可并排比较。用户要求进一步参考权威教程布局，加入上下文图解，并明确要求「设计完成给我审查，审查完毕后再继续任务」。当前只交付独立样稿，等待用户审查后才能整合正式网站和继续内容。

布局参考 [MDN 的分层学习模块](https://developer.mozilla.org/en-US/docs/Learn_web_development/Core)、[PyTorch 的循序渐进教程](https://docs.pytorch.org/tutorials/beginner/basics/)和 [GitBook 官方示例中的页面布局说明](https://github.com/GitbookIO/demo-docs-gitbook/blob/main/creating-content/content-structure/page.md)。采用清晰章节层级、正文附近的示例解释、可折叠辅助信息以及宽代码区域；图形为本项目原创，未复制参考网站插图。

- 样稿入口：`ros2-learning-hub/dist/layout-preview.html`。顶部「设计审查 · 图解导览」提供八个示例位置；所有图解放在相关正文小节内。
- 六张本地 SVG：ROS 2 分层架构、发布订阅与 QoS、Action 流程、生命周期、ros2_control 控制循环、Nav2 架构。共十四个上下文放置位置，带图注、适用范围和放大查看。
- 二维交互：平移与旋转滑块更新坐标系、观测点与数值结果，可切换纯平移及旋转 90°，用于理解刚体变换。
- 三维交互：空间几何模型采用正交投影显示，可拖动视角、调整三个关节、显示局部坐标系、切换正视/俯视；明确这是几何教学模型，未接入碰撞、物理仿真或 ROS。
- 图解、字体和脚本均在本地；手机侧栏、代码堆叠、二维图自适应、静态大图容器内横向滚动，不产生整页横向溢出。
- 本轮不替换正式入口、不扩写课程、不重建完整教材或离线压缩包。现有正文只作为设计上下文。

审查重点：阅读密度、左侧树结构、代码标签与并排模式、图解在正文中的位置、二维/三维交互是否有助理解。审查通过后再将这套设计应用到正式网站，并继续正文、示例和离线交付。
