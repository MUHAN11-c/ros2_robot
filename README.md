## 质量标准

- **第〇阶（零基础章）**：遵循 v6.0 编写规范——逐步演算禁止跳步、术语首现必定义、每章配可运行代码、练习折叠完整解答、机器人挂钩具体化
- **深层（原版章节）**：v5.0 规范，每篇 ≥2,000 行、双轮独立审核、五层质量门禁（结构/准确/一致/完整/润色）
- **教材锚定**：每章标注对应的教材章节（同济/浙大/胡寿松/Craig/Boyd/Thrun/Strang 等），便于回书查证
