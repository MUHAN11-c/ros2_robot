## 怎么挑：给三类人的建议

| 你是谁 | 最小购买集合 |
|---|---|
| 学生（有图书馆） | 借同济两本+浙大+胡寿松，自购《C++ Primer》《视觉SLAM十四讲》（这两本要长期翻） |
| 自学者（需自购） | 先买《C++ Primer》+同济《高等数学》上册；线代可先用 Strang 免费资源替代；确认兴趣后再补 SLAM 十四讲 |
| 只想试试水 | 全部用官方免费资源：Strang 18.06 视频 + Pro Git + Modern Robotics PDF + Sutton RL——零成本走完第〇阶到第一阶 |

> 📖 使用心法：**本站章节自足可独立阅读，教材用于查证与扩展**——先读本站建立直觉，再回教材精读对应章节做习题。
