# 机器人文档项目总导航图

> 这份导航回答三个问题：**这个项目教什么、按什么顺序学、每个方向去哪进入。**
> 学习路径问题请直接看 [从零开始学习路线总图](./从零开始学习路线总图.md)——那是给学习者的总入口，本页偏"项目地图"。

---

## 1. 项目定位

一套**从零基础起步、按大学本科→研究生教材脉络组织**的机器人学教学文档体系，四个阶段：

```text
第〇阶 零基础筑基      数学/编程/机器人通识（零基础友好）
第一阶 本科核心        自控原理 / SLAM 十四讲 / ROS2 工程
第二阶 研究生进阶      凸优化 / 概率机器人 / 线性系统 / 规划理论
第三阶 前沿与博士      论文与开源项目精读（原版深水区 430 篇，持续重写中）
```
