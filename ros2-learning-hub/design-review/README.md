# 鸣神 · ROS 2 文档笔记站设计审查版

这份样稿用于审查页面与功能，复用正式教材的 60 章内容和目录规则。紫樱主题、编辑与审查入口在本版集中展示。

## 打开

直接双击本目录的 `index.html` 即可离线阅读、搜索和使用交互实验。可在“设计审查台”查看六组场景和截图，在“紫樱素材画廊”查看插画、头像和贴纸。

也可从工作区根目录启动仅本机可见的预览：

```bash
# 服务根目录包含审查版与它只读引用的正式dist。
# 8767仅为本轮预览端口；结束时在当前终端按Ctrl+C。
python3 -m http.server 8767 --bind 127.0.0.1 --directory /home/wjz/ros2_robot/ros2-learning-hub
```

打开 `http://127.0.0.1:8767/design-review/`。便携压缩包解压后，双击其中 `design-review/index.html`；旁边的 `dist/` 是原教材副本，须一同保留。

## 本轮提供的功能

- 学习目录占满左列，首页、全书目录、图解、笔记、资料、素材与审查入口集中在顶部一行。窄屏顶栏可横向滚动，目录改为抽屉。
- 右上角可切换“阅读模式 / 编辑模式”。编辑模式直接沿用当前正文排版，点击文字即可修改；支持自动保存、恢复原文及撤销恢复。进入非章节页面时选择编辑，会打开最近阅读的章节。
- 当前章下展开可折叠的小节目录。左栏与顶部「本章目录」按正文顺序排列，主小节使用 `章.节` 编号，章内有标题的实测表和图解在对应小节下缩进，并沿用 `章.节.项` 编号。实现对照跟随正文位置，API、案例、练习和出处归到「配套学习」，其中 API 表和动手步骤继续按实际标题分层。点击目录会定位并高亮标题。原位编辑后的章名与小节名同步到目录，已有小节和章节深链接继续可用。
- 樱粉浅色与夜紫深色均使用仓库历史版的「紫樱」吉祥物。
- 紫樱素材画廊收录 7 个仓库原文件，可按类别和用途筛选，并查看裁切示意、SHA256 和来源。
- 教材、正文草稿、代码/API、图解、个人笔记及7122份文档元数据的本地搜索；结果高亮，方向键与回车定位。
- Markdown章节笔记、自动保存、预览、收藏、完成标记、JSON备份导入导出及单章Markdown下载。
- 二维坐标变换与三关节几何实验，支持预设、复位、宽屏和状态保留；退出与折叠释放实例。
- 桌面 1440px、手机 390px 与 320px、深浅主题、阅读和编辑状态的 22 张浏览器截图。第 41 章展示 SLAM 占据图与位姿误差，第 45 章展示 Nav2 代价图与绕行。

阅读数据来自同级 `dist/content.js`、本地修订缓存、`reference-data.js` 与原图解。保存功能保留原教材基线与第三方资料；本轮没有重新执行ROS实验。原文搜索仅使用标题和路径元数据；原始资料读取仍由正式站的白名单服务提供。

## 保存到教材目录

编辑工具条的“保存到教材”和 Ctrl / Cmd + S 写入实际文件。双击打开时首次选择教材根目录；支持时会记住所选目录。也可用“保存位置”更换目录。输入期间的“已暂存到浏览器”和完成写盘后的“已写入教材文件”分别显示。

写入 `source/local-edits.json`、`dist/local-edits.js` 和 `dist/chapters/<章节ID>.html` / `.md`。后续构建继续读取源修订，并同步全文 Markdown 与无脚本连续版。原文第一次保存前备份到 `backups/local-edits/original/`，覆盖前的版本保存在 `backups/local-edits/history/`；同一章的过期页面会提示刷新。目录写入和本机服务都先备份，再写教材。

浏览器没有目录写入能力时，在教材目录运行 `python3 scripts/serve_local.py --editable`，访问 `http://127.0.0.1:8766/design-review/`。服务只监听本机，默认启动方式仍只读。文件页与 HTTP 页的浏览器暂存不通用，已有修改可用“保存位置”中的备份导出转移。便携包含本机编辑服务，全文重建在完整工作区执行。

## 正文草稿、笔记与个人记录

审查版仅写入 `ros2-narukami-design-review-v1`。首次打开时可只读接续同一浏览器来源下的旧进度；不会写回正式站的 `ros2-atlas-v1`。

- 每章一篇笔记，最多50000字符；输入后约450ms保存，关闭抽屉前再保存。
- 每章排版修改累计最多500000字符；约450ms暂存到浏览器。模式切换、章节跳转及页面退出前再次暂存。Ctrl / Cmd + S 保存到教材文件，刷新后可读取磁盘修订。
- 正文草稿和章节笔记分开存储，原教材版本保留。恢复原文可在当前会话撤销；单章下载导出当前正文，JSON备份同时包含草稿、笔记和进度。
- 桌面与手机均在原排版上编辑段落、标题、列表、表格单元格、练习题目及代码。可对选中文字加粗或标为行内代码，并撤销/重做；支持中文输入法，粘贴只插入文本。公式、来源与交互图解保留组件结构，实验在编辑模式下仍可操作。
- “Markdown源码”是可选弹窗，关闭即回正文；只有点击“应用并返回正文”才应用源码修改。兼容之前的Markdown正文草稿，源码应用后仍能直接编辑排版。单章导出包含当前文字、表格、代码和本地图解。
- 原排版修改按稳定字段独立保存，保留原章节的折叠、代码对照、公式和实验。显示时只允许安全的行内文字格式；脚本、事件、样式与外部图片不进入正文。正文指纹不匹配时保留旧记录并提示，避免将旧字段套到不同正文。
- JSON导入上限10 MiB。只接受本站审查版或旧进度格式，剔除无效章节ID；分别合并同章较新的笔记、Markdown草稿和排版修改，解析失败保留原记录。
- 存储不可用时明确显示“未持久保存”，当前编辑内容仍可导出。文件协议与HTTP是不同浏览器来源，跨来源或换机用备份迁移。
- 浏览器自动测试使用隔离上下文；截图里的示例笔记和草稿不预置到用户浏览器。

## 图解与未来组件

当前实验只有本地教学数据。三关节几何模型与模型章的差速车 `learning_description` URDF是两个对象，页面明确区分。

`NarukamiVisuals`提供注册、挂载、尺寸更新、状态提取与释放接口。宽屏移动整个挂载容器，保持参数与事件引用；折叠和离开章节释放实例。

已只读核对 peach_robot v1.0.0 中 `ros2_web_link` 0.8.3 的 SceneView、ImageView、SeriesPlot、GraphView及工作台公有入口；接入状态保留为“接口预留”。本轮没有复制运行其SDK，没有启动ROS、WebSocket、回放、相机、仿真或硬件。
